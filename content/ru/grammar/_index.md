Грамматика GEUL — это бинарный потоковый формат, основанный на SIDX (Semantic-aligned Index) — 64-битном глобальном семантическом идентификаторе.

## Принципы проектирования

1. **Долгосрочная расширяемость:** Зарезервированные биты не используются для временных целей. Пространство сохраняется для будущих поколений.
2. **Неизменность значения:** Однажды определённый битовый шаблон не меняет значения. Для нового значения выделяется новый шаблон.
3. **Обратная совместимость:** Любая версия GEUL должна полностью интерпретировать все предыдущие версии.
4. **Линейная сложность:** Символическая обработка GEUL сохраняет O(n) относительно длины.

## Обзор SIDX

SIDX — это 64-битный глобальный семантический идентификатор. Область определяется последовательным ветвлением от старшего бита.

| Prefix | Область | Доля | Назначение |
|--------|---------|------|------------|
| `1` | Far Future | 50% | Резерв для далёкого будущего |
| `01` | Future | 25% | Резерв для ближайшего будущего |
| `001` | Standard | 12.5% | Официальная стандартная область |
| `000` | Free | 12.5% | Полностью свободная |

`0001` — конвенциональное пространство данной спецификации внутри свободной области (000).

## Система Prefix

```
bit1
├─ 1: Far Future
│
└─ 0
    └─ bit2
        ├─ 1 (01): Future
        │
        └─ 0
            └─ bit3
                ├─ 1 (001): Standard
                │     └─ bit4~
                │         ├─ 1           (001 1)        → Tiny Verb Edge
                │         ├─ 01          (001 01)       → Verb Edge
                │         ├─ 001         (001 001)      → Entity Node
                │         └─ 000         (001 000)      → 9-битная единая область
                │
                └─ 0 (000): Free
                      └─ 0001: Proposal (зеркало Standard)
```

## Типы пакетов

Поток GEUL состоит из 9 типов пакетов. Ниже они перечислены в порядке приоритета (по распределению битов Prefix).

| Тип | Prefix | Слов | Описание |
|-----|--------|------|----------|
| Tiny Verb Edge | `0001 1` | 2 | Высокочастотные простые предикаты |
| [Verb Edge](../verb-edge/) | `0001 01` | 3~5 | 559 корней → 13 767 глаголов WordNet |
| [Entity Node](../entity-node/) | `0001 001` | 4 | 64 EntityType, 48-бит атрибуты |
| [Triple Edge](../triple-edge/) | `0001 000 110` | 4~5 | Свойства/связи, Top63 + расширение |
| [Clause Edge](../clause-edge/) | `0001 000 101` | 4 | 16 дискурсивных связей на основе RST |
| [Event6 Edge](../event6-edge/) | `0001 000 100` | 3~8 | Событие по принципу 5W1H |
| [Context Edge](../context-edge/) | `0001 000 011` | 3 | 64 типа мировоззрений/контекстов |
| [Quantity Node](../quantity-node/) | `0001 000 010` | 4~7 | 64 кода единиц, SI/валюта/timestamp |
| [AST Edge](../ast-edge/) | `0001 000 001` | 3+ | 64 языка программирования, 256 типов AST-узлов |
| [Group Edge](../group-edge/) | `0001 000 000 111` | 4+ | 7 типов множеств/групп |

## Правила кодирования

| Параметр | Правило |
|----------|---------|
| Порядок байтов | Big Endian |
| Порядок битов | MSB First (bit1 = MSB) |
| Размер слова | 16 бит (2 байта) |

Все поля выровнены по границе 16-битного слова, размер пакета всегда кратен слову (2 байта). При необходимости заполняется 0x00.
