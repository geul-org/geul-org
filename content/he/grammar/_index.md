דקדוק GEUL הוא פורמט זרימה בינארית המבוסס על מזהה SIDX (Semantic-aligned Index) הסמנטי הגלובלי בן 64 סיביות.

## עקרונות עיצוב

1. **הרחבה לטווח ארוך:** סיביות שמורות אינן מוקצות לשימושים זמניים. השטח נשמר לשימוש הדורות הבאים.
2. **קביעות משמעות:** משמעות של דפוס סיביות אינה משתנה לאחר הגדרתה. כאשר נדרשת משמעות חדשה, מוקצה דפוס חדש.
3. **תאימות לאחור:** כל גרסה של GEUL חייבת להיות מסוגלת לפרש את כל הגרסאות הקודמות באופן מלא.
4. **סיבוכיות ליניארית:** עיבוד סימבולי ב-GEUL שומר על O(n) ביחס לאורך.

## סקירת SIDX

SIDX הוא מזהה סמנטי גלובלי בגודל 64 סיביות. הוא מסתעף ברצף מהסיבית העליונה לקביעת התחום.

| Prefix | תחום | יחס | שימוש |
|--------|------|------|-------|
| `1` | Far Future | 50% | שמור לעתיד הרחוק |
| `01` | Future | 25% | שמור לעתיד הקרוב |
| `001` | Standard | 12.5% | תחום תקני רשמי |
| `000` | Free | 12.5% | חופשי לחלוטין |

`0001` הוא המרחב המוסכם המשמש הצעה זו בתוך התחום החופשי (000).

## סכמת Prefix

```
bit1
├─ 1: Far Future
│
└─ 0
    └─ bit2
        ├─ 1 (01): Future
        │
        └─ 0
            └─ bit3
                ├─ 1 (001): Standard
                │     └─ bit4~
                │         ├─ 1           (001 1)        → Tiny Verb Edge
                │         ├─ 01          (001 01)       → Verb Edge
                │         ├─ 001         (001 001)      → Entity Node
                │         └─ 000         (001 000)      → 9-bit unified zone
                │
                └─ 0 (000): Free
                      └─ 0001: Proposal (Standard mirroring)
```

## סוגי מנות

זרימת GEUL מורכבת מ-9 סוגי מנות. מפורטים לפי סדר הקצאת סיביות Prefix (= חשיבות).

| סוג | Prefix | מילים | תיאור |
|-----|--------|-------|-------|
| Tiny Verb Edge | `0001 1` | 2 | תיאור פשוט בתדירות גבוהה |
| [קשת פועל](../verb-edge/) | `0001 01` | 3~5 | 559 שורש → 13,767 פעלים ב-WordNet |
| [צומת ישות](../entity-node/) | `0001 001` | 4 | 64 EntityType, תכונות 48 סיביות |
| [קשת שלישייה](../triple-edge/) | `0001 000 110` | 4~5 | מאפיינים/יחסים, Top63 + הרחבה |
| [קשת פסוקית](../clause-edge/) | `0001 000 101` | 4 | 16 יחסי שיח/לוגיקה מבוססי RST |
| [קשת אירוע6](../event6-edge/) | `0001 000 100` | 3~8 | אירוע לפי עקרון שש השאלות |
| [קשת הקשר](../context-edge/) | `0001 000 011` | 3 | 64 סוגי השקפה/הקשר |
| [צומת כמות](../quantity-node/) | `0001 000 010` | 4~7 | 64 קודי יחידות, SI/מטבעות/חותמות זמן |
| [קשת AST](../ast-edge/) | `0001 000 001` | 3+ | 64 שפות תכנות, 256 סוגי צמתי AST |
| [קשת קבוצה](../group-edge/) | `0001 000 000 111` | 4+ | 7 סוגי קבוצות/איגוד |

## כללי קידוד

| רכיב | כלל |
|------|------|
| סדר בתים | Big Endian |
| סדר סיביות | MSB First (bit1 = MSB) |
| גודל מילה | 16 סיביות (2 בתים) |

כל השדות מיושרים לגבולות מילים של 16 סיביות, וגודל המנה תמיד ביחידות מילים (כפולות של 2 בתים). במידת הצורך, ריפוד ממולא ב-0x00.
