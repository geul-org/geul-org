GEUL 文法は SIDX（Semantic-aligned Index）64ビットグローバル意味識別子に基づくバイナリストリームフォーマットである。

## 設計原則

1. **長期拡張性：** 予約ビットを一時的な用途に流用しない。将来世代が使用する空間を保全する。
2. **意味の永続性：** 一度定義されたビットパターンの意味は変更しない。新しい意味が必要な場合は新しいパターンを割り当てる。
3. **下位互換性：** どのバージョンの GEUL もすべての旧バージョンを完全に解釈できなければならない。
4. **線形計算量：** GEUL シンボリック処理は長さに対して O(n) を維持する。

## SIDX 概要

SIDX は64ビットグローバル意味識別子である。最上位ビットから順に分岐して領域を決定する。

| Prefix | 領域 | 割合 | 用途 |
|--------|------|------|------|
| `1` | Far Future | 50% | 遠い未来のための予約 |
| `01` | Future | 25% | 近い未来のための予約 |
| `001` | Standard | 12.5% | 公式標準領域 |
| `000` | Free | 12.5% | 完全自由 |

`0001` は自由領域（000）内で本提案が使用する慣例的空間である。

## Prefix 体系

```
bit1
├─ 1: Far Future
│
└─ 0
    └─ bit2
        ├─ 1 (01): Future
        │
        └─ 0
            └─ bit3
                ├─ 1 (001): Standard
                │     └─ bit4~
                │         ├─ 1           (001 1)        → Tiny Verb Edge
                │         ├─ 01          (001 01)       → Verb Edge
                │         ├─ 001         (001 001)      → Entity Node
                │         └─ 000         (001 000)      → 9ビット統一領域
                │
                └─ 0 (000): Free
                      └─ 0001: Proposal (Standard ミラーリング)
```

## パケットタイプ

GEUL ストリームは9種のパケットタイプで構成される。Prefix ビット割り当て順（=重要度順）に列挙する。

| タイプ | Prefix | ワード | 説明 |
|------|--------|------|------|
| Tiny Verb Edge | `0001 1` | 2 | 高頻度単純述語 |
| [動詞エッジ](../verb-edge/) | `0001 01` | 3~5 | 559 ルート → 13,767 WordNet 動詞 |
| [エンティティノード](../entity-node/) | `0001 001` | 4 | 64 EntityType、48ビット属性 |
| [トリプルエッジ](../triple-edge/) | `0001 000 110` | 4~5 | 属性/関係、Top63 + 拡張 |
| [節エッジ](../clause-edge/) | `0001 000 101` | 4 | RST ベースの談話/論理16関係 |
| [イベント6エッジ](../event6-edge/) | `0001 000 100` | 3~8 | 六何原則イベント |
| [コンテキストエッジ](../context-edge/) | `0001 000 011` | 3 | 世界観/文脈64タイプ |
| [数量ノード](../quantity-node/) | `0001 000 010` | 4~7 | 64単位コード、SI/通貨/タイムスタンプ |
| [AST エッジ](../ast-edge/) | `0001 000 001` | 3+ | 64プログラミング言語、256 ASTノードタイプ |
| [グループエッジ](../group-edge/) | `0001 000 000 111` | 4+ | 集合/グループ7タイプ |

## エンコード規則

| 項目 | 規則 |
|------|------|
| バイトオーダー | Big Endian |
| ビットオーダー | MSB First (bit1 = MSB) |
| ワードサイズ | 16ビット（2バイト） |

すべてのフィールドは16ビットワード境界に整列し、パケットサイズは常にワード単位（2バイトの倍数）である。パディングが必要な場合は 0x00 で埋める。
