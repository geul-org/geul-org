DO는 TOULMIN 그래프의 관계를 쓰는 LINK Codec이다. 뜻: 노드가 Active이면 수행하는 동작.

| 항목 | 값 |
|---|---|
| 이름 | `DO` (규격 문서 BIND `DO`) |
| TAG ID | `0x111L` |
| 코덱 ID | `0x00001110` |
| 규격 문서 | `0x00000000/codecs/0x00001110/` (DECLARE 대상 `1110`) |
| 섹션 | 8 `1000` (Edge TOULMIN), 섹션 안 오프셋 C = 17 |
| Kind | Edge · 계열: TOULMIN, 묶음: 실행, 레이아웃: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| 색인 설명 | 노드가 Active이면 수행하는 동작 |
| Hugo 쪽 | `edge/toulmin/link.md` |

## 레이아웃

레이아웃은 [LINK](_index.md#link)다(ID, src, dst, flags, 조건부 필드, SPAN).

| 항목 | 값 |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | 규칙 → FuncRef |

- dst는 FuncRef(REF(ALIAS, 없으면 0) + VerbCode 1 WORD)다([NODE](_index.md#필드)).
- F_FORCE는 쓰지 않는다(켜져 있으면 거부한다).
- 공통 필드(ID, REF, SPAN)와 수치 규칙은 [TOULMIN](_index.md#공통-필드)을 따른다.

## 코덱 문서

코덱 문서는 DECLARE(대상 `1110`)를 둔다. LINK 레이아웃의 조건부 필드와 SOURCE가 정하는 SPAN 폭은 FIELD로 선언할 수 없어, 필드 선언은 열린 문제다([TOULMIN](_index.md#열린-문제)).

## 관련 페이지

## 규격 문서 원문

규격 문서 `0x00000000/codecs/0x00001110/latest.geul`을 `geul show`로 읽은 모습이다(16진은 대문자).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
