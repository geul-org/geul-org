GEUL(General Encoding Unified Language) 문법은 SIDX(Semantic-aligned Index) 64비트 전역 의미 식별자를 기반으로 한 바이너리 스트림 포맷이다.

## 설계 원칙

1. **장기 확장성:** 예약 비트를 임시 용도로 전용하지 않는다. 미래 세대가 사용할 공간을 보존한다.
2. **의미의 영속성:** 한 번 정의된 비트 패턴의 의미는 변경하지 않는다. 새 의미가 필요하면 새 패턴을 할당한다.
3. **하위 호환:** 어떤 버전의 GEUL도 모든 이전 버전을 완전히 해석할 수 있어야 한다.
4. **선형 복잡도:** GEUL 심볼릭 처리는 길이에 대해 O(n)을 유지한다.

## SIDX 개요

SIDX는 64비트 전역 의미 식별자이다. 최상위 비트부터 순서대로 분기하여 영역을 결정한다.

| Prefix | 영역 | 비율 | 용도 |
|--------|------|------|------|
| `1` | Far Future | 50% | 먼 미래를 위한 예약 |
| `01` | Future | 25% | 가까운 미래를 위한 예약 |
| `001` | Standard | 12.5% | 공식 표준 영역 |
| `000` | Free | 12.5% | 완전 자유 |

`0001`은 자유 영역(000) 내에서 본 제안이 사용하는 관례적 공간이다.

## Prefix 체계

```
bit1
├─ 1: Far Future
│
└─ 0
    └─ bit2
        ├─ 1 (01): Future
        │
        └─ 0
            └─ bit3
                ├─ 1 (001): Standard
                │     └─ bit4~
                │         ├─ 1           (001 1)        → Tiny Verb Edge
                │         ├─ 01          (001 01)       → Verb Edge
                │         ├─ 001         (001 001)      → Entity Node
                │         └─ 000         (001 000)      → 9비트 통일 영역
                │
                └─ 0 (000): Free
                      └─ 0001: Proposal (Standard 미러링)
```

## 패킷 타입

GEUL 스트림은 9종의 패킷 타입으로 구성된다. Prefix 비트 할당 순서(=중요도)로 나열한다.

| 타입 | Prefix | 워드 | 설명 |
|------|--------|------|------|
| Tiny Verb Edge | `0001 1` | 2 | 고빈도 단순 서술 |
| [동사 엣지](../verb-edge/) | `0001 01` | 3~5 | 559 루트 → 13,767 WordNet 동사 |
| [엔티티 노드](../entity-node/) | `0001 001` | 4 | 64 EntityType, 48비트 속성 |
| [트리플 엣지](../triple-edge/) | `0001 000 110` | 4~5 | 속성/관계, Top63 + 확장 |
| [절 엣지](../clause-edge/) | `0001 000 101` | 4 | RST 기반 담화/논리 16관계 |
| [이벤트6 엣지](../event6-edge/) | `0001 000 100` | 3~8 | 6하원칙 사건 |
| [컨텍스트 엣지](../context-edge/) | `0001 000 011` | 3 | 세계관/맥락 64타입 |
| [수량 노드](../quantity-node/) | `0001 000 010` | 4~7 | 64 단위 코드, SI/통화/타임스탬프 |
| [AST 엣지](../ast-edge/) | `0001 000 001` | 3+ | 64 프로그래밍 언어, 256 AST 노드 타입 |
| [그룹 엣지](../group-edge/) | `0001 000 000 111` | 4+ | 집합/그룹 7타입 |

## 인코딩 규칙

| 항목 | 규칙 |
|------|------|
| 바이트 오더 | Big Endian |
| 비트 오더 | MSB First (bit1 = MSB) |
| 워드 크기 | 16비트 (2바이트) |

모든 필드는 16비트 워드 경계에 정렬하고, 패킷 크기는 항상 워드 단위(2바이트 배수)이다. 패딩 필요 시 0x00으로 채운다.
