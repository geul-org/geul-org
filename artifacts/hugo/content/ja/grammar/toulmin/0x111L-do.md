DO は TOULMIN グラフの関係を書く LINK Codec である。意味はノードが Active なら行う動作。

| 項目 | 値 |
|---|---|
| 名前 | `DO` (規格ドキュメント BIND `DO`) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| 規格ドキュメント | `0x00000000/codecs/0x00001110/` (DECLARE 対象 `1110`) |
| セクション | 8 `1000` (Edge TOULMIN)、セクション内オフセット C = 17 |
| Kind | Edge · 系列: TOULMIN、まとまり: 実行、レイアウト: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| 索引の説明 | ノードが Active なら行う動作 |
| Hugo 側 | `edge/toulmin/link.md` |

## レイアウト {#레이아웃}

レイアウトは [LINK](_index.md#link) である (ID、src、dst、flags、条件付きフィールド、SPAN)。

| 項目 | 値 |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | 規則 → FuncRef |

- dst は FuncRef (REF (ALIAS、なければ 0) + VerbCode 1 WORD) である ([NODE](_index.md#필드))。
- F_FORCE は使わない (オンになっていれば拒否する)。
- 共通フィールド (ID、REF、SPAN) と数値規則は [TOULMIN](_index.md#공통-필드) に従う。

## Codec ドキュメント {#코덱-문서}

Codec ドキュメントは DECLARE (対象 `1110`) を置く。LINK レイアウトの条件付きフィールドと、SOURCE が定める SPAN 幅は FIELD で宣言できないため、フィールド宣言は未解決の問題である ([TOULMIN](_index.md#열린-문제))。

## 規格ドキュメント原文 {#규격-문서-원문}

規格ドキュメント `0x00000000/codecs/0x00001110/latest.geul` を `geul show` で読んだ姿である (16 進は大文字)。

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
