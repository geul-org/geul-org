DO هو Codec من نوع LINK يكتب علاقة في رسم TOULMIN. المعنى: إجراء يُنفَّذ إذا كانت العقدة Active.

| البند | القيمة |
|---|---|
| الاسم | `DO` (مستند المواصفة BIND `DO`) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| مستند المواصفة | `0x00000000/codecs/0x00001110/` (هدف DECLARE هو `1110`) |
| القسم | 8 `1000` (Edge TOULMIN)، الإزاحة داخل القسم C = 17 |
| Kind | Edge · العائلة: TOULMIN، الحزمة: التنفيذ، التخطيط: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| وصف الفهرس | إجراء يُنفَّذ إذا كانت العقدة Active |
| جهة Hugo | `edge/toulmin/link.md` |

## التخطيط {#레이아웃}

التخطيط هو [LINK](_index.md#link) (ID وsrc وdst وflags والحقول الشرطية وSPAN).

| البند | القيمة |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | قاعدة → FuncRef |

- dst هو FuncRef (REF(ALIAS، أو 0 إن لم يوجد) + VerbCode في 1 WORD) ([NODE](_index.md#필드)).
- لا يُستخدم F_FORCE (يُرفض إن كان مفعّلًا).
- تتبع الحقول المشتركة (ID وREF وSPAN) وقواعد الأعداد ما في [TOULMIN](_index.md#공통-필드).

## مستند Codec {#코덱-문서}

يتضمن مستند Codec عنصر DECLARE (الهدف `1110`). لا يمكن إعلان الحقول الشرطية في تخطيط LINK وعرض SPAN الذي يحدده SOURCE بواسطة FIELD، لذا فإعلان الحقول مسألة مفتوحة ([TOULMIN](_index.md#열린-문제)).

## صفحات ذات صلة {#관련-페이지}

- [LINK](_index.md#link)، [TOULMIN](_index.md)

## نص مستند المواصفة {#규격-문서-원문}

هذا ما يعرضه `geul show` عند قراءة مستند المواصفة `0x00000000/codecs/0x00001110/latest.geul` (الأرقام السداسية عشرية بأحرف كبيرة).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
