ATTACKS هو Codec من نوع LINK يكتب علاقة في رسم TOULMIN. المعنى: علاقة هجوم. يخفض حكمُ المهاجِم حكمَ الهدف تدريجياً بمقدار قوة الهجوم (0 إلى 1، والافتراضي 1).

| البند | القيمة |
|---|---|
| الاسم | `ATTACKS` (مستند المواصفة BIND `ATTACKS`) |
| TAG ID | `0x108L` |
| Codec ID | `0x00001080` |
| مستند المواصفة | `0x00000000/codecs/0x00001080/` (هدف DECLARE هو `1080`) |
| القسم | 8 `1000` (Edge TOULMIN)، الإزاحة داخل القسم C = 8 |
| Kind | Edge · العائلة: TOULMIN، الحزمة: العلاقة، التخطيط: LINK |
| TAG WORD | `0001 0000 1000 LLLL` (`000K KKKC CCCC LLLL`) |
| وصف الفهرس | علاقة هجوم. يخفض حكمُ المهاجِم حكمَ الهدف تدريجياً بمقدار قوة الهجوم (0 إلى 1، والافتراضي 1) |

## التخطيط {#레이아웃}

التخطيط هو [LINK](_index.md#link) (ID وsrc وdst وflags والحقول الشرطية وSPAN).

| البند | القيمة |
|---|---|
| TANGEUL | `don't X when Y` |
| src → dst | قاعدة → قاعدة. يخفض الحكم تدريجياً بمقدار قوة الهجوم |

- dst هو REF للعقدة.
- يستخدم F_FORCE (قوة الهجوم) هذا Codec وحده. انظر [قوة الهجوم](#공격-세기) أدناه.
- تتبع الحقول المشتركة (ID وREF وSPAN) وقواعد الأعداد ما في [TOULMIN](_index.md#공통-필드).

## قوة الهجوم {#공격-세기}

تدل قوة الهجوم (Force) على مدى شدة هجوم حافة ATTACKS واحدة على الهدف. نطاقها من 0 إلى 1، وتكون 1 إذا لم يوجد F_FORCE.

- في الحكم تُضرب مساهمة قيمة حكم المهاجِم v، أي `(v+1)/2`، في القوة F. ويدخل هجوم الدحض (COUNTER) في حد المقام `F·(v+1)/2`، ويدخل هجوم الاستثناء (EXCEPT) في البوابة `Π(1 − F·(v+1)/2)`. وإذا كانت F تساوي 0 فلا أثر للهجوم في الحكم.
- تتبع القيمة قواعد الأعداد في [TOULMIN](_index.md#수치). يحذف المرمِّز الأصفار الأخيرة من المعامل (0.5 هي `C=5, E=−1`، و1.0 هي `C=1, E=0`). ويقبل فاكّ الترميز حتى أربع منازل عشرية.
- الصيغة السطحية التي لا تذكر القوة (`don't X when Y` و`` `Y` 면 `X` 는 무효다``) تُطفئ F_FORCE.
- الصيغة السطحية التي تذكر القوة (`` `Y` 면 `X` 를 0.5의 세기로 공격한다``) تُشغِّل F_FORCE وتحمل قيمتها. وحتى لو كُتبت 1 مثل `1.0의 세기로` يُشغَّل F_FORCE وتُحمل القيمة 1. وبذلك تعود الصيغة السطحية الأصلية كما هي.
- قوة الهجوم محور مختلف عن صلابة العقدة (Strict وDefeasible وDefeater). فالصلابة تلحق بالعقدة، وقوة الهجوم تلحق بحافة ATTACKS.

### مثال على قوة الهجوم {#공격-세기-예시}

`` `Y` 면 `X` 를 0.5의 세기로 공격한다``. Edge Id هو 5، والمهاجِم Y له Edge Id 3، والهدف X له Edge Id 2، وعرض SPAN هو 1 WORD.

```
108D                  TAG WORD: Edge، وCodec 0x108L (ATTACKS)، والمجموع 14 WORD
0051 0005             ID      LOCAL 5
0051 0003             src     LOCAL 3 (Y، المهاجِم)
0051 0002             dst     LOCAL 2 (X، الهدف)
0010                  flags   F_FORCE
0683 FFFF FFFF 0005   F_FORCE SIGNED-DECIMAL, E=−1, C=5 (0.5)
0040 001A             SPAN    بايت البداية 0x40، وعدد البايتات 0x1A
```

أما الحافة نفسها دون ذكر القوة فتكون flags فيها `0000` ولا يوجد حقل F_FORCE. ويكون TAG WORD هو `1089` (المجموع 10 WORD).

## مستند Codec {#코덱-문서}

يتضمن مستند Codec عنصر DECLARE (الهدف `1080`). لا يمكن إعلان الحقول الشرطية في تخطيط LINK وعرض SPAN الذي يحدده SOURCE بواسطة FIELD، لذا فإعلان الحقول مسألة مفتوحة ([TOULMIN](_index.md#열린-문제)).

## نص مستند المواصفة {#규격-문서-원문}

هذا ما يعرضه `geul show` عند قراءة مستند المواصفة `0x00000000/codecs/0x00001080/latest.geul` (الأرقام السداسية عشرية بأحرف كبيرة).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000108000000000
BODY
#1 DECLARE 0x1080
#2 BIND #1 "ATTACKS"
```
