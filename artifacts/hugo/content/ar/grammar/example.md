نقرأ من أوله إلى آخره مستندًا صغيرًا عن عنصر ويكي بيانات Q42 (Douglas Adams). محتواه كما يلي.

- الاسم الإنجليزي: Douglas Adams
- Q42 نسخة (instance) من إنسان (Q5) (P31).
- تلقى Q42 تعليمه في St John's College (Q691283) (P69). زمن البدء (P580) هو عام 1971.

المستند هو المستند `0x510000000000002A` الصادر عن Issuer `0x00000001`، وطوله الكامل 63 WORD (126 بايت).

## الكل {#전체}

```
1C01 003F 1C51 0001 1C79 0418 0000 0001 5100 0000 0000 002A 0000 0000
1C30
0A4E 0010 0051 0001 0141 002A 0799 0761 656E 446F 7567 6C61 7320 4164 616D 7300
0AA9 0051 0002 0191 001F 0141 002A 0141 0005 0000
0AAA 0051 0003 0191 0045 0141 002A 0142 000A 8C53 0000
0AB9 0051 0004 0191 0244 0051 0003 06E2 3139 3731
1C40
```

## HEAD {#head}

```
1C01 003F
```

`1C01` هي Meta (القسم 14)، وCodec `0x1C0L` (DOC-1WORD)، وLength يساوي 2 WORD. القيمة `003F` (63) هي عدد WORD في المستند كله. بهذه القيمة يعرف المفكّك نهاية المستند مسبقًا.

```
1C51 0001
```

Meta `0x1C5L` SPEC-VERSION. هو إصدار المواصفة الذي يتبعه هذا المستند. وv1 هو `0001`.

```
1C79 0418 0000 0001 5100 0000 0000 002A 0000 0000
```

Meta `0x1C7L` DOC-ID، وطوله الكامل 10 WORD. الـ Payload هو Reference واحد من نوع DOC-POINTER.

| WORD | المعنى |
|---|---|
| `0418` | Reference، وCodec `0x041L` (DOC-POINTER)، و9 WORD |
| `0000 0001` | Issuer `0x00000001` (2 WORD) |
| `5100 0000 0000 002A` | معرّف المستند `0x510000000000002A` |
| `0000 0000` | الإصدار `0` (المستند نفسه) |

```
1C30
```

BODY. ينتهي HEAD ويبدأ BODY.

## BODY {#body}

### #1 LABEL — الاسم الإنجليزي {#1-label--영어-이름}

```
0A4E 0010 0051 0001 0141 002A 0799 0761 656E 446F 7567 6C61 7320 4164 616D 7300
```

| WORD | المعنى |
|---|---|
| `0A4E` | Edge، وCodec `0x0A4L` LABEL، وLength `1110` (ممتد) |
| `0010` | الطول الممتد: 16 WORD كاملة |
| `0051 0001` | Edge Id: LOCAL 1 |
| `0141 002A` | Subject: Q42 في ويكي بيانات |
| `0799` | Object: UTF8-LANGUAGE-TEXT، عدد بايتات فردي (`0x079L`)، و10 WORD |
| `0761 656E` | اللغة: BCP 47 `en` |
| `446F … 7300` | `Douglas Adams` أي 13 بايت + حشو `00` |

### #2 TRIPLE — Q42 إنسان {#2-triple--q42는-사람이다}

```
0AA9 0051 0002 0191 001F 0141 002A 0141 0005 0000
```

| WORD | المعنى |
|---|---|
| `0AA9` | Edge، وCodec `0x0AAL` TRIPLE، و10 WORD |
| `0051 0002` | Edge Id: LOCAL 2 |
| `0191 001F` | Predicate: P31 (instance of) |
| `0141 002A` | Subject: Q42 |
| `0141 0005` | Object: Q5 (إنسان) |
| `0000` | Rank: normal |

### #3 TRIPLE — تلقى Q42 تعليمه في St John's College {#3-triple--q42는-st-johns-college에서-교육받았다}

```
0AAA 0051 0003 0191 0045 0141 002A 0142 000A 8C53 0000
```

| WORD | المعنى |
|---|---|
| `0AAA` | Edge، وTRIPLE، و11 WORD |
| `0051 0003` | Edge Id: LOCAL 3 |
| `0191 0045` | Predicate: P69 (educated at) |
| `0141 002A` | Subject: Q42 |
| `0142 000A 8C53` | Object: Q691283. القيمة تتجاوز 16 بت، فهي Reference من 3 WORD |
| `0000` | Rank: normal |

### #4 QUALIFIER — زمن البدء عام 1971 {#4-qualifier--시작-시점-1971년}

```
0AB9 0051 0004 0191 0244 0051 0003 06E2 3139 3731
```

| WORD | المعنى |
|---|---|
| `0AB9` | Edge، وCodec `0x0ABL` QUALIFIER، و10 WORD |
| `0051 0004` | Edge Id: LOCAL 4 |
| `0191 0244` | Property: P580 (start time) |
| `0051 0003` | Target: #3 (الـ TRIPLE أعلاه) |
| `06E2 3139 3731` | Value: EDTF `1971` (الدقة بالسنة، فهو EDTF لا GREGORIAN-DATE) |

معنى #3 هو مجموع #3 نفسه وكل QUALIFIER يشير إليه: «تلقى Q42 تعليمه في St John's College منذ عام 1971.»

```
1C40
```

END. هنا تنتهي الـ 63 WORD.

## القراءة دون كتاب الرموز {#코덱북-없이-읽으면}

المفكّك الذي لا يعرف كتاب الرموز يعرف مع ذلك ما يلي.

- المستند 63 WORD، وفي HEAD سجلا Meta اثنان، وفي BODY أربعة سجلات Edge.
- Codec كل Edge (LABEL وTRIPLE وTRIPLE وQUALIFIER) وEdge Id (1 و2 و3 و4).
- موضع السجل التالي لكل سجل.

أما دور المكوّنات (Predicate وSubject وObject وRank) فلا يُعرف إلا بقراءة [مستند المواصفة](codec-spec.md) الخاص بكل Codec.

## تجزئة المحتوى {#내용-해시}

تجزئة المحتوى (SHA-256) لهذا المستند كما يلي. عند النشر تُسجَّل هذه التجزئة في قائمة الإصدارات مع معرّف الإصدار.

