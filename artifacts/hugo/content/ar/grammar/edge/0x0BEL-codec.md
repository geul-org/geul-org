## الحقول (مستند المواصفة) {#필드-규격-문서}

ترتيب FIELD داخل المستند هو ترتيب حقول Payload ([مستند مواصفة Codec](../codec-spec.md)). لا يُصرَّح بـ Edge Id الخاص بـ Edge عبر FIELD.

| الترتيب | الحقل (BIND) | FIELD | العرض | الصيغة المقبولة (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `field` | #2 | سجل | `0050` LOCAL |  |
| 2 | `target` | #4 | قيمة خام 1 WORD |  |  |

CODEC هو Edge عبارة يحدد Kind وCodec واحداً يقبله [FIELD](0x0BCL-field.md) واحد. Codec `0x0BEL`.

كما يُلحق [ENUM](0x0BDL-enum.md) معنى بقيمة رمز واحدة في حقل خام، يُلحق CODEC صيغة واحدة بالحقل. ولأن كل Edge يحمل صيغة واحدة فيمكن تحديد عدة صيغ. التخطيط مضمَّن في المفكِّك ([مستند مواصفة Codec](../codec-spec.md)).

## التخطيط {#레이아웃}

```
TAG WORD          0000 1011 1110 LLLL
[Length TAG ممتد]
Edge Id           سجل LOCAL Reference
الحقل             سجل LOCAL Reference يشير إلى Edge من نوع FIELD
الهدف             1 WORD. 000K KKKC CCCC LLLL (LLLL = 0000 تام، 1111 حرف بدل)
```

## WORD الهدف {#대상-word}

- يُترك موضع Codec في TAG WORD (القسم `KKKK` و`CCCCC`) كما هو. والبتات الثلاث العليا 0. و`LLLL` هو `0000` (تام) أو `1111` (حرف بدل)، وأي قيمة أخرى invalid.
- القيمة المكتوبة في 32 بت للهدف التام (`LLLL = 0000`) هي Codec ID لذلك Codec (مثل LOCAL `0x0050` ← `0x00000050`، وCOORDINATE-EARTH `0x0640`، وUTF8-LANGUAGE-TEXT `0x0780`). لذلك يشير الهدف مباشرة إلى مستند مواصفة ذلك Codec ([مستند مواصفة Codec](../codec-spec.md)).
- يُحدَّد أيضاً زوج الرموز الزوجي/الفردي (النص وسلسلة البايتات) بالرمز التام. ولقبول الزوجي والفردي معاً يوضع كلاهما. ولا توجد قاعدة لتفسير الزوج معاً (إذ توجد رموز متجاورة ليست زوجاً مثل NUMERIC `0x064L`/`0x065L`).

### حرف البدل (`LLLL = 1111`) {#와일드카드-llll--1111}

- إذا كان `LLLL = 1111` قُبل القسم `KKKK` كله (32 خانة) في WORD الهدف بغض النظر عن قيمة `C`. وداخل القسم نفسه فإن `C` أياً كانت قيمته فالمعنى واحد. يُنظر فقط هل قسم الهدف وقسم السجل واحد. ولا يُقبل ما يتجاوز القسم.
- إذا كان `LLLL = 1111` فتوصى بأول خانة في القسم (`C = 0`). وهي توصية لا إلزام. ويصح أي `C` آخر في القسم نفسه.
- إذا امتد Kind على عدة أقسام فتُسرد CODEC لكل قسم.

| الهدف | المعنى |
|---|---|
| `000F`·`020F`·`040F` | أي Reference (الأقسام 0~2، بما فيها REFERENCE-ISSUER) |
| `060F`·`080F` | أي Value (القسمان 3 و4، بما فيهما VALUE-ISSUER) |
| `0A0F`·`0C0F`·`0E0F`·`100F`·`120F`·`140F`·`160F`·`180F`·`1A0F` | أي Edge (الأقسام 5~13، بما فيها EDGE-ISSUER) |
| `1C0F`·`1E0F` | أي Meta (القسمان 14 و15) |

- علامات موضع Reference (`0x000L~0x002L`) لا تناسب `LLLL = 1111` (فـ `000F` لا تقبل ABSENT·UNKNOWN-VALUE·NO-VALUE). وفي المقابل فإن القسم الذي عُيّنت فيه أول خانة مثل Value `0x060L` (BOOL) وEdge `0x0A0L` (REFERENCE-NODE) يشملها أيضاً `LLLL = 1111` (ولقبول BOOL فقط `0600` بـ `LLLL = 0000`).
- الهدف ذو `LLLL = 1111` لا يشير إلى مستند مواصفة.
- يُكتب عدم الاكتراث بالتكميم أو الحزمة بسرد CODEC (`LLLL = 0000`) فقط. مثال: عدم الاكتراث بتكميم WIKIDATA-QID هو خمسة: `0140` و`0150` و`0160` و`0170` و`0180`.
- رموز نظام 5Q في Reference تحتوي على التكميم. فيُحدَّد الهدف تاماً حتى التكميم. ولقبول عدة Quantifier توضع عدة CODEC. وتكميم REFERENCE-ISSUER تحدده وثيقة Issuer.

### علامة الموضع (الهدف `0000` و`0010` و`0020`) {#자리-표지-대상-0000-0010-0020}

[علامة الموضع](../slot-marker.md) حزمة سجلات من 1 WORD عُيّنت في أول ثلاث خانات `0x000L~0x002L` من القسم 0 في Reference. لا تكميم لها.

| الهدف | العلامة | المعنى |
|---|---|---|
| `0000` | ABSENT | غير مدوَّن. ذلك الحقل حقل اختياري |
| `0010` | UNKNOWN-VALUE | غير معروف. يقبل تأكيد أن هناك قيمة |
| `0020` | NO-VALUE | لا شيء. يقبل تأكيد أنه لا توجد قيمة |

- **قاعدة القبول:** لا تصح العلامة إلا إذا وُجد WORD نفسه هدفاً تاماً في قائمة CODEC لذلك الحقل. فحروف البدل وحقل السجل بلا CODEC («أي سجل») لا تقبل العلامة. وعلامة في موضع سجل HEAD·BODY أو موضع Edge Id invalid.
- القائمة التي فيها أهداف علامات فقط (علامة دائماً) invalid (تعميم لقاعدة القائمة التي فيها `0000` فقط). وتُستخدم مع هدف `LLLL = 1111` أو هدف تام (`000F`·`020F`·`040F` + `0000` = أي Reference أو حذف).
- لا يمكن وضع هدف علامة في حقل خام. فالقيمة الخام بلا TAG وعرضها محدد فلا موضع فيها لعلامة من 1 WORD.
- معنى العلامة تحدده مواصفة Codec التي تقبلها.

### الحقل الاختياري (الهدف `0000`) {#선택-필드-대상-0000}

- إذا وُضع الهدف `0000` في قائمة CODEC لحقل سجل فذلك الحقل **حقل اختياري**. وعند حذفه يُكتب في موضعه WORD واحد `0x0000`. وهذا السجل من 1 WORD هو علامة الموضع ABSENT (غير مدوَّن).
- `0x0000` هو Reference وCodec `0x000L` (Reserved) و`LLLL = 0000` (الكل 1 WORD). لا يتداخل مع سجل آخر، ويتخطاه المفكِّك الذي لا يعرف المواصفة بوصفه سجلاً من 1 WORD.
- يشغل الحقل الاختياري موضعه دائماً. فعند الحذف يجب كتابة `0x0000` ولا يُترك الموضع فارغاً (حتى لو كان حقلاً أخيراً). لذلك للسجل الواحد تدوين واحد فقط، ويتحدد التفكيك بالموضع وحده. ولا قيد على موضع الحقل الاختياري وعدده ولا على تداخل قائمته مع حقول أخرى.
- ABSENT صالح في موضع الحقل الاختياري فقط. و`0x0000` في موضع سجل HEAD·BODY أو موضع الحقل الإلزامي أو موضع Edge Id invalid.
- الحذف ليس «لا توجد قيمة» بل «غير مدوَّن». لا يؤكَّد شيء عن العالم. ويُكتب «لا توجد قيمة» بـ NO-VALUE (`0020`). وما يعنيه الحذف (مثل أن عدم وجود هدف في TAG يعني هذا الإصدار) تحدده مواصفة كل صيغة.

## التفسير والصلاحية {#해석과-유효성}

- الحقل هو Edge من نوع FIELD في الوثيقة نفسها. لا يوضع الهدف نفسه مرتين في حقل واحد.
- **حقل السجل (العرض 0)**: إن لم توجد CODEC قُبل أي سجل عدا علامة الموضع. وإن وُجدت واحدة أو أكثر فهي قائمة مغلقة. يجب أن يكون Kind وCodec (مع Quantifier في Reference) لسجل ذلك الحقل أحد القائمة، وإلا فلا يتبع السجل المواصفة. وهذا يخالف ENUM التي هي قائمة مفتوحة.
- **الحقل الخام (العرض n ≥ 1، أو المتبقي `0xFFFF`)**: لا يوضع في CODEC إلا هدف تام واحد (لا حرف بدل). وتلك القيمة الخام هي Payload ذلك Value بعد طرح TAG. تعطي CODEC الـ Kind وCodec، ويعطي عرضُ FIELD الـ Length. وفي الرمز الزوجي/الفردي يحدد الرمز المعيَّن زوجية عدد البايتات أو فرديته. وإن لم تتبع القيمة الخام قواعد ذلك Value (ومنها الطول) فلا يتبع السجل المواصفة.
- تُقارن علامة الموضع بالأهداف التامة في القائمة فقط. فإن جاء `0x0000` في موضع الحقل الاختياري (الهدف `0000`) فهو حذف. وأي سجل آخر يُقارن بالقائمة بعد طرح أهداف العلامات.
- يمكن وضع CODEC وENUM معاً لحقل خام. فـ CODEC للصيغة وENUM لاسم قيمة الرمز (مثل جعل rank من نوع UNSIGNED-INTEGER وجعل 0·1·2 ENUM).
- يمكن إلحاق اسم بـ Edge Id الخاص بـ CODEC عبر BIND لكنه ليس إلزامياً.
- حقل «Reference أو Value» يُكتب بخمس CODEC (`000F` و`020F` و`040F` و`060F` و`080F`).

## الطول {#길이}

```
الكل = 1 + N_len + N_id + N_field + 1 WORD   (6 WORD إذا كان Edge Id والحقل من نوع LOCAL بـ 1 WORD ID)
```

## مثال {#예시}

في مستند مواصفة LABEL `0x00000000/codecs/0x00000A40/` يقبل حقل Object (FIELD #3) UTF8-LANGUAGE-TEXT (الزوجي والفردي) وLOCAL. Edge Id هي 7~9.

```
0BE5 0051 0007 0051 0003 0780
0BE5 0051 0008 0051 0003 0790
0BE5 0051 0009 0051 0003 0050
```

- TAG `0BE5` (Edge، Codec `0x0BEL`، `LLLL = 0101`، 6 WORD)، وEdge Id `0051 0007`، والحقل `0051 0003`، والهدف `0780`.
