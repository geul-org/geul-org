CODEC هو Edge وصف يحدد Kind وCodec واحداً يقبله [FIELD](/ar/grammar/edge/field/) واحد. Codec `0x1E`.

كما يعطي [ENUM](/ar/grammar/edge/enum/) معنى لقيمة رمز واحدة في حقل القيمة الخام، يعطي CODEC الحقل صيغة واحدة. ولأنه واحد لكل Edge يمكن تحديد عدة صيغ. تخطيطه مدمج في المفكك ([مواصفة Codec](/ar/grammar/codec-spec/)).

## التخطيط

```
TAG WORD          0001 0LLL L001 1110
[Length ممتد TAG]
Edge Id           سجل Reference من نوع LOCAL
الحقل             سجل Reference من نوع LOCAL يشير إلى Edge من نوع FIELD
الهدف             1 WORD. 000K KLLL LCCC CCCC (LLLL = 0000 دقيق، 1111 رمز شامل)
```

## WORD الهدف

- يُترك موضع Kind (`KK`) وCodec (`CCCCCCC`) في TAG WORD كما هو. وأعلى 3 بتات هي 0. و`LLLL` هي `0000` (دقيق) أو `1111` (رمز شامل)، وأي قيمة أخرى invalid.
- الهدف الدقيق (`LLLL = 0000`) له قيمة معرّف مستند مواصفة Codec نفسها (مثل LOCAL `0x0008` وCOORDINATE-EARTH `0x0804` وUTF8-LANGUAGE-TEXT `0x084A`). لذلك يشير الهدف مباشرة إلى مستند مواصفة ذلك Codec.
- أزواج الرموز زوجي/فردي (النصوص وسلاسل البايتات) تُحدد أيضاً برمز دقيق. ولقبول الزوجي والفردي يوضع الاثنان معاً. ولا توجد قاعدة تفسّر الزوج مجموعة واحدة (فهناك رموز متجاورة ليست أزواجاً مثل NUMERIC `0x04`/`0x05`).

### الرمز الشامل (`LLLL = 1111`)

- يجب أن يتطابق Kind، و**حزمة بتات Codec التي قيمتها 0 تطابق أي شيء**. في Reference تكون `CCCC` (Codec) و`QQQ` (Quantifier) حزمتين منفصلتين، وفي بقية Kind تكون البتات السبع كلها حزمة واحدة.

| الهدف | المعنى |
|---|---|
| `0780` | أي Reference |
| `07A0` | WIKIDATA-QID بصرف النظر عن Quantifier |
| `0781` | أي Reference Codec بـ Quantifier من نوع Generic (`001`) |
| `0F80` | أي Value |
| `1780`، `1F80` | أي Edge، أي Meta |

- الرمز الشامل الذي لا يطابق شيئاً invalid. في Value وEdge وMeta يجب أن يكون Codec صفراً، وفي Reference يجب أن تكون إحدى `CCCC` أو `QQQ` صفراً. وReference `CCCC = 0000` (علامة موضع) هو Codec محجوز فـ **لا يطابق أي رمز شامل** (فـ `0780` لا يقبل ABSENT ولا UNKNOWN-VALUE ولا NO-VALUE). في المقابل، Kind الذي خُصص له Codec صفر مثل Value `0x00` (BOOL) وEdge `0x00` (REFERENCE-NODE) يشمله الرمز الشامل أيضاً (ولقبول BOOL وحده يُستخدم `LLLL = 0000`).
- الرمز الشامل لا يشير إلى مستند مواصفة.
- لا يوجد تعبير يثبّت حزمة واحدة غير صفرية ويثبّت الحزمة الصفرية، مثل "أي Reference من نوع Identified فقط". مثل هذه القوائم تُسرد بأهداف دقيقة.
- تحمل بتات Codec السبع في Reference بتات Quantifier (`QQQ`). ويحدد الهدف Quantifier بدقة. ولقبول عدة Quantifier توضع عدة CODEC.

### علامة الموضع (الهدف `0000`~`0002`)

[علامة الموضع](/ar/grammar/reference/slot-marker/) هي حزمة سجلات من 1 WORD في Reference Codec المحجوز `0000`. أدنى 3 بتات هي رقم العلامة (وليست Quantifier).

| الهدف | العلامة | المعنى |
|---|---|---|
| `0000` | ABSENT | غير مكتوب. ذلك الحقل حقل اختياري |
| `0001` | UNKNOWN-VALUE | غير معروف. يقبل تقرير أن القيمة موجودة |
| `0002` | NO-VALUE | لا شيء. يقبل تقرير أن لا قيمة |
| `0003`~`0007` | محجوز | |

- **قاعدة القبول:** تصح العلامة فقط إذا كانت WORD نفسها موجودة هدفاً دقيقاً في قائمة CODEC للحقل. الرمز الشامل وحقل السجل بلا CODEC ("أي سجل") لا يقبلان العلامات. والعلامة في موضع سجل HEAD وBODY وموضع Edge Id هي invalid.
- القائمة التي ليس فيها إلا أهداف علامات (علامة دائماً) invalid (تعميم لقاعدة القائمة التي فيها `0000` فقط). تُستخدم مع رمز شامل أو هدف دقيق (`0780` + `0000` = أي Reference أو حذفه).
- لا يمكن وضع هدف علامة في حقل القيمة الخام. فالقيمة الخام بلا TAG وعرضها محدد فلا موضع فيها لعلامة من 1 WORD.
- معنى العلامة تحدده مواصفة Codec التي تقبلها.

### الحقل الاختياري (الهدف `0000`)

- إذا وُضع الهدف `0000` في قائمة CODEC لحقل سجل فذلك الحقل **حقل اختياري**. وعند حذفه تُكتب في موضعه WORD واحدة هي `0x0000`. وهذا السجل من 1 WORD هو علامة الموضع ABSENT (غير مكتوب).
- `0x0000` هي Reference Codec `0000` (محجوز)، ورقم العلامة `000`، و`LLLL = 0000` (المجموع 1 WORD). لا تتداخل مع سجلات أخرى، والمفكك الذي لا يعرف المواصفة يتخطاها أيضاً كسجل من 1 WORD.
- الحقل الاختياري أيضاً يشغل موضعه دائماً. فعند الحذف يجب كتابة `0x0000` ولا يُترك الموضع فارغاً (وكذلك إن كان حقلاً أخيراً). لذلك للسجل الواحد كتابة واحدة فقط، ويتحدد التحليل بالموضع وحده. لا قيد على موضع الحقل الاختياري وعددهما وعلى تداخل قائمتي حقلين.
- ABSENT صالح في موضع الحقل الاختياري فقط. و`0x0000` في موضع سجل HEAD وBODY وموضع الحقل الإلزامي وموضع Edge Id هي invalid.
- الحذف يعني "غير مكتوب" لا "لا قيمة". لا يقرر شيئاً عن العالم. و"لا قيمة" تُكتب بـ NO-VALUE (`0002`). ومعنى الحذف (مثلاً: إذا لم يوجد هدف TAG فهو هذا الإصدار) تحدده مواصفة كل صيغة.

## التفسير والصلاحية

- الحقل هو Edge من نوع FIELD في المستند نفسه. ولا يوضع الهدف نفسه مرتين لحقل واحد.
- **حقل السجل (العرض 0)**: إذا لم يوجد CODEC قَبِل أي سجل ما عدا علامة الموضع. وإذا وُجد واحد فأكثر فهي قائمة مغلقة. يجب أن يكون سجل ذلك الحقل (Kind وCodec، ومعهما Quantifier في Reference) أحد عناصر القائمة، وإلا فذلك السجل لا يتبع المواصفة. وهذا يختلف عن ENUM التي هي قائمة مفتوحة.
- **حقل القيمة الخام (العرض n ≥ 1، أو الباقي `0xFFFF`)**: يوضع له CODEC بهدف دقيق واحد فقط (لا رمز شامل). وتلك القيمة الخام هي Payload تلك Value دون TAG. يعطي CODEC الـ Kind وCodec، ويعطي عرض FIELD الـ Length. وفي الرموز الزوجية/الفردية يحدد الرمز المحدَّد فردية عدد البايتات أو زوجيته. وإذا لم تتبع القيمة الخام قواعد تلك Value (ومنها الطول) فذلك السجل لا يتبع المواصفة.
- تُطابَق علامات الموضع بالأهداف الدقيقة في القائمة فقط. فإذا جاءت `0x0000` في موضع حقل اختياري (الهدف `0000`) فهو حذف. والسجلات الأخرى تُطابَق بقائمة تستثني أهداف العلامات.
- يمكن وضع CODEC وENUM معاً في حقل القيمة الخام. CODEC هو الصيغة وENUM هو اسم قيمة الرمز (مثلاً: rank بـ UNSIGNED-INTEGER مع ENUM لـ 0 و1 و2).
- يمكن ربط اسم بـ Edge Id الخاص بـ CODEC بـ BIND لكنه غير إلزامي.
- حقل "Reference أو Value" يُكتب بـ CODEC اثنين (`0780` و`0F80`).

## الطول

```
المجموع = 1 + N_len + N_id + N_field + 1 WORD   (6 WORD إذا كان كل من Edge Id والحقل معرّف LOCAL من 1 WORD)
```

## أمثلة

في مستند مواصفة LABEL `geul.org/label` يقبل حقل Object (FIELD #3) كلاً من UTF8-LANGUAGE-TEXT (زوجي/فردي) وLOCAL. وEdge Id من 7 إلى 9.

```
129E 0088 0007 0088 0003 084A
129E 0088 0008 0088 0003 084B
129E 0088 0009 0088 0003 0008
```

- TAG `129E` (Edge، وCodec `0x1E`، و`LLLL = 0101`، و6 WORD)، وEdge Id `0088 0007`، والحقل `0088 0003`، والهدف `084A`.
