DO est le Codec LINK qui écrit une relation du graphe TOULMIN. Sens : action exécutée quand le nœud est Active.

| Élément | Valeur |
|---|---|
| Nom | `DO` (BIND du document de spécification `DO`) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Document de spécification | `0x00000000/codecs/0x00001110/` (cible de DECLARE `1110`) |
| Section | 8 `1000` (Edge TOULMIN), décalage dans la section C = 17 |
| Kind | Edge · famille : TOULMIN, groupe : exécution, disposition : LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Description d'index | Action exécutée quand le nœud est Active |
| Côté Hugo | `edge/toulmin/link.md` |

## Disposition {#레이아웃}

La disposition est [LINK](_index.md#link) (ID, src, dst, flags, champs conditionnels, SPAN).

| Élément | Valeur |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | règle → FuncRef |

- dst est un FuncRef (REF(ALIAS, 0 si absent) + VerbCode 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE n'est pas employé (s'il est allumé, on refuse).
- Les champs communs (ID, REF, SPAN) et les règles numériques suivent [TOULMIN](_index.md#공통-필드).

## Document de Codec {#코덱-문서}

Le document de Codec porte un DECLARE (cible `1110`). Les champs conditionnels de la disposition LINK et la largeur de SPAN fixée par SOURCE ne peuvent pas être déclarés par FIELD ; la déclaration des champs est donc un problème ouvert ([TOULMIN](_index.md#열린-문제)).
