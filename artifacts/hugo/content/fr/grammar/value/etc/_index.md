Les autres formats numériques sont des formats d'Issuer de la famille NUMERIC. Ils se placent sous ADHOC (`0x0001`), numéros de format `0x0700`~`0x0704`.

- Il y a les complexes (COMPLEX64, COMPLEX128), les fractions normalisées (RATIONAL-I64), les intervalles fermés binary64 et les quaternions binary32.
