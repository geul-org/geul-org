DO הוא Codec מסוג LINK שכותב קשר בגרף TOULMIN. משמעות: פעולה שמבוצעת כשהצומת Active.

| פריט | ערך |
|---|---|
| שם | `DO` (BIND `DO` במסמך המפרט) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| מסמך מפרט | `0x00000000/codecs/0x00001110/` (יעד DECLARE `1110`) |
| קטע | 8 `1000` (Edge TOULMIN), היסט C בתוך הקטע = 17 |
| Kind | Edge · משפחה: TOULMIN, קבוצה: ביצוע, פריסה: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| תיאור באינדקס | פעולה שמבוצעת כשהצומת Active |
| בצד Hugo | `edge/toulmin/link.md` |

## פריסה {#레이아웃}

הפריסה היא [LINK](_index.md#link) (ID, src, dst, flags, שדות מותנים, SPAN).

| פריט | ערך |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | כלל → FuncRef |

- dst הוא FuncRef‏ (REF(ALIAS, או 0 אם אין) + VerbCode ב-WORD אחד) ([NODE](_index.md#필드)).
- F_FORCE אינו בשימוש (אם הוא מודלק, דוחים).
- השדות המשותפים (ID, REF, SPAN) והכללים המספריים נקבעים לפי [TOULMIN](_index.md#공통-필드).

## מסמך Codec {#코덱-문서}

מסמך ה-Codec מכיל DECLARE (יעד `1110`). את השדות המותנים של פריסת LINK ואת רוחב ה-SPAN שקובע SOURCE אי אפשר להצהיר באמצעות FIELD, ולכן הצהרת השדות היא בעיה פתוחה ([TOULMIN](_index.md#열린-문제)).

## דפים קשורים {#관련-페이지}

- [LINK](_index.md#link), [TOULMIN](_index.md)

## נוסח מקור של מסמך המפרט {#규격-문서-원문}

כך נראה מסמך המפרט `0x00000000/codecs/0x00001110/latest.geul` כשקוראים אותו באמצעות `geul show` (הספרות ההקסדצימליות באותיות גדולות).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
