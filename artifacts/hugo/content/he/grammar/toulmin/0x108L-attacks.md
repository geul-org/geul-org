## פריסה {#레이아웃}

הפריסה היא [LINK](_index.md#link) (ID, src, dst, flags, שדות מותנים, SPAN).

| פריט | ערך |
|---|---|
| TANGEUL | `don't X when Y` |
| src → dst | כלל → כלל. מקטין בהדרגה את הפסק בעוצמת התקיפה |

- dst הוא REF של צומת.
- F_FORCE (עוצמת התקיפה) משמש רק את ה-Codec הזה. ראו [עוצמת תקיפה](#공격-세기) להלן.
- השדות המשותפים (ID, REF, SPAN) והכללים המספריים נקבעים לפי [TOULMIN](_index.md#공통-필드).

## עוצמת תקיפה {#공격-세기}

עוצמת תקיפה (Force) מציינת באיזו חוזקה קשת ATTACKS אחת תוקפת את היעד. הטווח הוא 0~1, ואם אין F_FORCE היא 1.

- בפסק הדין, התרומה `(v+1)/2` של ערך פסק התוקף v מוכפלת בעוצמה F. תקיפת ראיית נגד (COUNTER) נכנסת כאיבר המכנה `F·(v+1)/2`, ותקיפת חריג (EXCEPT) נכנסת כשער `Π(1 − F·(v+1)/2)`. אם F הוא 0, התקיפה אינה משפיעה על הפסק.
- הערך נקבע לפי הכללים המספריים של [TOULMIN](_index.md#수치). המקודד מוחק אפסים בסוף המקדם (0.5 הוא `C=5, E=−1`, ו-1.0 הוא `C=1, E=0`). המפענח מקבל עד ארבע ספרות אחרי הנקודה.
- משטח שאינו מציין עוצמה (`don't X when Y`, `` `Y` 면 `X` 는 무효다`` — «אם Y, אז X בטל») מכבה את F_FORCE.
- משטח שמציין עוצמה (`` `Y` 면 `X` 를 0.5의 세기로 공격한다`` — «אם Y, תוקפים את X בעוצמה 0.5») מדליק את F_FORCE ונושא בו את הערך. גם כשכותבים 1, כמו `1.0의 세기로` («בעוצמה 1.0»), F_FORCE מודלק ונושא 1. כך משטח המקור חוזר כפי שהוא.
- עוצמת תקיפה היא ציר שונה מחוזק הצומת (Strict, Defeasible, Defeater). החוזק מוצמד לצומת, ועוצמת התקיפה לקשת ATTACKS.

### דוגמה לעוצמת תקיפה {#공격-세기-예시}

`` `Y` 면 `X` 를 0.5의 세기로 공격한다`` («אם Y, תוקפים את X בעוצמה 0.5»). Edge Id 5, התוקף Y הוא Edge Id 3, היעד X הוא Edge Id 2, רוחב SPAN הוא 1 WORD.

```
108D                  TAG WORD: Edge, Codec 0x108L (ATTACKS), סך הכול 14 WORD
0051 0005             ID      LOCAL 5
0051 0003             src     LOCAL 3 (Y, תוקף)
0051 0002             dst     LOCAL 2 (X, יעד)
0010                  flags   F_FORCE
0683 FFFF FFFF 0005   F_FORCE SIGNED-DECIMAL, E=−1, C=5 (0.5)
0040 001A             SPAN    בייט התחלה 0x40, מספר בייטים 0x1A
```

באותה קשת ללא ציון עוצמה, flags הוא `0000` ואין שדה F_FORCE. ה-TAG WORD הוא `1089` (סך הכול 10 WORD).

## מסמך Codec {#코덱-문서}

מסמך ה-Codec מכיל DECLARE (יעד `1080`). את השדות המותנים של פריסת LINK ואת רוחב ה-SPAN שקובע SOURCE אי אפשר להצהיר באמצעות FIELD, ולכן הצהרת השדות היא בעיה פתוחה ([TOULMIN](_index.md#열린-문제)).
