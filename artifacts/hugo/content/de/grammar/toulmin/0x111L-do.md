DO ist ein LINK-Codec, der eine Relation des TOULMIN-Graphen schreibt. Bedeutung: Aktion, die ausgeführt wird, wenn der Knoten Active ist.

| Eigenschaft | Wert |
|---|---|
| Name | `DO` (BIND `DO` des Spezifikationsdokuments) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Spezifikationsdokument | `0x00000000/codecs/0x00001110/` (DECLARE-Ziel `1110`) |
| Abschnitt | 8 `1000` (Edge TOULMIN), Offset im Abschnitt C = 17 |
| Kind | Edge · Familie: TOULMIN, Gruppe: Ausführung, Layout: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Indexbeschreibung | Aktion, die ausgeführt wird, wenn der Knoten Active ist |
| Hugo-Seite | `edge/toulmin/link.md` |

## Layout {#레이아웃}

Das Layout ist [LINK](_index.md#link) (ID, src, dst, flags, bedingte Felder, SPAN).

| Eigenschaft | Wert |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | Regel → FuncRef |

- dst ist ein FuncRef (REF(ALIAS, 0 falls nicht vorhanden) + VerbCode 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE wird nicht verwendet (ist es gesetzt, wird abgelehnt).
- Gemeinsame Felder (ID, REF, SPAN) und numerische Regeln folgen [TOULMIN](_index.md#공통-필드).

## Codec-Dokument {#코덱-문서}

Das Codec-Dokument enthält DECLARE (Ziel `1110`). Die bedingten Felder des LINK-Layouts und die vom SOURCE bestimmte SPAN-Breite lassen sich nicht mit FIELD deklarieren; die Felddeklaration ist daher ein offenes Problem ([TOULMIN](_index.md#열린-문제)).

## Verwandte Seiten {#관련-페이지}

- [LINK](_index.md#link), [TOULMIN](_index.md)

## Wortlaut des Spezifikationsdokuments {#규격-문서-원문}

So sieht das Spezifikationsdokument `0x00000000/codecs/0x00001110/latest.geul` aus, gelesen mit `geul show` (Hexadezimalwerte in Großbuchstaben).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
