DO adalah Codec LINK yang menulis relasi graf TOULMIN. Arti: aksi yang dilakukan jika node Active.

| Butir | Nilai |
|---|---|
| Nama | `DO` (BIND dokumen spesifikasi `DO`) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Dokumen spesifikasi | `0x00000000/codecs/0x00001110/` (target DECLARE `1110`) |
| Bagian | 8 `1000` (Edge TOULMIN), offset dalam bagian C = 17 |
| Kind | Edge · keluarga: TOULMIN, kelompok: eksekusi, layout: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Deskripsi indeks | Aksi yang dilakukan jika node Active |
| Sisi Hugo | `edge/toulmin/link.md` |

## Layout {#레이아웃}

Layout-nya adalah [LINK](_index.md#link) (ID, src, dst, flags, field bersyarat, SPAN).

| Butir | Nilai |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | aturan → FuncRef |

- dst adalah FuncRef (REF(ALIAS, 0 jika tidak ada) + VerbCode 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE tidak dipakai (ditolak jika aktif).
- Field umum (ID, REF, SPAN) dan aturan numerik mengikuti [TOULMIN](_index.md#공통-필드).

## Dokumen Codec {#코덱-문서}

Dokumen Codec memuat DECLARE (target `1110`). Field bersyarat layout LINK dan lebar SPAN yang ditentukan SOURCE tidak dapat dideklarasikan dengan FIELD, sehingga deklarasi field menjadi masalah terbuka ([TOULMIN](_index.md#열린-문제)).

## Halaman terkait {#관련-페이지}

- [LINK](_index.md#link), [TOULMIN](_index.md)

## Teks asli dokumen spesifikasi {#규격-문서-원문}

Tampilan dokumen spesifikasi `0x00000000/codecs/0x00001110/latest.geul` yang dibaca dengan `geul show` (heksadesimal huruf kapital).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
