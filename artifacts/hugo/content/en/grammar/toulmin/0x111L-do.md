DO is the LINK Codec that writes a relation of a TOULMIN graph. Meaning: an action performed if the node is Active.

| Item | Value |
|---|---|
| Name | `DO` (spec document BIND `DO`) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Spec document | `0x00000000/codecs/0x00001110/` (DECLARE target `1110`) |
| Section | 8 `1000` (Edge TOULMIN), offset within section C = 17 |
| Kind | Edge · family: TOULMIN, group: execution, layout: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Index description | An action performed if the node is Active |
| Hugo page | `edge/toulmin/link.md` |

## Layout {#레이아웃}

The layout is [LINK](_index.md#link) (ID, src, dst, flags, conditional fields, SPAN).

| Item | Value |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | rule → FuncRef |

- dst is a FuncRef (REF(ALIAS, 0 if none) + VerbCode 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE is not used (it is rejected if turned on).
- The common fields (ID, REF, SPAN) and the numeric rules follow [TOULMIN](_index.md#공통-필드).

## Codec document {#코덱-문서}

The Codec document holds a DECLARE (target `1110`). The conditional fields of the LINK layout and the SPAN width set by SOURCE cannot be declared with FIELD, so the field declaration is an open problem ([TOULMIN](_index.md#열린-문제)).
