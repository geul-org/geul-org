DO é um Codec LINK que escreve uma relação do grafo TOULMIN. Significado: ação executada quando o nó está Active.

| Item | Valor |
|---|---|
| Nome | `DO` (BIND do documento de especificação `DO`) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Documento de especificação | `0x00000000/codecs/0x00001110/` (alvo do DECLARE `1110`) |
| Seção | 8 `1000` (Edge TOULMIN), deslocamento dentro da seção C = 17 |
| Kind | Edge · família: TOULMIN, grupo: execução, layout: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Descrição no índice | ação executada quando o nó está Active |
| Lado Hugo | `edge/toulmin/link.md` |

## Layout {#레이아웃}

O layout é [LINK](_index.md#link) (ID, src, dst, flags, campos condicionais, SPAN).

| Item | Valor |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | regra → FuncRef |

- dst é um FuncRef (REF(ALIAS, 0 se não houver) + VerbCode de 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE não é usado (se estiver ligado, é rejeitado).
- Os campos comuns (ID, REF, SPAN) e as regras numéricas seguem [TOULMIN](_index.md#공통-필드).

## Documento do Codec {#코덱-문서}

O documento do Codec contém um DECLARE (alvo `1110`). Os campos condicionais do layout LINK e a largura do SPAN definida por SOURCE não podem ser declarados com FIELD; a declaração de campos é um problema em aberto ([TOULMIN](_index.md#열린-문제)).
