URI — это Value, хранящий ASCII-последовательность байт по грамматике RFC 3986 `URI = scheme ":" hier-part [ "?" query ] [ "#" fragment ]`. Поскольку scheme входит в значение, для интерпретации base URI не нужен.

## Раскладка

- Код: прямой код Value `0x44` (чётное число байт) и `0x45` (нечётное число байт). Семейство TEXT.
- Число байт определяется младшим битом Codec и числом WORD Payload: `2 × число WORD Payload − младший бит`; Byte Count не используется ([Value](/ru/grammar/value/)).

```
TAG WORD          0000 1LLL LCCC CCCC      Codec 0x44/0x45
[Length extension TAG] если всего 15 WORD и более
Payload WORD 1st ... Nth          байты URI / нулевой padding в конце
```

## Интерпретация и допустимость

- Последовательность байт должна соответствовать грамматике RFC 3986 `URI = scheme ":" hier-part [ "?" query ] [ "#" fragment ]`. Query и fragment могут присутствовать.
- Терминалы грамматики URI — символы US-ASCII. Допустимые ASCII-символы хранятся как есть, а percent-encoding octet использует форму `pct-encoded = "%" HEXDIG HEXDIG`. Не-ASCII символы нельзя вставлять напрямую как literal byte.
- `scheme` и `:` обязательны. Для относительных ссылок используйте [URI-RELATIVE-REF](/ru/grammar/value/text/uri-relative-ref/) (номера форматов IETF `0x8000` и `0x8001`).
- Production URI в RFC 3986 не допускает пустую строку. Запись из 0 byte недопустима.
- Внутри WORD первым идёт старший byte. Если число байт нечётное (нечётный код), неиспользуемый младший byte последнего WORD должен быть `00`.
- Число WORD Payload равно `ceil(число байт/2)`. Если код нечётный, а младший byte последнего WORD не `00`, значение отклоняется.

## Основание в стандартах

- Грамматика `URI`, символов URI и percent-encoding следует [RFC 3986, Uniform Resource Identifier (URI): Generic Syntax](https://www.rfc-editor.org/rfc/rfc3986).
- Пара чётного/нечётного кодов, нулевой padding, GEUL TAG/Length и размещение в 16-битных WORD — правила framing этого формата.

## Длина

- Всего — число WORD: TAG 1 WORD, Length extension TAG (если есть) и Payload. До 14 WORD используется прямая длина, от 15 WORD — расширенная длина `1110`/`1111`, и extension TAG тоже входит в общее число ([Length](/ru/grammar/record/)).

## Примеры

- `https://example.com/` — 20 байт ASCII (чётное число), поэтому используется `URI-EVEN` (`0x44`).
- Payload — 10 WORD: `6874 7470 733a 2f2f 6578 616d 706c 652e 636f 6d2f`.
- TAG 1 WORD и Payload 10 WORD дают всего 11 WORD, значит `LLLL=1010`. Целиком: `0D44 6874 7470 733a 2f2f 6578 616d 706c 652e 636f 6d2f`.

## GEUL Archive URI

`archive.geul.org` — неизменяемое хранилище содержимого, позволяющее GEUL ссылаться на крупное внешнее содержимое, например бинарные файлы и документы. Рекомендуемая форма адреса — `https://archive.geul.org/sha256/{digest}`. Одинаковая последовательность байт должна иметь один и тот же URI, а после публикации байты по этому URI изменять нельзя.

Value URI лишь указывает расположение или строку адреса внешнего содержимого и не гарантирует ни тождественность, ни неизменяемость самого объекта. Бинарные данные и текст, превышающие максимальный размер inline Value, можно задавать ссылкой на archive URI. В metadata сохранённого объекта нужно записывать следующее:

- исходный URI и время получения;
- SHA-256 и Byte Length;
- MIME type;
- идентификатор и версию лицензии;
- автора, источник и уведомления;
- URI основания лицензии и, при необходимости, копию этого основания на момент получения.

Допустимость получения определяется не тем, бесплатен ли доступ, а тем, подтверждено ли явно право на распространение. Необходимо соблюдать применимые условия лицензии: указание авторства, некоммерческое использование, запрет изменений, распространение на тех же условиях и т. п. Для документов и содержимого записывается явная лицензия, например Creative Commons, а для программного обеспечения по возможности используется SPDX License ID.

Даже если раздача прекращена из-за вопросов прав или исправления, на прежний URI нельзя помещать другие байты. Этот URI должен возвращать tombstone с причиной и временем прекращения, а исходный digest и журнал аудита должны сохраняться. Однако если юридическая обязанность запрещает хранить журнал аудита, она имеет приоритет.

Archive URI даёт и место доступа, и digest содержимого. Эти правила content-address и неизменяемости — политика профиля GEUL Archive, а общая грамматика Value URI не привязана к `archive.geul.org`.
