BIT-VECTOR — raw bit sequence с указанной длиной. Прямой код Value `0x080L`, семейство BINARY. Первые 2 Payload WORD — беззнаковое 32-битное число бит `N`, за ними следуют `ceil(N/16)` WORD.

| Пункт | Значение |
|---|---|
| Имя | `BIT-VECTOR` (BIND в документе спецификации `BIT-VECTOR`) |
| TAG ID | `0x080L` |
| Codec ID | `0x00000800` |
| Документ спецификации | `0x00000000/codecs/0x00000800/` (цель DECLARE `0800`) |
| Раздел | 4 `0100` (Value), смещение C внутри раздела = 0 |
| Kind | Value · семейство: BINARY |
| TAG WORD | `0000 1000 0000 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | Число бит, за которым N бит, сохранённых в порядке MSB-first |
| Сторона Hugo | `value/binary/bit-vector.md` |

## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([документ спецификации Codec](../codec-spec.md)).

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемый формат (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `bit-count` | #2 | простое значение, 2 WORD |  |  |
| 2 | `bits` | #3 | остаток, простое значение (`0xFFFF`) |  |  |

## Раскладка {#레이아웃}

```
TAG WORD          0000 1000 0000 LLLL      Codec 0x080L
[расширяющий Length TAG] если всего 15 WORD и более
Payload WORD 1st–2nd       Bit Count N (старшие 16 бит │ младшие 16 бит)
Payload WORD 3rd ... Nth   Payload bits, MSB-first
```

## Интерпретация и действительность {#해석과-유효성}

- `N` — значение, прочитанное из первых 2 Payload WORD как беззнаковое 32-битное целое в big-endian.
- Биты payload заполняются по порядку, начиная со старшего бита каждого WORD.
- Число payload WORD равно ровно `ceil(N/16)`, а неиспользуемые младшие биты последнего WORD должны быть нулевыми.
- При `N=0` payload WORD нет. Два WORD счётчика уже составляют Payload, поэтому правилу о минимуме Payload в 1 WORD это не противоречит.

## Статус формата {#형식-지위}

- Беззнаковое 32-битное число бит, порядок MSB-first и zero padding в последнем WORD — не ссылка на внешний отраслевой стандарт, а собственное обрамление (framing) GEUL.
- Представление определяет эта страница, включая правила GEUL TAG, Length и 16-битных WORD.

## Длина {#길이}

- Всего — число WORD: 1 WORD TAG, расширяющий Length TAG (если есть) и Payload. До 14 WORD используется прямая длина, от 15 WORD — расширенная длина `1110`·`1111`; расширяющий TAG также входит в общее число ([запись и TAG WORD](../record.md)).

## Примеры {#예시}

- Пустой bit vector: count `0000 0000`, payload нет, всего 3 WORD, `LLLL=0010`. Целиком: `0802 0000 0000`.
- Последовательность бит `101`: count `0000 0003`, payload `A000`, всего 4 WORD, `LLLL=0011`. Целиком: `0803 0000 0003 A000`.
