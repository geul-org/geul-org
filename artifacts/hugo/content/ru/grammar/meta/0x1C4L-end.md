## Поля (документ спецификации) {#필드-규격-문서}

В документе спецификации нет FIELD. Поля Payload не объявляются.

Запись, закрывающая документ.

## Раскладка {#레이아웃}

```
TAG WORD          0001 1100 0100 LLLL      Codec 0x1C4L
[Length — расширяющий TAG]
```

- Codec: Meta `0x1C4L`, класс структуры
- Payload: нет (1 WORD)
- Количество: по одному на документ, в самом конце

## Интерпретация и валидность {#해석과-유효성}

- Обязательна. Положение проверяется по длине [DOC](0x1C0L-doc-1word.md) (`DOC-*`).
- Если вход заканчивается без END, документ усечён. Считать ли содержимое усечённого документа действительным, решает политика декодера.
- После неё ничего не следует.

## Пример {#예시}

- `0x1C40`

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00001C40/latest.geul`, прочитанный командой `geul show` (16-ричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000001C4000000000
BODY
#1 DECLARE 0x1C40
#2 BIND #1 "END"
```
