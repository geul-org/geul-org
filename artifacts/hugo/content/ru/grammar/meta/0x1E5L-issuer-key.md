## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([Документ спецификации Codec](../codec-spec.md)).

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемый формат (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `algorithm` | #2 | простое значение 1 WORD |  | `0x0001` ed25519 |
| 2 | `key` | #3 | остаток, простое значение (`0xFFFF`) |  |  |

Объявляет открытый ключ Issuer с самостоятельной выдачей (16 WORD). Issuer ID = SHA-256("GEUL-ISSUER-v1" ‖ ID алгоритма ‖ открытый ключ) ([Issuer 16 WORD](../issuer.md#16-word-issuer)).

## Раскладка {#레이아웃}

```
TAG WORD          0001 1110 0101 LLLL      Codec 0x1E5L
[Length — расширяющий TAG]
ID алгоритма      1 WORD (0x0001 = Ed25519)
Открытый ключ     ширина, заданная алгоритмом (Ed25519 16 WORD)
```

- Codec: Meta `0x1E5L`, класс проверки
- Payload: простое значение (ID алгоритма + открытый ключ)
- Количество: может быть несколько (смена ключа)

## Интерпретация и валидность {#해석과-유효성}

- Поскольку это класс проверки, она исключается из хеша содержимого.
- Issuer на 2 и 4 WORD используют ключ, зарегистрированный на geul.org, поэтому им она не нужна.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00001E50/latest.geul`, прочитанный командой `geul show` (16-ричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000001E5000000000
BODY
#1 DECLARE 0x1E50
#2 FIELD #1 0x0001
#3 FIELD #1 rest
#4 ENUM #2 0x0001
#5 BIND #1 "ISSUER-KEY"
#6 BIND #2 "algorithm"
#7 BIND #3 "key"
#8 BIND #4 "ed25519"
```
