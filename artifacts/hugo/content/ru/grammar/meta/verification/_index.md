Класс проверки в Meta (старшие 3 бита `100`, Codec `0x40`~`0x4F`) содержит материал для оценки того, можно ли верить документу. Это открытый ключ самостоятельно выданного Issuer, подпись, подтверждение права на вклад, степень доверия и вердикт по всему документу.

- Класс проверки исключается из вычисления хеша содержимого. Поэтому хеш содержимого не меняется ни от того, что подпись лежит внутри документа, ни от добавления новых подписей (так же, как git `gpgsig`).
- Класс определяется по старшим 3 битам Codec, поэтому хеш можно вычислить без кодекбука.
- Вердикт на уровне узла или записи берёт на себя Edge `VERDICT` (`0x78`) из [TOULMIN](/ru/grammar/edge/toulmin/).
