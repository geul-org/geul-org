Указывает неизменяемое имя, данное версии (git annotated tag).

## Раскладка

```
TAG WORD          0001 1LLL L011 1001      Codec 0x39
[Length-расширенный TAG]
Имя               Value UTF8-TEXT-*
Цель              Value SHA-256-DIGEST либо маркер пропуска 0x0000 (необязательное поле). Если пропущен -- эта версия
```

- Codec: Meta `0x39`, класс родословной (`011`)
- Payload: встроенный Value (текст + необязательный хеш содержимого)
- Количество: может быть несколько

## Интерпретация и валидность

- Имя -- [UTF8-TEXT](/ru/grammar/value/text/utf8-text/), цель -- [SHA-256-DIGEST](/ru/grammar/value/binary/sha-256-digest/).
- Если цель пропущена (ABSENT `0x0000`, необязательное поле [CODEC](/ru/grammar/edge/codec/)), имя дано самому этому документу. Собственный хеш содержимого внутри себя записать нельзя. Спецификация geul.org `0x1839` -- это поле из двух записей: name (`0840`, `0841`) и target (`0861`, `0000`).
- Одно и то же имя не используется повторно для другой версии.

## Пример

- Имя `v1`, эта версия: `19B9 08C0 7631 0000`

## Открытые вопросы

- Нужен ли TAG при наличии ID версии (порядкового номера), и как разграничить роль с именем документа (`BIND`).
