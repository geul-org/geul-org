Указывает создателя документа. Им может быть человек, модель или движок правил.

## Раскладка

```
TAG WORD          0001 1LLL L011 0010      Codec 0x32
[Length-расширенный TAG]
Создатель         Reference (человек, модель, движок правил)
Версия            Value UTF8-TEXT либо маркер пропуска 0x0000 (необязательное поле)
```

- Codec: Meta `0x32`, класс родословной (`011`)
- Payload: встроенный Reference + текст версии (необязательно)
- Количество: может быть несколько

## Интерпретация и валидность

- Для модели вместе указывается версия модели.
- Если версия неизвестна или не указывается, её место опускается и пишется ABSENT (`0x0000`) (необязательное поле [CODEC](/ru/grammar/edge/codec/)). Спецификация geul.org `0x1832` -- это поле из двух записей: agent (без CODEC) и version (`0840`, `0841`, `0000`).
- Для версии исходников программы (коммита) точнее формат [TRANSFORMED-BY](/ru/grammar/meta/lineage/transformed-by/) (дайджест, обязателен). Версия в GENERATED-BY -- это то, что не является ID коммита, например имя и версия модели, записанные текстом.
- В опубликованных документах geul.org нет Reference, указывающих на физических лиц ([Issuer и публикация](/ru/grammar/issuer/#публикация-через-geulorg)). Указываются организации и Issuer. В порядке исключения указывать физическое лицо через [WIKIDATA-QID](/ru/grammar/reference/wikidata-qid/) разрешено.
