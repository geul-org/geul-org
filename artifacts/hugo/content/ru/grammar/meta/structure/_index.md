Класс структуры в Meta (старшие 3 бита `000`, Codec `0x00`~`0x0F`) задаёт границы и длину документа. Единица данных GEUL — один документ.

```
DOC-*                  ← начало HEAD
  Meta объявления, происхождения, родословной, проверки, политики и IMPORT
  SOURCE всего документа и его QUALIFIER
BODY                   ← начало BODY
  Reference, Value, Edge
END                    ← закрытие документа
```

- Каждый документ открывается через `DOC-1WORD/2WORD/4WORD` с указанием полной длины. По этой длине декодер может пропустить весь документ за один шаг.
- `BODY` и `END` — записи в 1 WORD без Payload. `END` обязателен.
- Документы не вкладываются друг в друга. Другие документы указываются через IMPORT.
- Если HEAD (Meta, SOURCE всего документа и его QUALIFIER) пуст, `BODY` опускается. `BODY` может быть указан в документе только один раз.

Полная структура документа описана в разделе [Документ](/ru/grammar/document/).
