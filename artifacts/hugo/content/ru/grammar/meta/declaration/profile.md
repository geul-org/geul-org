Объявляет профиль, применённый к документу. Те же записи интерпретируются по документам Codec, определённым профилем (например, при `tangeul-1.0` -- [TOULMIN](/ru/grammar/edge/toulmin/)).

## Раскладка

```
TAG WORD          0001 1LLL L001 0001      Codec 0x11
[Length-расширенный TAG]
Payload           Value UTF8-TEXT "<имя>-<major>.<minor>"
```

- Codec: Meta `0x11`, класс объявления (`001`)
- Payload: встроенный Value ([UTF8-TEXT](/ru/grammar/value/text/utf8-text/))
- Количество: не более одного

## Интерпретация и валидность

- Профиль с другим major отвергается. Различие в minor допускается (только добавочные изменения).
- Если профиля нет, документ читается только по базовой грамматике GEUL и спецификациям прямых кодов.

## Пример

- `tangeul-1.0`: `0x1B91 0x0B41 7461 6e67 6575 6c2d 312e 3000`

## Открытые вопросы

- Реестр имён профилей (geul.org) и правила имён.
- Указывать ли профиль по ID документа (IMPORT) или текстом.
