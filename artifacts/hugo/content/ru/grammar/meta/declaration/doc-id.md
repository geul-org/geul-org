Объявляет идентификатор этого документа. Он нужен, чтобы другие документы могли указывать на этот документ и на объекты в нём.

## Раскладка

```
TAG WORD          0001 1LLL L001 0010      Codec 0x12
[Length-расширенный TAG]
Документ          запись Reference DOC-POINTER. (Issuer, ID документа, версия 0)
```

- Codec: Meta `0x12`, класс объявления (`001`)
- Payload: один встроенный Reference [DOC-POINTER](/ru/grammar/reference/doc-pointer/) (Issuer, ID документа, версия 0)
- Количество: не более одного. Обязателен для документов, имя которых начинается с `0x`

## Интерпретация и валидность

- Payload -- ровно одна запись Reference `DOC-POINTER` (Issuer, ID документа, версия `0`). В качестве ID версии используется только `0`. Версии назначает не документ, а список версий. Quantifier -- `000`.
- Поэтому запись, указывающая на «этот документ», одинакова в DOC-ID, в Subject у [BIND](/ru/grammar/edge/bind/) в `documents.geul` и в ссылках из других документов.
- Один и тот же документ при любой версии имеет один и тот же `DOC-ID`. ID версии и хеш содержимого в документе не пишутся ([Версия](/ru/grammar/document/#версии)).
- Адресное имя берёт на себя описательный `BIND` в индексе имён `documents.geul` ([Адрес публикации и список версий](/ru/grammar/publishing/#имя-документа)), а заголовок для чтения человеком -- описательный [LABEL](/ru/grammar/edge/label/).
- Если его нет, документ безымянный, и на него можно указать только по хешу содержимого. Он нужен, чтобы другие документы могли указывать на LOCAL этого документа через указывающий Reference.
- Сторона, импортирующая документ, проверяет, что `DOC-ID` полученного документа совпадает с запрошенными Issuer и ID документа.
- Документ с ID `0x0000000000000000` -- это индексный документ определений терминов Issuer ([Issuer](/ru/grammar/issuer/)). Имя этого документа тоже начинается с `0x`, поэтому в нём есть DOC-ID (`DOC-POINTER` (Issuer, `0`, `0`)). Сам Issuer представляет [ISSUER-POINTER](/ru/grammar/reference/issuer-pointer/).
- Для документов под `.well-known/geul/`, имя которых начинается с `0x` (документы версий `<ID версии>.geul`, спецификационные документы), `DOC-ID` обязателен.
- Для документов, имя которых не начинается с `0x`, `DOC-ID` в порядке исключения не указывается: список версий `versions.geul` ([PUBLICATION](/ru/grammar/edge/publication/)), индекс имён документов `documents.geul`, индекс имён Issuer `issuers.geul` ([Адрес публикации и список версий](/ru/grammar/publishing/)). Хранилище по хешу содержимого `h/` -- копии перечисленных документов и следует оригиналу.
- Спецификационный документ Codec -- это документ GEUL Issuer `0x0000`. ID документа -- это TAG WORD Kind·Codec, расширенный до 4 WORD (`0x1018` → `0x0000000000001018`). Reference `0000` зарезервирован, поэтому ID документа не может быть `0` ([Спецификационный документ](/ru/grammar/codec-spec/)).

## Пример

- Issuer `0x0001`, документ `0x…0005`: `1C12 03B8 0001 0000 0000 0000 0005 0000 0000` (TAG Meta 1 + TAG Reference 1 + Issuer 1 + ID документа 4 + версия 2 = 9 WORD)
