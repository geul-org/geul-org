Класс объявлений Meta (старшие 3 бита `001`, Codec `0x10`~`0x1F`) -- это объявления, влияющие на интерпретацию. Объявления меняют правила интерпретации, поэтому их должен обрабатывать каждый декодер. Область действия объявления -- этот документ.

- `SPEC-VERSION` определяет, как читать остальные записи, поэтому содержит только целое число без встроенного Value. GEUL v1 -- это `0x0001` (запись `1890 0001`).
- `DOC-ID` -- это `DOC-POINTER` (Issuer, ID документа, версия `0`), указывающий на сам документ. Если его нет, документ безымянный, и на него можно указать только по хешу содержимого.
- Адресное имя документа в Meta не указывается. Его привязывает через описательный `BIND` индекс имён Issuer `documents.geul`, а заголовок для чтения человеком привязывается через `LABEL` ([Адрес публикации и список версий](/ru/grammar/publishing/#имя-документа)).
