Объявляет версию спецификации GEUL, которой следует документ. Это значение определяет, как читать остальные записи.

## Раскладка

```
TAG WORD          0001 1LLL L001 0000      Codec 0x10
[Length-расширенный TAG]
Payload           версия спецификации. v1 = 0x0001
```

- Codec: Meta `0x10`, класс объявления (`001`)
- Payload: сырое значение (unsigned целое наименьшей ширины)
- Количество: не более одного

## Интерпретация и валидность

- Не опирается на коды Value. Чтобы запись мог прочитать декодер любой версии, указывается только целое число без встроенного Value.
- Если версия неизвестна, декодер отвергает документ или выдаёт предупреждение.
- Если записи нет, документ читается по версии, известной декодеру. Опубликованные документы её указывают.

## Пример

- `0x1890 0x0001`: GEUL v1
