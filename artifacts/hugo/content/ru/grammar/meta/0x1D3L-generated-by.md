## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([Документ спецификации Codec](../codec-spec.md)).

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемый формат (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `agent` | #2 | запись | любая запись (кроме маркера места) |  |
| 2 | `version` | #5 | запись | `0720` UTF8-TEXT-EVEN, `0730` UTF8-TEXT-ODD, `0000` ABSENT (необязательное поле) |  |

Указывает субъекта, создавшего документ. Это может быть человек, модель или движок правил.

## Раскладка {#레이아웃}

```
TAG WORD          0001 1101 0011 LLLL      Codec 0x1D3L
[Length — расширяющий TAG]
Субъект-создатель Reference (человек, модель, движок правил)
Версия            UTF8-TEXT Value либо маркер пропуска 0x0000 (необязательное поле)
```

- Codec: Meta `0x1D3L`, класс родословной
- Payload: встроенный Reference + текст версии (необязательно)
- Количество: может быть несколько

## Интерпретация и валидность {#해석과-유효성}

- Если это модель, вместе с ней указывается версия модели.
- Если версия неизвестна или не указывается, место пропускается и ставится ABSENT (`0x0000`) (необязательное поле [CODEC](../edge/0x0BEL-codec.md)). Спецификация geul.org `0x1D30` — это два поля-записи: agent (без CODEC) и version (`0720`, `0730`, `0000`).
- Для версии исходного кода программы (коммита) точнее формат [TRANSFORMED-BY](0x1D4L-transformed-by.md) (дайджест, обязателен). Версия в GENERATED-BY записывается текстом, если это не ID коммита, а, например, имя и версия модели.
- В документах, опубликованных на geul.org, Reference на физическое лицо не ставится ([Issuer и публикация](../issuer.md#geulorg-공표)). Указывается организация или Issuer. Исключение: указывать физическое лицо через [WIKIDATA-QID](../reference/0x014L-wikidata-qid.md) допускается.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00001D30/latest.geul`, прочитанный командой `geul show` (16-ричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000001D3000000000
BODY
#1 DECLARE 0x1D30
#2 FIELD #1 record
#3 BIND #1 "GENERATED-BY"
#4 BIND #2 "agent"
#5 FIELD #1 record
#6 BIND #5 "version"
#7 CODEC #5 0x0720
#8 CODEC #5 0x0730
#9 CODEC #5 0x0000
```
