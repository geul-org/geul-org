Разбираем от начала до конца небольшой документ об элементе Викиданных Q42 (Douglas Adams). Он содержит следующее.

- Английское имя: Douglas Adams
- Q42 — экземпляр человека (Q5) (P31).
- Q42 получил образование в St John's College (Q691283) (P69). Момент начала (P580) — 1971 год.

Документ — это документ `0x510000000000002A` Issuer `0x00000001`, всего 63 WORD (126 байт).

## Целиком {#전체}

```
1C01 003F 1C51 0001 1C79 0418 0000 0001 5100 0000 0000 002A 0000 0000
1C30
0A4E 0010 0051 0001 0141 002A 0799 0761 656E 446F 7567 6C61 7320 4164 616D 7300
0AA9 0051 0002 0191 001F 0141 002A 0141 0005 0000
0AAA 0051 0003 0191 0045 0141 002A 0142 000A 8C53 0000
0AB9 0051 0004 0191 0244 0051 0003 06E2 3139 3731
1C40
```

## HEAD {#head}

```
1C01 003F
```

`1C01` — Meta (раздел 14), Codec `0x1C0L` (DOC-1WORD), Length 2 WORD. Значение `003F` (63) — общее число WORD документа. По нему декодер заранее знает конец документа.

```
1C51 0001
```

Meta `0x1C5L` SPEC-VERSION. Редакция спецификации, которой следует документ. Для v1 это `0001`.

```
1C79 0418 0000 0001 5100 0000 0000 002A 0000 0000
```

Meta `0x1C7L` DOC-ID, всего 10 WORD. Payload — одна Reference типа DOC-POINTER.

| WORD | Значение |
|---|---|
| `0418` | Reference, Codec `0x041L` (DOC-POINTER), 9 WORD |
| `0000 0001` | Issuer `0x00000001` (2 WORD) |
| `5100 0000 0000 002A` | ID документа `0x510000000000002A` |
| `0000 0000` | версия `0` (сам документ) |

```
1C30
```

BODY. HEAD заканчивается, начинается BODY.

## BODY {#body}

### #1 LABEL — английское имя {#1-label--영어-이름}

```
0A4E 0010 0051 0001 0141 002A 0799 0761 656E 446F 7567 6C61 7320 4164 616D 7300
```

| WORD | Значение |
|---|---|
| `0A4E` | Edge, Codec `0x0A4L` LABEL, Length `1110` (расширенная) |
| `0010` | расширенная длина: всего 16 WORD |
| `0051 0001` | Edge Id: LOCAL 1 |
| `0141 002A` | Subject: Q42 Викиданных |
| `0799` | Object: UTF8-LANGUAGE-TEXT, нечётное число байт (`0x079L`), 10 WORD |
| `0761 656E` | язык: BCP 47 `en` |
| `446F … 7300` | `Douglas Adams`, 13 байт + заполнение `00` |

### #2 TRIPLE — Q42 — человек {#2-triple--q42는-사람이다}

```
0AA9 0051 0002 0191 001F 0141 002A 0141 0005 0000
```

| WORD | Значение |
|---|---|
| `0AA9` | Edge, Codec `0x0AAL` TRIPLE, 10 WORD |
| `0051 0002` | Edge Id: LOCAL 2 |
| `0191 001F` | Predicate: P31 (instance of) |
| `0141 002A` | Subject: Q42 |
| `0141 0005` | Object: Q5 (человек) |
| `0000` | Rank: normal |

### #3 TRIPLE — Q42 получил образование в St John's College {#3-triple--q42는-st-johns-college에서-교육받았다}

```
0AAA 0051 0003 0191 0045 0141 002A 0142 000A 8C53 0000
```

| WORD | Значение |
|---|---|
| `0AAA` | Edge, TRIPLE, 11 WORD |
| `0051 0003` | Edge Id: LOCAL 3 |
| `0191 0045` | Predicate: P69 (educated at) |
| `0141 002A` | Subject: Q42 |
| `0142 000A 8C53` | Object: Q691283. Значение не помещается в 16 бит, поэтому это Reference из 3 WORD |
| `0000` | Rank: normal |

### #4 QUALIFIER — момент начала, 1971 год {#4-qualifier--시작-시점-1971년}

```
0AB9 0051 0004 0191 0244 0051 0003 06E2 3139 3731
```

| WORD | Значение |
|---|---|
| `0AB9` | Edge, Codec `0x0ABL` QUALIFIER, 10 WORD |
| `0051 0004` | Edge Id: LOCAL 4 |
| `0191 0244` | Property: P580 (start time) |
| `0051 0003` | Target: #3 (TRIPLE выше) |
| `06E2 3139 3731` | Value: EDTF `1971` (точность до года, поэтому EDTF, а не GREGORIAN-DATE) |

Смысл #3 — это совокупность самого #3 и всех QUALIFIER, указывающих на #3: «Q42 с 1971 года получал образование в St John's College».

```
1C40
```

END. На этом заканчиваются 63 WORD.

## Чтение без кодовой книги {#코덱북-없이-읽으면}

Даже декодер, не знающий кодовой книги, знает следующее.

- Документ занимает 63 WORD; в HEAD 2 Meta, в BODY 4 Edge.
- Codec каждого Edge (LABEL, TRIPLE, TRIPLE, QUALIFIER) и Edge Id (1, 2, 3, 4).
- Положение следующей записи после каждой записи.

Роли компонентов (Predicate, Subject, Object, Rank) становятся известны только после чтения [документа спецификации](codec-spec.md) каждого Codec.
