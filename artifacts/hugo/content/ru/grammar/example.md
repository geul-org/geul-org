Прочитаем от начала до конца небольшой документ об элементе Викиданных Q42 (Douglas Adams). Он содержит следующее.

- Английское имя: Douglas Adams
- Q42 — экземпляр (instance of) человека (Q5) (P31).
- Q42 получил образование в St John's College (Q691283) (P69). Время начала (P580) — 1971 год.

Документ — это документ `0x510000000000002a` Issuer `0x00010000`, всего 63 WORD (126 байт).

## HEAD

```
1880 003f
```

`1880` — Meta (`11`), Length 2 WORD, Codec `0x00` (DOC-1WORD). Значение `003f` (63) — полное число WORD документа. По нему декодер заранее знает конец документа.

```
1890 0001
```

Meta `0x10` SPEC-VERSION. Версия спецификации, которой следует документ. Для v1 это `0001`.

```
1c92 0438 0001 0000 5100 0000 0000 002a 0000 0000
```

Meta `0x12` DOC-ID, всего 10 WORD. Payload — один Reference DOC-POINTER.

| WORD | Смысл |
|---|---|
| `0438` | Reference, 9 WORD, Codec `0111` (DOC-POINTER), Quantifier `000` |
| `0001 0000` | Issuer `0x00010000` (2 WORD) |
| `5100 0000 0000 002a` | ID документа `0x510000000000002a` |
| `0000 0000` | Версия `0` (сам документ) |

```
180e
```

BODY. HEAD закончился, начинается BODY.

## BODY

### #1 LABEL — английское имя

```
1704 0010 0088 0001 00a0 002a 0ccb 08c6 656e 446f 7567 6c61 7320 4164 616d 7300
```

| WORD | Смысл |
|---|---|
| `1704` | Edge, Length `1110` (расширенная), Codec `0x04` LABEL |
| `0010` | Расширенная длина: всего 16 WORD |
| `0088 0001` | Edge Id: LOCAL 1 |
| `00a0 002a` | Subject: Q42 в Викиданных |
| `0ccb` | Object: UTF8-LANGUAGE-TEXT, 10 WORD, нечётное число байтов (`0x4B`) |
| `08c6 656e` | Язык: BCP 47 `en` |
| `446f … 7300` | `Douglas Adams` 13 байтов + дополнение `00` |

### #2 TRIPLE — Q42 — человек

```
148a 0088 0002 00a8 001f 00a0 002a 00a0 0005 0000
```

| WORD | Смысл |
|---|---|
| `148a` | Edge, 10 WORD, Codec `0x0A` TRIPLE |
| `0088 0002` | Edge Id: LOCAL 2 |
| `00a8 001f` | Predicate: P31 (instance of) |
| `00a0 002a` | Subject: Q42 |
| `00a0 0005` | Object: Q5 (человек) |
| `0000` | Rank: normal |

### #3 TRIPLE — Q42 получил образование в St John's College

```
150a 0088 0003 00a8 0045 00a0 002a 0120 000a 8c53 0000
```

| WORD | Смысл |
|---|---|
| `150a` | Edge, 11 WORD, TRIPLE |
| `0088 0003` | Edge Id: LOCAL 3 |
| `00a8 0045` | Predicate: P69 (educated at) |
| `00a0 002a` | Subject: Q42 |
| `0120 000a 8c53` | Object: Q691283. Значение не помещается в 16 бит, поэтому это Reference в 3 WORD |
| `0000` | Rank: normal |

### #4 QUALIFIER — время начала: 1971 год

```
148b 0088 0004 00a8 0244 0088 0003 0924 3139 3731
```

| WORD | Смысл |
|---|---|
| `148b` | Edge, 10 WORD, Codec `0x0B` QUALIFIER |
| `0088 0004` | Edge Id: LOCAL 4 |
| `00a8 0244` | Property: P580 (start time) |
| `0088 0003` | Target: #3 (TRIPLE выше) |
| `0924 3139 3731` | Value: EDTF `1971` (точность до года, поэтому EDTF, а не GREGORIAN-DATE) |

Смысл #3 — это сам #3 вместе со всеми QUALIFIER, указывающими на #3: «Q42 с 1971 года получал образование в St John's College».

END. Вместе это 63 WORD.

## Если читать без кодекбука

Декодер, не знающий кодекбука, тоже знает следующее.

- Документ занимает 63 WORD; в HEAD 2 Meta, в BODY 4 Edge.
- Codec каждого Edge (LABEL, TRIPLE, TRIPLE, QUALIFIER) и Edge Id (1, 2, 3, 4).
- Положение следующей записи для каждой записи.

Роли компонентов (Predicate, Subject, Object, Rank) можно узнать, только прочитав [спецификацию](/ru/grammar/codec-spec/) каждого Codec.
