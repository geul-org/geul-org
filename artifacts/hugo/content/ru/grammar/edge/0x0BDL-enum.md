## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([документ спецификации Codec](../codec-spec.md)). Edge Id у Edge не объявляется через FIELD.

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемый формат (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `field` | #2 | запись | `0050` LOCAL |  |
| 2 | `code` | #3 | остаток простого значения (`0xFFFF`) |  |  |

ENUM — Edge-высказывание, придающий смысл одному кодовому значению поля простого значения. Codec `0x0BDL`.

Вместе с [FIELD](0x0BCL-field.md) это словарь для записи спецификации Codec. Раскладка встроена в декодер ([документ спецификации Codec](../codec-spec.md)).

## Раскладка {#레이아웃}

```
TAG WORD          0000 1011 1101 LLLL
[Length, расширяющий TAG]
Edge Id           запись LOCAL Reference
поле              запись LOCAL Reference, указывающая на Edge FIELD
кодовое значение  простое значение. Столько же WORD, сколько ширина этого FIELD
```

## Интерпретация и действительность {#해석과-유효성}

- Поле должно быть FIELD простого значения (ширина `n ≥ 1`). К полю-записи ENUM не прикрепляется. Смысл записи говорит Codec этой записи.
- Кодовое значение занимает ровно ширину этого FIELD. Граница проверяется по Length записи ENUM.
- В одном поле одно и то же кодовое значение дважды не объявляют.
- Имя кодового значения привязывается к Edge Id ENUM через [BIND](0x0A3L-bind.md). UTF8-TEXT, прикрепляемые к DECLARE, FIELD, ENUM и CODEC, все задаются через BIND и не прикрепляются другими Edge, например LABEL.
- Необъявленное кодовое значение не является ошибкой. Средство просмотра показывает простое значение как есть. Закрывать ли допустимые значения, решает спецификация Codec; в нынешнем словаре отметки закрытия нет.

## Длина {#길이}

```
всего = 1 + N_len + N_id + N_field + n WORD
```

## Пример (не нормативно) {#예시-비규범}

Для поля категории причины в документе спецификации TOMBSTONE (FIELD #4, простое значение 1 WORD) объявляется код `0x0001`. Edge Id 10. Имя привязывается отдельно через BIND. Таблица кодов категорий причин ещё не определена, поэтому кодовое значение — лишь пример.

- TAG 1 + Edge Id 2 + поле 2 + кодовое значение 1 = 6 WORD, `LLLL = 0101`.

```
0BD5 0051 000A 0051 0004 0001
```

В документе спецификации TRIPLE у поля Rank (FIELD #5) три ENUM (`0`·`1`·`2`), которые через BIND получают имена `normal`·`preferred`·`deprecated` ([TRIPLE](0x0AAL-triple.md)).

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000BD0/latest.geul`, прочитанный через `geul show` (16-ричные цифры в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000000BD000000000
BODY
#1 DECLARE 0x0BD0
#2 FIELD #1 record
#3 FIELD #1 rest
#4 BIND #1 "ENUM"
#5 BIND #2 "field"
#6 BIND #3 "code"
#7 CODEC #2 0x0050
```
