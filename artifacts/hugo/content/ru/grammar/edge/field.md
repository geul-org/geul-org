FIELD -- описательный Edge, который объявляет одно поле Payload Codec. Codec `0x1C`.

FIELD указывает на свой [DECLARE](/ru/grammar/edge/declare/). FIELD, указывающие на один DECLARE, образуют Payload в порядке документа. Раскладка встроена в декодер ([документ спецификации Codec](/ru/grammar/codec-spec/)).

## Раскладка

```
TAG WORD          0001 0LLL L001 1100
Edge Id           запись LOCAL Reference
DECLARE           запись LOCAL Reference. Edge DECLARE, которому принадлежит это поле
Ширина            1 WORD. 0 = запись, n (1~65534) = сырое значение n WORD, 0xFFFF = остаток сырого значения
```

## Интерпретация и допустимость

- DECLARE указывает на Edge DECLARE того же документа. Один FIELD принадлежит только одному DECLARE. Порядок отдельно не записывается, это порядок, в котором записи FIELD расположены в документе.
- Документ спецификации FIELD объявляет DECLARE как поле шириной `0` (запись), CODEC `0008` (LOCAL). Поэтому в графе просмотрщика связь FIELD → DECLARE рисуется как соединение.
- Ширина `0` -- поле-запись. Начинается с TAG WORD и читается на столько, сколько указывает Length этого TAG ([правила интерпретации DECLARE](/ru/grammar/edge/declare/)).
- Ширина `n` (1~65534) -- поле с сырым значением. Всегда ровно n WORD.
- Ширина `0xFFFF` -- остаток сырого значения. В DECLARE его ставят только одно, и оно может быть в начале, в середине или в конце. Его ширина -- число оставшихся WORD, заданное Length TAG внешней записи, за вычетом ширины последующих полей. Поэтому все поля после поля-остатка должны быть сырыми значениями фиксированной ширины (запись приходится читать с начала, чтобы узнать её конец). Может быть 0 WORD. ENUM не прикрепляют.
- Принимаемые полем Kind и Codec задаются через [CODEC](/ru/grammar/edge/codec/). Поле-запись без CODEC принимает любую запись, а при наличии CODEC должно соответствовать одному из них. Если на поле с сырым значением задан один CODEC, это сырое значение интерпретируется как этот Value без TAG.
- Имя поля привязывают к Edge Id FIELD через [BIND](/ru/grammar/edge/bind/) (например, `doc`, `hash`). Любой UTF8-TEXT к DECLARE, FIELD, ENUM и CODEC прикрепляют через BIND, а не через LABEL или другие Edge.
- Смысл кодов поля с сырым значением придают через [ENUM](/ru/grammar/edge/enum/).
- Поле, указывающее в графе на другой узел, отдельно не отмечается. Если поле-запись -- Reference, это и есть связь.

## Длина

```
всего = 1 + 2 + 2 + 1 WORD   (если Edge Id и DECLARE -- LOCAL ID в 1 WORD)
```

## Пример (ненормативный)

- Поле-запись: Edge Id 7, DECLARE #1, ширина `0`. TAG 1 + Edge Id 2 + DECLARE 2 + ширина 1 = 6 WORD. Чтобы принимался только LOCAL, смотрите пример [CODEC](/ru/grammar/edge/codec/).

```
129C 0088 0007 0088 0001 0000
```

- Поле с сырым значением, например хеш содержимого, смотрите в примере [DECLARE](/ru/grammar/edge/declare/).
