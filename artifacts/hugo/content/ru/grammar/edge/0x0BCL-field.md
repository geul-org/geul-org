## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([документ спецификации Codec](../codec-spec.md)). Edge Id у Edge не объявляется через FIELD.

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемый формат (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `declare` | #2 | запись | `0050` LOCAL |  |
| 2 | `width` | #3 | простое значение 1 WORD |  | `0x0000` record, `0xFFFF` rest |

FIELD — Edge-высказывание, объявляющий одно поле Payload Codec. Codec `0x0BCL`.

FIELD указывает на свой [DECLARE](0x0BBL-declare.md). FIELD, указывающие на один DECLARE, образуют Payload в порядке их расположения в документе. Раскладка встроена в декодер ([документ спецификации Codec](../codec-spec.md)).

## Раскладка {#레이아웃}

```
TAG WORD          0000 1011 1100 LLLL
Edge Id           запись LOCAL Reference
DECLARE           запись LOCAL Reference. Edge DECLARE, которому принадлежит это поле
ширина            1 WORD. 0 = запись, n (1~65534) = простое значение n WORD, 0xFFFF = остаток простого значения
```

## Интерпретация и действительность {#해석과-유효성}

- DECLARE указывает на Edge DECLARE в том же документе. Один FIELD принадлежит только одному DECLARE. Порядок отдельно не записывается: это порядок расположения записей FIELD в документе.
- Документ спецификации FIELD объявляет DECLARE как поле с шириной `0` (запись) и CODEC `0050` (LOCAL). Поэтому в графе средства просмотра связь FIELD → DECLARE рисуется как соединение.
- Ширина `0` — поле-запись. Оно начинается с TAG WORD и читается на Length этого TAG (правила интерпретации [DECLARE](0x0BBL-declare.md)).
- Ширина `n` (1~65534) — поле простого значения. Всегда ровно n WORD.
- Ширина `0xFFFF` — остаток простого значения. В DECLARE он один и может стоять в начале, в середине или в конце. Ширина — это оставшиеся WORD, заданные TAG Length внешней записи, за вычетом ширины следующих полей. Поэтому все поля после поля-остатка должны быть простыми значениями фиксированной ширины (запись можно прочесть только с начала, чтобы узнать её конец). Может быть 0 WORD. ENUM не прикрепляется.
- Принимаемые полем Kind·Codec указываются через [CODEC](0x0BEL-codec.md). Если у поля-записи нет CODEC, оно принимает любую запись, если есть — запись должна быть одной из них. Если у поля простого значения задан один CODEC, это простое значение интерпретируется как соответствующее Value без TAG.
- Имя поля привязывается к Edge Id FIELD через [BIND](0x0A3L-bind.md) (например, `doc`, `hash`). UTF8-TEXT, прикрепляемые к DECLARE, FIELD, ENUM и CODEC, все задаются через BIND и не прикрепляются другими Edge, например LABEL.
- Смысл кодовых значений поля простого значения прикрепляется через [ENUM](0x0BDL-enum.md).
- Поле, указывающее в графе на другой узел, отдельно не отмечается. Если поле-запись — Reference, это и есть связь.

## Длина {#길이}

```
всего = 1 + 2 + 2 + 1 WORD   (когда Edge Id и DECLARE — LOCAL с ID в 1 WORD)
```

## Пример (не нормативно) {#예시-비규범}

- Поле-запись: Edge Id 7, DECLARE #1, ширина `0`. TAG 1 + Edge Id 2 + DECLARE 2 + ширина 1 = 6 WORD. Чтобы принимался только LOCAL, смотрите пример [CODEC](0x0BEL-codec.md).

```
0BC5 0051 0007 0051 0001 0000
```

- Поле простого значения вроде хеша содержимого — смотрите пример [DECLARE](0x0BBL-declare.md).

```
#13 CODEC #2 0x0050
#3 FIELD #1 0x0001
#5 ENUM #3 0x0000
#6 ENUM #3 0xFFFF
#7 BIND #1 "FIELD"
#8 BIND #2 "declare"
#9 BIND #3 "width"
#11 BIND #5 "record"
#12 BIND #6 "rest"
```
