TRY — Codec группы ошибок исполняемых Edge. Значение: обработка ошибок.

| Пункт | Значение |
|---|---|
| Имя | `TRY` (BIND документа спецификации `TRY`) |
| TAG ID | `0x0F9L` |
| Codec ID | `0x00000F90` |
| Документ спецификации | `0x00000000/codecs/0x00000F90/` (цель DECLARE `0F90`) |
| Раздел | 7 `0111` (Edge, исполнение), смещение внутри раздела C = 25 |
| Kind | Edge · семейство: исполнение, группа: ошибки |
| TAG WORD | `0000 1111 1001 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в указателе | Обработка ошибок. BLOCK тела, символ ошибки, BLOCK обработки, BLOCK завершения (0 при отсутствии) |
| Страница Hugo | `edge/_index.md` |

## Компоненты {#구성요소}

BLOCK тела, символ ошибки, BLOCK обработки, BLOCK завершения (0 при отсутствии).

- Компоненты указываются LOCAL ID (REF) этого документа. REF `0` означает отсутствие. На месте выражения ставится выражение-Edge или символ ([Edge](_index.md#실행-edge)).
- Коды операторов, представление типов и раскладка Payload пока не определены ([Edge](_index.md#실행-edge), открытые проблемы).

## Документ Codec {#코덱-문서}

Раскладка пока не определена. Документ Codec содержит только DECLARE (цель `0F90`). FIELD добавляются после определения раскладки.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000F90/latest.geul`, прочитанный командой `geul show` (16-ричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000000F9000000000
BODY
#1 DECLARE 0x0F90
#2 BIND #1 "TRY"
```
