BLOCK — Codec группы операторов исполняемых Edge. Значение: упорядоченная группа операторов.

| Пункт | Значение |
|---|---|
| Имя | `BLOCK` (BIND документа спецификации `BLOCK`) |
| TAG ID | `0x0F0L` |
| Codec ID | `0x00000F00` |
| Документ спецификации | `0x00000000/codecs/0x00000F00/` (цель DECLARE `0F00`) |
| Раздел | 7 `0111` (Edge, исполнение), смещение внутри раздела C = 16 |
| Kind | Edge · семейство: исполнение, группа: операторы |
| TAG WORD | `0000 1111 0000 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в указателе | Упорядоченная группа операторов. Число операторов, оператор × число операторов |
| Страница Hugo | `edge/_index.md` |

## Компоненты {#구성요소}

Число операторов, оператор × число операторов.

- Компоненты указываются LOCAL ID (REF) этого документа. REF `0` означает отсутствие. На месте выражения ставится выражение-Edge или символ ([Edge](_index.md#실행-edge)).
- Коды операторов, представление типов и раскладка Payload пока не определены ([Edge](_index.md#실행-edge), открытые проблемы).

## Документ Codec {#코덱-문서}

Раскладка пока не определена. Документ Codec содержит только DECLARE (цель `0F00`). FIELD добавляются после определения раскладки.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000F00/latest.geul`, прочитанный командой `geul show` (16-ричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000000F0000000000
BODY
#1 DECLARE 0x0F00
#2 BIND #1 "BLOCK"
```
