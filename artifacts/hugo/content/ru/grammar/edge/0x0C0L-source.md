## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе задаёт порядок полей Payload ([документ спецификации Codec](../codec-spec.md)). Edge Id у Edge не объявляется как FIELD.

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемая форма (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `target` | #2 | запись | `0050` LOCAL |  |
| 2 | `origin` | #3 | запись | `000F` раздел 0 целиком (шаблон, Reference), `020F` раздел 1 целиком (шаблон, Reference), `040F` раздел 2 целиком (шаблон, Reference), `0010` UNKNOWN-VALUE, `0000` ABSENT (необязательное поле) |  |

SOURCE — Edge основания, связывающий одну запись (цель) или документ целиком с источником, из которого он взят. Codec `0x0C0L`. Единственный прямой код семейства основания (`01`).

Один reference Викиданных (набор источников) соответствует одному SOURCE. Если у одной записи несколько источников, SOURCE тоже несколько.

## Раскладка {#레이아웃}

```
TAG WORD          0000 1100 0000 LLLL
[расширяющий TAG Length]
Edge Id           LOCAL Reference, запись
Target            LOCAL Reference, запись (в BODY — Edge Id Edge, к которому присоединяется основание; в HEAD — 0 = документ целиком)
Origin            запись Reference либо маркер места 0x0000 ABSENT·0x0010 UNKNOWN-VALUE
```

- Origin указывает на источник. Если есть подходящий Reference, используется он (WIKIDATA-QID, DOC-POINTER или EXTERNAL-ISSUER документа GEUL и т. п.), иначе — узел LOCAL этого документа.
- Если источник не описывает происхождение (например, в Викиданных источник только с «imported from» (P143) или только с датой обращения), Origin равен [ABSENT](../slot-marker.md) (не записан). Пишущая сторона лишь не записала источник и ничего о нём не утверждает. Остальное содержимое источника остаётся в QUALIFIER.
- [UNKNOWN-VALUE](../slot-marker.md) используется, только когда пишущая сторона утверждает: «источник есть, но неизвестно, какой» (запись, сделанная человеком, и т. п.). Конвертер, переносящий исходные данные, не утверждает того, о чём источник молчит, поэтому использует ABSENT.
- Origin со значением ABSENT·UNKNOWN-VALUE независим при каждом появлении. Источники двух SOURCE не считаются одним и тем же.

## Два слоя {#두-층}

Сведения об источнике делятся на две части. Их не смешивают.

| Слой | Что | Как записывается | Пример |
|---|---|---|---|
| Источник | Свойства самого источника. Одинаковы для любого, кто его цитирует | [TRIPLE](0x0AAL-triple.md), где источник — Subject (rank normal) | URL (P854), название (P1476), автор (P50·P2093), дата публикации (P577), издание (P1433), издатель (P123), язык (P407) |
| Цитирование | Свойства акта, которым эта запись процитировала источник | [QUALIFIER](0x0ABL-qualifier.md), где Target — Edge Id SOURCE | дата обращения (P813), положение внутри источника (страница P304, раздел P958, внешний идентификатор P227·P1417), откуда взято (P143), метод вывода (P887), хеш оригинала (P4092) |

- **Смысл SOURCE — совокупность всех QUALIFIER, указывающих на его Edge Id.** Два источника, полученные обращением к одному и тому же источнику в разные дни, имеют один и тот же источник и разные QUALIFIER.
- TRIPLE источника — утверждение об источнике. Свойство, слой которого определить не удалось, помещается на сторону цитирования (QUALIFIER). Безопаснее ничего не утверждать об источнике.
- Один и тот же источник внутри документа объявляется один раз как один LOCAL, и на него указывают несколько SOURCE.
- Источник, описываемый одним лишь URL, определяется через [REFERENCE-NODE](0x0A0L-reference-node.md) (LOCAL → URI). Так же устроена страница документа sitelink.

## Интерпретация и действительность {#해석과-유효성}

- Target и Origin — по одной законченной записи. Курсор после чтения Origin должен совпасть с концом Edge.
- Target — LOCAL Reference. SOURCE в BODY указывает на Edge Id в BODY того же документа. `0` (документ целиком) используется только в SOURCE в HEAD ([источник документа целиком](#문서-전체의-출처)). SOURCE с Target `0` в BODY — invalid. Для записи другого документа основание присоединяется внутри того документа.
- Origin — Reference. Из маркеров места допускаются только `0x0000` (ABSENT) и `0x0010` (UNKNOWN-VALUE). NO-VALUE (`0x0020`) и Value не допускаются.
- Документ спецификации geul.org `0x00000000/codecs/0x00000C00` (имя `source`) задаёт для Target [CODEC](0x0BEL-codec.md) LOCAL (`0050`), для Origin — CODEC `000F`·`020F`·`040F` (любой Reference), `0000` (ABSENT, необязательно), `0010` (UNKNOWN-VALUE).
- Порядок среди SOURCE с одним Target значения не имеет. Порядок элементов внутри одного источника тоже не имеет значения (порядок значений одного свойства сохраняется как порядок документа).
- SOURCE не меняет истинность или ложность цели. Он лишь записывает, откуда цель взята. Результат вердикта определяет [TOULMIN](../toulmin/_index.md) `VERDICT`.

## Источник документа целиком {#문서-전체의-출처}

Источник документа целиком (исходный дамп, издание, файл оригинала) записывается как **SOURCE с Target `0` в HEAD**. QUALIFIER, нацеленные на этот SOURCE (хеш оригинала P4092, время получения P813, диапазон оригинала и т. п.), тоже помещаются в HEAD ([документ](../document.md#head와-body)).

- В HEAD можно поместить только эти два Edge. Остальные Edge помещаются в BODY.
- QUALIFIER в HEAD помещается после HEAD SOURCE, на который он указывает. Декодер читает с начала и отделяет HEAD от BODY.
- QUALIFIER, нацеленный на HEAD SOURCE, в BODY — invalid. SOURCE и QUALIFIER в BODY не указывают на Edge в HEAD.
- **Edge Id в HEAD и BODY используют одно пространство номеров.** Номер уникален внутри документа, как и для других Edge получается от [NEXT-LOCAL-ID](../meta/0x1DDL-next-local-id.md), а при повторном построении с тем же содержимым наследует тот же номер. Даже в версии без HEAD Edge его номер не используется повторно.
- Если Origin — LOCAL, его определение (REFERENCE-NODE, TRIPLE источника) помещается в BODY. Область LOCAL — документ целиком.
- HEAD Edge не относится к Meta класса проверки, поэтому входит в [хеш содержимого](../document.md#내용-해시). В diff он заменяется вместе с HEAD целиком (в `DELTA-REMOVE` не записывается).
- Отдельного Meta для источника документа целиком нет. Диапазон оригинала и время получения, записанные как Meta, при нескольких источниках не позволяют определить, к какому источнику они относятся. QUALIFIER, присоединённый к SOURCE, определяет это через Target.

Пример: HEAD документа Q42, перенесённого из дампа Викиданных (Edge Id для пояснения).

```
SPEC-VERSION  0x0001
DOC-ID        0x00000001/0x510000000000002A
TRANSFORMED-BY …
#1738 SOURCE     #0     #1735                                         версия (revision) сущности
#1741 SOURCE     #0     #1740                                         файл дампа
#1742 QUALIFIER  P4092  #1741  SHA-256-DIGEST(0xA249…0774)            хеш файла
#1743 QUALIFIER  P813   #1741  POSIX-TIMESTAMP-SECONDS(1792996483)    время получения
BODY
#1736 TRIPLE     P577   #1735  POSIX-TIMESTAMP-SECONDS(1792210885) normal                      время сохранения версии
#1737 TRIPLE     P854   #1735  <https://www.wikidata.org/w/index.php?oldid=2557857485> normal  постоянный адрес версии
#1739 REFERENCE-NODE    #1740  <https://dumps.wikimedia.org/wikidatawiki/entities/20261019/wikidata-20261019-all.json.bz2>
…
```

- Версия и дамп — разные источники, поэтому SOURCE два. Версия — источник содержимого (по постоянному адресу то же содержимое можно получить снова), дамп — файл, в котором эта версия получена. Хеш файла и время получения — свойства стороны цитирования, относящиеся к файлу дампа, поэтому присоединяются к SOURCE дампа.

## Выражение других оснований {#다른-근거의-표현}

В семействе основания есть только SOURCE. Другие основания записываются через QUALIFIER.

| Основание | Как записывается | Property |
|---|---|---|
| Диапазон внутри оригинала | QUALIFIER к SOURCE. Один SOURCE на один диапазон | страница P304, раздел P958, цитата P1683. Диапазон символов — термин GEUL (не определён) |
| Время получения исходных данных | QUALIFIER к SOURCE | дата обращения P813 |
| Хеш байтов оригинала (фиксация издания) | QUALIFIER к SOURCE | контрольная сумма P4092, значение — [SHA-256-DIGEST](../value/0x07CL-sha-256-digest.md) и т. п. |
| Создавший субъект (человек, модель, движок правил) | QUALIFIER к SOURCE (субъект, создавший цитирование) или к цели | термин GEUL (не определён) |
| Достоверность | QUALIFIER к цели | термин GEUL (не определён), значение от 0 до 1, как у Meta [CONFIDENCE](../meta/0x1E8L-confidence.md) |
| Срок действия по статьям | QUALIFIER к цели | начало P580, конец P582 |
| Прежняя запись до перемещения, разделения, объединения | QUALIFIER к цели, значение — прежний Edge Id (LOCAL) | P1365 (replaces) |
| Версия первого появления | Не хранится. Вычисляется по истории версий (git blame) | |

## Пример (ненормативный) {#예시-비규범}

Q42 P19 (место рождения) Q350, целевой TRIPLE `#178`. В дампе Викиданных от 2026-10-19 у этого утверждения пять источников, показаны три из них. ③ статья Telegraph (`#1358`–`#1367`) аналогична ②, а ⑤ Store norske leksikon (Q746368) — ①, поэтому опущены.

```
SOURCE     #1347  #178   Q5375741                     ① Britannica: без описания источника, один P248
QUALIFIER  #1348  P1417  #1347  "biography/Douglas-Adams"

TRIPLE     #1350  P50    #1349  Q18145749  normal     ② статья Guardian #1349
TRIPLE     #1351  P407   #1349  Q1860      normal
TRIPLE     #1352  P577   #1349  GREGORIAN-DATE(2001-05-15)  normal
TRIPLE     #1353  P854   #1349  <http://www.theguardian.com/news/2001/may/15/guardianobituaries.books>  normal
TRIPLE     #1354  P1433  #1349  Q5614018   normal
TRIPLE     #1355  P1476  #1349  "Obituary: Douglas Adams"@en  normal
SOURCE     #1356  #178   #1349
QUALIFIER  #1357  P813   #1356  GREGORIAN-DATE(2013-12-07)

SOURCE     #1368  #178   #1158                        ④ GND: LOCAL #1158, объявленный ранее (P248 Q36578, P407 Q188)
QUALIFIER  #1369  P227   #1368  "119033364"
QUALIFIER  #1370  P813   #1368  GREGORIAN-DATE(2022-10-09)
```

- В ① описания источника нет, а P248 один, поэтому источник — этот элемент. `#1347` — TAG 1 + Edge Id 2 + Target 2 + Q5375741 3 = 8 WORD, TAG `0C07`.

```
0C07 0051 0543 0051 00B2 0142 0052 06FD
```

- Источник из одного лишь URL: `REFERENCE-NODE #1383 #1384 <http://www.eskimo.com/~rkj/weekly/aa051701a.htm>`, `SOURCE #1385 #180 #1384`.
- Источник только с «imported from» английская Википедия: `SOURCE #n #t ABSENT`, `QUALIFIER P143 #n Q328`. Origin `0x0000` — 1 WORD.

## Открытые проблемы {#열린-문제}

- Термины GEUL для диапазона символов, создавшего субъекта и достоверности (документ определения термина и ID).
- Когда описание источника не идентифицирует источник (источник только с языком и т. п.), совместное использование одного описания через один LOCAL приведёт к утверждению, что разные источники одинаковы.
- Список свойств источника и цитирования для источников вне Викиданных (законы, веб-цитаты).
- Источник источника (цепочка): присоединять ли SOURCE снова к LOCAL источника.
