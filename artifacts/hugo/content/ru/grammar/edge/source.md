SOURCE — это Edge основания, который связывает одну запись (цель) или весь документ с первоисточником, из которого они взялись. Codec `0x20`. Единственный прямой код семейства оснований (`01`).

Один reference (набор источников) в Wikidata — это один SOURCE. Если у одной записи несколько источников, то и SOURCE несколько.

## Раскладка

```
TAG WORD          0001 0LLL L010 0000
[Length extension TAG]
Edge Id           запись LOCAL Reference
Target            запись LOCAL Reference (в BODY — Edge Id того Edge, к которому прикрепляется основание; в HEAD — 0 = весь документ)
Origin            запись Reference либо маркер слота 0x0000 ABSENT или 0x0001 UNKNOWN-VALUE
```

- Origin указывает на первоисточник. Если есть подходящий для первоисточника Reference, используется он (WIKIDATA-QID, DOC-POINTER или EXTERNAL-ISSUER документа GEUL и т. п.), иначе — узел LOCAL этого документа.
- Если источник не описывает первоисточник (например, источник, где есть только «imported from» (P143) Wikidata и дата обращения), Origin — [ABSENT](/ru/grammar/reference/slot-marker/) (не указан). Пишущая сторона просто не указала первоисточник и ничего о нём не утверждает. Остальное содержимое источника остаётся в QUALIFIER как есть.
- [UNKNOWN-VALUE](/ru/grammar/reference/slot-marker/) используется, только когда пишущая сторона утверждает «первоисточник есть, но какой — неизвестно» (например, запись, сделанная человеком). Конвертер, переносящий данные из исходного материала, не утверждает того, о чём исходный материал не говорит, поэтому использует ABSENT.
- Origin со значением ABSENT или UNKNOWN-VALUE независим при каждом появлении. Первоисточники двух SOURCE не считаются одинаковыми.

## Два слоя

Сведения об источнике делятся на две части. Их не смешивают.

| Слой | Что | Как записывать | Пример |
|---|---|---|---|
| Первоисточник | Свойства самого первоисточника. Одни и те же, кто бы ни цитировал | [TRIPLE](/ru/grammar/edge/triple/) с первоисточником в роли Subject (rank normal) | URL (P854), название (P1476), автор (P50, P2093), дата выпуска (P577), издание (P1433), издатель (P123), язык (P407) |
| Цитирование | Свойства акта, в котором эта запись процитировала первоисточник | [QUALIFIER](/ru/grammar/edge/qualifier/) с Edge Id SOURCE в роли Target | Дата обращения (P813), место внутри первоисточника (страница P304, раздел P958, внешние идентификаторы P227, P1417), откуда взято (P143), метод вывода (P887), хеш исходного текста (P4092) |

- **Смысл SOURCE — совокупность всех QUALIFIER, указывающих на его Edge Id.** Два источника, в которых один и тот же первоисточник просмотрен в разные дни, имеют один первоисточник и разные QUALIFIER.
- TRIPLE первоисточника — утверждение о первоисточнике. Свойство, слой которого определить не удаётся, помещают на сторону цитирования (QUALIFIER). Безопаснее ничего не утверждать о первоисточнике.
- Один и тот же первоисточник в документе объявляют одним LOCAL ровно один раз, и на него указывают несколько SOURCE.
- Первоисточник, описываемый одним лишь URL, определяют через [REFERENCE-NODE](/ru/grammar/edge/reference-node/) (LOCAL → URI). Так же, как документ страницы sitelink.

## Интерпретация и допустимость

- Target и Origin — каждый ровно одна полная запись. Позиция после чтения Origin должна совпасть с концом Edge.
- Target — LOCAL Reference. SOURCE в BODY указывает на Edge Id из BODY того же документа. `0` (весь документ) используется только у SOURCE в HEAD ([Источник всего документа](#источник-всего-документа)). SOURCE с Target `0` в BODY — invalid. Основание к записи другого документа прикрепляют внутри того документа.
- Origin — Reference. Из маркеров слота принимаются только `0x0000` (ABSENT) и `0x0001` (UNKNOWN-VALUE). NO-VALUE (`0x0002`) и Value не принимаются.
- Документ спецификации geul.org `0x0000/0x0000000000001020` (имя `source`) ставит на Target [CODEC](/ru/grammar/edge/codec/) LOCAL (`0008`), а на Origin — CODEC `0780` (любой Reference), `0000` (ABSENT, необязательно) и `0001` (UNKNOWN-VALUE).
- Порядок между SOURCE с одним Target не несёт смысла. Порядок элементов внутри одного источника тоже не несёт смысла (порядок значений одного свойства сохраняется порядком документа).
- SOURCE не меняет истинность или ложность цели. Он лишь записывает, откуда взята цель. Результат вердикта ведёт [TOULMIN](/ru/grammar/edge/toulmin/) `VERDICT`.

## Источник всего документа

Первоисточник всего документа (исходный дамп, издание, файл исходного текста) записывается как **SOURCE с Target `0` в HEAD**. QUALIFIER, у которых Target — этот SOURCE (хеш исходного текста P4092, время получения P813, диапазон в исходном тексте и т. п.), тоже помещаются в HEAD ([Документ](/ru/grammar/document/#head-и-body)).

- Edge, которые можно поместить в HEAD, — только эти два. Остальные Edge помещаются в BODY.
- QUALIFIER в HEAD ставится после того HEAD SOURCE, на который он указывает. Декодер читает документ с начала и разделяет HEAD и BODY.
- QUALIFIER, у которого Target — HEAD SOURCE, в BODY — invalid. SOURCE и QUALIFIER в BODY не указывают на Edge из HEAD.
- **HEAD и BODY используют одно пространство номеров Edge Id.** Edge Id уникален в пределах документа, берётся, как у других Edge, из [NEXT-LOCAL-ID](/ru/grammar/meta/lineage/next-local-id/), а при пересоздании с тем же содержимым номер наследуется. Даже в версии, где HEAD Edge пропал, его номер повторно не используется.
- Если Origin — LOCAL, его определение (REFERENCE-NODE, TRIPLE первоисточника) помещается в BODY. Область действия LOCAL — весь документ.
- HEAD Edge не является Meta класса проверки, поэтому входит в [хеш содержимого](/ru/grammar/document/#хеш-содержимого). В diff он заменяется целиком вместе с HEAD (в `DELTA-REMOVE` не указывается).
- Отдельной Meta для источника всего документа нет. Диапазон в исходном тексте и время получения, записанные как Meta, при нескольких первоисточниках не позволяют определить, к какому из них они относятся. QUALIFIER, прикреплённый к SOURCE, определяет это через Target.

Пример: HEAD документа Q42, перенесённого из дампа Wikidata (Edge Id условные).

```
SPEC-VERSION  0x0001
DOC-ID        0x00010000/0x510000000000002a
TRANSFORMED-BY …
#1738 SOURCE     #0     #1735                                         версия сущности (revision)
#1741 SOURCE     #0     #1740                                         файл дампа
#1742 QUALIFIER  P4092  #1741  SHA-256-DIGEST(0xa249…0774)            хеш файла
#1743 QUALIFIER  P813   #1741  POSIX-TIMESTAMP-SECONDS(1792996483)    время получения
BODY
#1736 TRIPLE     P577   #1735  POSIX-TIMESTAMP-SECONDS(1792210885) normal                      время сохранения версии
#1737 TRIPLE     P854   #1735  <https://www.wikidata.org/w/index.php?oldid=2557857485> normal  постоянный адрес версии
#1739 REFERENCE-NODE    #1740  <https://dumps.wikimedia.org/wikidatawiki/entities/20261019/wikidata-20261019-all.json.bz2>
…
```

- Версия и дамп — разные первоисточники, поэтому SOURCE два. Версия — первоисточник содержимого (по постоянному адресу то же содержимое можно получить снова), а дамп — файл, в котором эта версия получена. Хеш файла и время получения — свойства дампа на стороне цитирования, поэтому они прикрепляются к SOURCE дампа.

## Представление других оснований

В семействе оснований есть только SOURCE. Остальные основания записываются как QUALIFIER.

| Основание | Как записывать | Property |
|---|---|---|
| Диапазон внутри исходного текста | QUALIFIER к SOURCE. Один SOURCE на один диапазон | страница P304, раздел P958, цитата P1683. Диапазон символов — термин GEUL (не определён) |
| Время получения исходного материала | QUALIFIER к SOURCE | дата обращения P813 |
| Хеш байтов исходного текста (фиксация издания) | QUALIFIER к SOURCE | контрольная сумма P4092, значение — [SHA-256-DIGEST](/ru/grammar/value/binary/sha-256-digest/) и т. п. |
| Создавший субъект (человек, модель, движок правил) | QUALIFIER к SOURCE (субъект, создавший цитирование) или к цели | термин GEUL (не определён) |
| Достоверность | QUALIFIER к цели | термин GEUL (не определён), значение от 0 до 1, как у Meta [CONFIDENCE](/ru/grammar/meta/verification/confidence/) |
| Срок действия по статьям | QUALIFIER к цели | начало P580, конец P582 |
| Прежняя запись до перемещения, разделения, объединения | QUALIFIER к цели, значение — прежний Edge Id (LOCAL) | P1365 (replaces) |
| Версия, в которой запись появилась впервые | Не хранится. Вычисляется из истории версий (git blame) | |

## Пример (ненормативный)

Q42 P19 (место рождения) Q350, целевой TRIPLE `#178`. В дампе Wikidata от 2026-10-19 у этого утверждения пять источников; показаны три. ③ — статья Telegraph (`#1358`~`#1367`) — устроен так же, как ②, а ⑤ — Store norske leksikon (Q746368) — так же, как ①, поэтому они опущены.

```
SOURCE     #1347  #178   Q5375741                     ① Британика: без описания первоисточника, только P248
QUALIFIER  #1348  P1417  #1347  "biography/Douglas-Adams"

TRIPLE     #1350  P50    #1349  Q18145749  normal     ② статья Guardian #1349
TRIPLE     #1351  P407   #1349  Q1860      normal
TRIPLE     #1352  P577   #1349  GREGORIAN-DATE(2001-05-15)  normal
TRIPLE     #1353  P854   #1349  <http://www.theguardian.com/news/2001/may/15/guardianobituaries.books>  normal
TRIPLE     #1354  P1433  #1349  Q5614018   normal
TRIPLE     #1355  P1476  #1349  "Obituary: Douglas Adams"@en  normal
SOURCE     #1356  #178   #1349
QUALIFIER  #1357  P813   #1356  GREGORIAN-DATE(2013-12-07)

SOURCE     #1368  #178   #1158                        ④ GND: LOCAL #1158, объявленный ранее (P248 Q36578, P407 Q188)
QUALIFIER  #1369  P227   #1368  "119033364"
QUALIFIER  #1370  P813   #1368  GREGORIAN-DATE(2022-10-09)
```

- ① не описывает первоисточник, а P248 один, поэтому первоисточник — этот элемент. `#1347` — это TAG 1 + Edge Id 2 + Target 2 + Q5375741 3 = 8 WORD, TAG `13A0`.

```
13A0 0088 0543 0088 00B2 0120 0052 06FD
```

- Источник только с одним URL: `REFERENCE-NODE #1383 #1384 <http://www.eskimo.com/~rkj/weekly/aa051701a.htm>`, `SOURCE #1385 #180 #1384`.
- Источник только с «imported from» английской Википедии: `SOURCE #n #t ABSENT`, `QUALIFIER P143 #n Q328`. Origin `0x0000` — 1 WORD.

## Открытые вопросы

- Термины GEUL (документ определений терминов и ID) для диапазона символов, создавшего субъекта и достоверности.
- Когда описание первоисточника не позволяет его идентифицировать (источник только с языком и т. п.), общий для нескольких источников один LOCAL с таким описанием стал бы утверждением, что разные первоисточники одинаковы.
- Список свойств первоисточника и цитирования для источников вне Wikidata (законы, веб-цитаты).
- Источник источника (цепочка): нужно ли снова прикреплять SOURCE к LOCAL первоисточника.
