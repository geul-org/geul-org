## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([документ спецификации Codec](../codec-spec.md)). Edge Id у Edge не объявляется через FIELD.

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемый формат (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `subject` | #2 | запись | любая запись (кроме маркера места) |  |
| 2 | `object` | #3 | запись | любая запись (кроме маркера места) |  |

DIFFERENT-NODE — Edge-высказывание о нетождестве: две Reference указывают на разные референты. Codec `0x0A2L`.

Это не означает, что байтовое кодирование, Codec и ID двух записей Reference различаются. Его нужно отличать от направленной привязки [REFERENCE-NODE](0x0A0L-reference-node.md) и тождества [SAME-NODE](0x0A1L-same-node.md).

## Раскладка {#레이아웃}

```
TAG WORD          0000 1010 0010 LLLL
[Length, расширяющий TAG]
Edge Id           запись LOCAL Reference
Subject           1 запись Reference
Object            1 запись Reference
```

## Интерпретация и действительность {#해석과-유효성}

- Subject и Object должны быть каждый ровно одной полной записью [Reference](../reference/_index.md). Граница находится по Length каждой записи; если это Value или Edge либо запись неполна, она invalid.
- Subject и Object указывают на разные референты. Один лишь факт различия байтовых последовательностей, Codec или ID записей Reference не позволяет заключить, что референты различны.
- В частности, разные ID [LOCAL](../reference/0x005L-local.md) — это лишь разные Reference, но не значит, что различны и реальные референты. Из одной лишь разницы LOCAL ID DIFFERENT не выводится.
- Нетождество симметрично, иррефлексивно и не транзитивно. `DIFFERENT(A, B)` — то же отношение, что и `DIFFERENT(B, A)`. Однако из `DIFFERENT(A, B)` и `DIFFERENT(B, C)` не выводится `DIFFERENT(A, C)`.
- Порядок Subject/Object в wire — лишь порядок сериализации для framing и не создаёт смыслового направления. Реализация должна уметь обходить отношение в обе стороны.
- Курсор после чтения обоих компонентов должен точно совпасть с концом Edge.

Само отношение иррефлексивно, но структурно valid-утверждение `DIFFERENT(A, A)` или утверждение, где SAME и DIFFERENT сталкиваются, нельзя удалять как ошибку грамматики wire. Такие утверждения сохраняют контекст и родословную, а на уровне вердикта обрабатываются как противоречие. При интерпретации или выводе DIFFERENT сохраняются происхождение, момент времени, world и policy scope документа, содержащего этот Edge, и вывод не расширяется до глобального заключения, игнорирующего их.

## Длина {#길이}

```
всего = 1 + N_len + N_id + N_subject + N_object WORD
```

## Пример (не нормативно) {#예시-비규범}

Edge Id `000A`, Subject — LOCAL 1, Object — LOCAL 2.

- Edge — TAG 1 + Edge Id 2 + Subject 2 + Object 2 = 7 WORD, `LLLL=0110`. TAG — `0000 1010 0010 0110` = `0A26`.

```
0A26 0051 000A 0051 0001 0051 0002
```

Различие LOCAL ID в этом примере нужно лишь для демонстрации кодирования. Эта последовательность становится DIFFERENT-NODE только тогда, когда есть отдельное утверждение, что ID 1 и ID 2 указывают на разные референты.
