RAISE — Codec группы ошибок исполняемых Edge. Значение: возбуждение ошибки.

| Пункт | Значение |
|---|---|
| Имя | `RAISE` (BIND документа спецификации `RAISE`) |
| TAG ID | `0x0F8L` |
| Codec ID | `0x00000F80` |
| Документ спецификации | `0x00000000/codecs/0x00000F80/` (цель DECLARE `0F80`) |
| Раздел | 7 `0111` (Edge, исполнение), смещение внутри раздела C = 24 |
| Kind | Edge · семейство: исполнение, группа: ошибки |

## Компоненты {#구성요소}

Значение ошибки.

- Компоненты указываются LOCAL ID (REF) этого документа. REF `0` означает отсутствие. На месте выражения ставится выражение-Edge или символ ([Edge](_index.md#실행-edge)).
- Коды операторов, представление типов и раскладка Payload пока не определены ([Edge](_index.md#실행-edge), открытые проблемы).

## Документ Codec {#코덱-문서}

Раскладка пока не определена. Документ Codec содержит только DECLARE (цель `0F80`). FIELD добавляются после определения раскладки.
