SCENE — Edge-высказывание для записи структуры сцены. Смысл: структура сцены для описаний сценарного характера.

| Пункт | Значение |
|---|---|
| Имя | `SCENE` (BIND документа спецификации `SCENE`) |
| TAG ID | `0x0B2L` |
| Codec ID | `0x00000B20` |
| Документ спецификации | `0x00000000/codecs/0x00000B20/` (цель DECLARE `0B20`) |
| Раздел | 5 `0101` (Edge-высказывание), смещение C внутри раздела = 18 |
| Kind | Edge · семейство: высказывание, группа: структура |
| TAG WORD | `0000 1011 0010 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | Структура сцены для описаний сценарного характера |
| Сторона Hugo | `edge/_index.md` |

## Раскладка {#레이아웃}

```
TAG WORD          0000 1011 0010 LLLL      Codec 0x0B2L
[Length, расширяющий TAG]
TAG для Codec     1 WORD. Подформат
Edge Id           запись LOCAL Reference
компоненты        определяет подформат
```

- Это Codec с подформатами. Подформат указывает 1 WORD TAG для Codec ([запись и TAG WORD](../record.md#레코드-레이아웃)).
- Подформаты и компоненты пока не определены.

## Документ Codec {#코덱-문서}

Раскладка пока не определена. В документе Codec есть только DECLARE (цель `0B20`). FIELD добавляются, когда раскладка будет определена.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000B20/latest.geul`, прочитанный через `geul show` (16-ричные цифры в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000000B2000000000
BODY
#1 DECLARE 0x0B20
#2 BIND #1 "SCENE"
```
