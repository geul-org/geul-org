TYPE-DECLARE — Codec группы объявлений исполняемых Edge. Значение: объявление типа.

| Пункт | Значение |
|---|---|
| Имя | `TYPE-DECLARE` (BIND документа спецификации `TYPE-DECLARE`) |
| TAG ID | `0x0E2L` |
| Codec ID | `0x00000E20` |
| Документ спецификации | `0x00000000/codecs/0x00000E20/` (цель DECLARE `0E20`) |
| Раздел | 7 `0111` (Edge, исполнение), смещение внутри раздела C = 2 |
| Kind | Edge · семейство: исполнение, группа: объявления |
| TAG WORD | `0000 1110 0010 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в указателе | Объявление типа. Символ и состав (список символов полей, значения перечисления, цель псевдонима) |
| Страница Hugo | `edge/_index.md` |

## Компоненты {#구성요소}

Символ и состав (список символов полей, значения перечисления, цель псевдонима).

- Компоненты указываются LOCAL ID (REF) этого документа. REF `0` означает отсутствие. На месте выражения ставится выражение-Edge или символ ([Edge](_index.md#실행-edge)).
- Коды операторов, представление типов и раскладка Payload пока не определены ([Edge](_index.md#실행-edge), открытые проблемы).

## Документ Codec {#코덱-문서}

Раскладка пока не определена. Документ Codec содержит только DECLARE (цель `0E20`). FIELD добавляются после определения раскладки.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000E20/latest.geul`, прочитанный командой `geul show` (16-ричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x04260000000000000E2000000000
BODY
#1 DECLARE 0x0E20
#2 BIND #1 "TYPE-DECLARE"
```
