Маркер места (slot marker) — 1-WORD запись, занимающая место поля записи. Он ни на что не указывает. Это коды, назначенные первым трём позициям `0x000L~0x002L` раздела 0 Reference. У каждого маркера есть своя страница: [ABSENT](reference/0x000L-absent.md), [UNKNOWN-VALUE](reference/0x001L-unknown-value.md), [NO-VALUE](reference/0x002L-no-value.md).

На месте значения могут стоять три высказывания: значение не записано, значение есть, но неизвестно какое, значения нет. Это три разные вещи. Маркер места записывает их тремя соседними WORD.

## Макет {#레이아웃}

```
TAG WORD          0000 0000 00CC 0000
                  Prefix 000, раздел 0 (Reference), Codec 0~2, LLLL 0000 (1 WORD)
```

| WORD | Имя | Значение | Запись |
|---|---|---|---|
| `0x0000` | [ABSENT](reference/0x000L-absent.md) | не записано | `ABSENT` |
| `0x0010` | [UNKNOWN-VALUE](reference/0x001L-unknown-value.md) | неизвестно: значение есть, но неизвестно какое | `UNKNOWN` |
| `0x0020` | [NO-VALUE](reference/0x002L-no-value.md) | нет: значения нет | `NONE` |
| Codec 0~2, LLLL ≥ `0001` | Reserved | Эта форма TAG (маркер с Payload) не назначена | |

- У маркера **нет Quantifier.** Квантификация читается только в системе 5Q (`5 <= C < 30` в разделе 0, `C < 30` в разделе 1). `0x0010` UNKNOWN-VALUE не читается как `C % 5` и не интерпретируется как Generic ([Reference](reference/_index.md), Quantifier).
- Payload нет. Идентификатора цели тоже нет.
- Декодер без кодекбука по одному TAG WORD узнаёт, что это Kind Reference длиной 1 WORD, и пропускает его. Условие «WORD равен `0x0000`, `0x0010` или `0x0020` — маркер места» проверяется как `w & 0xF == 0 && w <= 0x0020`.
- Записи `ABSENT`, `UNKNOWN`, `NONE` — текстовая запись `geul show` и `geul add`.

## Три различия {#세-가지-구분}

| | Не записано (ABSENT) | Неизвестно (UNKNOWN-VALUE) | Нет (NO-VALUE) |
|---|---|---|---|
| О чём высказывание | **О документе**: это место не заполнено | **О мире**: значение есть, но неизвестно какое | **О мире**: значения нет |
| Логика | Ничего не утверждает | `∃x. P(s, x)`, x не идентифицирован | `¬∃x. P(s, x)` |
| Допущение о мире | Открытый мир (нет информации) | Существование замкнуто, личность открыта | Замкнутый мир для (s, P, ограничивающее условие) |
| Викиданные | Соответствующего snak нет | `somevalue` | `novalue` |
| Где применяется | Необязательное поле с целью CODEC `0000` (SOURCE Origin и др.) | Поле с целью CODEC `0010` (TRIPLE Object, QUALIFIER Value, SOURCE Origin) | Поле с целью CODEC `0020` (TRIPLE Object, QUALIFIER Value) |
| «Сколько у него детей (P40)» | Неизвестно | 1 или больше | 0 |
| «Есть ли момент окончания (P582)» | Неизвестно → неизвестно, действует ли ещё | Закончилось. Когда — неизвестно | Не закончилось (утверждение) |

То же различие действует и на уровне суждений. **Отсутствие TRIPLE в документе** — это «не записано». Документ GEUL — открытый мир, поэтому отсутствие утверждения не означает отсутствия факта. Сказать «нет» можно, только **записав** NO-VALUE.

## Правила приёма {#수용-규칙}

- Маркер места действителен, **только если тот же WORD есть в списке** [CODEC](edge/0x0BEL-codec.md) этого поля **как точная цель**. Цель `0000` означает «необязательное поле», `0010` — «принимает неизвестное», `0020` — «принимает отсутствие».
- Шаблоны (`000F`, `060F` и т. п., `L=1111`) маркер не принимают. Любой Reference (`000F`·`020F`·`040F`) тоже не пересекается с маркерами.
- Поле-запись без CODEC («любая запись») маркер тоже не принимает.
- Маркер на месте записи HEAD или BODY и на месте Edge Id недействителен.
- В поле с простым значением маркер использовать нельзя. У простого значения нет TAG, поэтому места для 1-WORD маркера нет.
- Список CODEC, состоящий только из целей-маркеров (всегда маркер), недействителен.
- Что маркер означает (что есть и чего нет), определяет спецификация Edge, принимающего этот маркер. Это тот же принцип: квантификацию и отрицание задаёт Edge, а не Reference.
- Значение маркера и правила приёма относятся к [уровню 0](publishing.md#층) (встроены в декодер). Payload у всех трёх нет, поэтому стоимости встраивания нет. Тем не менее для каждого кода заводится документ Codec. В документе Codec только DECLARE и нет FIELD.

## Обязанность читающей стороны {#읽는-쪽의-의무}

Для каждого маркера она записана на его странице. Суть такова.

- [UNKNOWN-VALUE](reference/0x001L-unknown-value.md#읽는-쪽의-의무) — не значение, а утверждение о существовании. Он не равен и не отличен ни от какого значения, и такие TRIPLE не объединяются как дубликаты.
- [NO-VALUE](reference/0x002L-no-value.md#읽는-쪽의-의무) замкнут в пределах ограничивающего условия этого суждения.
- К обоим маркерам rank применяется так же, а если маркер используется как значение QUALIFIER, он меняет смысл этого ограничения.
- [ABSENT](reference/0x000L-absent.md#읽는-쪽의-의무) ничего не говорит о мире. Значение, которое не удалось перенести, не записывается как UNKNOWN-VALUE.

## Отличие от других «нет» {#다른-없음과의-차이}

- Правило Codec, где [LOCAL](reference/0x005L-local.md) `0` означает «нет» (REF в [TOULMIN](toulmin/_index.md) и т. п.), — соглашение внутри этого Codec. Оно отличается от маркера места.
- Identified LOCAL не используется как null или sentinel. Чтобы записать «неизвестно» или «отсутствует», в поле, принимающем маркер места, ставится маркер.

## Пример {#예시}

Граница Q30 (США) – Q34266 (Российская империя), момент окончания неизвестен. Edge Id приведён для пояснения.

```
0AA9 0051 080C 0191 002F 0141 001E 0141 85DA 0000      #2060 TRIPLE P47 Q30 Q34266 normal
0AB7 0051 0C58 0191 0246 0051 080C 0010                #3160 QUALIFIER P582 #2060 UNKNOWN
```

Центрального банка Q30 в 1811–1816 годах не было.

```
0AA8 0051 0C59 0191 0518 0141 001E 0020 0000           #3161 TRIPLE P1304 Q30 NONE normal
0AB9 0051 0C5A 0191 0244 0051 0C59 06E2 3138 3131      #3162 QUALIFIER P580 #3161 EDTF("1811")
0AB9 0051 0C5B 0191 0246 0051 0C59 06E2 3138 3136      #3163 QUALIFIER P582 #3161 EDTF("1816")
```

- Место маркера — 1 WORD. TRIPLE занимает 9 WORD (`0AA8`), QUALIFIER — 8 WORD (`0AB7`).
- В простой форме «детей (P40) нет» записывается так: `0AA8 0051 <Edge Id> 0191 0028 <Subject> 0020 0000`.
