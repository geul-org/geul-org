ENTRY — NODE Codec, записывающий узел графа TOULMIN. Значение: внешняя точка входа. Выполняет дело или выносит по нему вердикт.

| Пункт | Значение |
|---|---|
| Имя | `ENTRY` (BIND `ENTRY` документа спецификации) |
| TAG ID | `0x115L` |
| Codec ID | `0x00001150` |
| Документ спецификации | `0x00000000/codecs/0x00001150/` (объект DECLARE `1150`) |
| Раздел | 8 `1000` (Edge TOULMIN), смещение внутри раздела C = 21 |
| Kind | Edge · семейство: TOULMIN, группа: выполнение, раскладка: NODE |
| TAG WORD | `0001 0001 0101 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | внешняя точка входа. Выполняет дело или выносит по нему вердикт |
| Сторона Hugo | `edge/toulmin/node.md` |

## Раскладка {#레이아웃}

Раскладка — [NODE](_index.md#node). Заголовок в 1 WORD задаёт role, level, форму Claim и условные поля.

| Пункт | Значение |
|---|---|
| TANGEUL | provides x |
| Узел | внешняя точка входа |

- role должен быть 0.
- Общие поля (ID, REF, SPAN) и числовые правила следуют [TOULMIN](_index.md#공통-필드).

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1150`). Условные поля раскладки NODE и ширину SPAN, задаваемую SOURCE, нельзя объявить через FIELD, поэтому объявление полей остаётся открытой проблемой ([TOULMIN](_index.md#열린-문제)).
