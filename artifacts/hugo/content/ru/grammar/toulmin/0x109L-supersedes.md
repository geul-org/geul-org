SUPERSEDES — LINK Codec, записывающий отношение графа TOULMIN. Значение: отношение отстранения. Если атакующий Active, цель детерминированно исключается из агрегирования. Цепочка (`A > B > C`) записывается по одному ребру на каждую пару.

| TAG ID | `0x109L` |

## Раскладка {#레이아웃}

Раскладка — [LINK](_index.md#link) (ID, src, dst, flags, условные поля, SPAN).

| Пункт | Значение |
|---|---|
| TANGEUL | `X supersedes Y` |
| src → dst | правило → правило. Если Active, исключает цель из агрегирования |

- Цепочка SUPERSEDES `A > B > C` записывается по одному SUPERSEDES на каждую пару. У сокращения [SUPERSEDE-CHAIN](0x10AL-supersede-chain.md) раскладки пока нет.
- F_FORCE не используется (если он включён, запись отклоняется).
- Общие поля (ID, REF, SPAN) и числовые правила следуют [TOULMIN](_index.md#공통-필드).

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1090`). Условные поля раскладки LINK и ширину SPAN, задаваемую SOURCE, нельзя объявить через FIELD, поэтому объявление полей остаётся открытой проблемой ([TOULMIN](_index.md#열린-문제)).
