PREDICATE-DECLARE — TOULMIN Codec, объявляющий предикат (формулу вердикта). Раскладка — EXPR. EXPR — раскладка для записи условных выражений из Rules в TANGEUL. Дерево условного выражения хранится развёрнутым в прямом порядке, а строки внутри выражения указываются через таблицу меток внутри записи. Поэтому запись самодостаточна и не требует записей TEXT.

| Пункт | Значение |

## Раскладка {#레이아웃}

```
ID                     запись LOCAL Reference (Edge Id)
Число узлов 1 WORD     общее число записей выражения
Число меток 1 WORD
Метка × число меток    запись UTF8-TEXT Value
Запись выражения × число узлов   в прямом порядке
```

- Метка — строка: имя поля, строковое значение, шаг пути, имя функции. Пустая строка тоже может быть меткой. Запись выражения указывает на метку индексом (1 WORD), нумерация с 0.
- Записи выражения идут так: родитель, затем его дочерние по порядку (прямой порядок). Число дочерних в каждой записи и этот порядок однозначно задают дерево.

## Запись выражения {#식-레코드}

Запись выражения начинается с заголовка в 1 WORD.

```
Заголовок 1 WORD      младшие 2 бита вида (b15–14) | старший 1 бит вида (b13) | число дочерних 13 бит (b12–0)
```

Вид = `(b13 << 2) | b15–14`.

| Вид | Имя | Число дочерних | После заголовка |
|---|---|---|---|
| 0 | COMPARE | 0 | оператор сравнения 1 WORD, метка поля 1 WORD, место значения |
| 1 | LOGIC | n | оператор логики 1 WORD |
| 2 | NOT | 1 | нет |
| 3 | EITHER | n | нет |
| 4 | EXISTS | 1 | оператор квантификации 1 WORD, операнд-объект, метка имени связывания 1 WORD |
| 5 | CALL | 0 | метка алиаса 1 WORD, метка имени функции 1 WORD |
| 6 | COMPARE-X | 0 | оператор сравнения 1 WORD, метка поля 1 WORD, левый признак 1 WORD [+ операнд], место значения |
| 7 | Reserved | | |

- Дочерние записи следуют после полей, идущих за заголовком. У EXISTS дочернее — одно условие.
- COMPARE — сравнение `<поле> <оператор> <значение>` без операндов с обеих сторон. Если операнд есть хотя бы с одной стороны, используется COMPARE-X.
- Если левый признак COMPARE-X равен `1`, за ним следует операнд, если `0` — нет. Если левый операнд есть, метка поля — пустая строка.
- CALL — вызов функции хоста на месте предиката. Если функция из этого документа, метка алиаса — пустая строка.

### Место значения {#값-자리}

```
Вид значения 1 WORD    0 число, 1 строка, 2 операнд
Значение               0: запись UNSIGNED-INTEGER Value
                       1: метка 1 WORD
                       2: операнд (только в COMPARE-X)
```

- Если строка значения в точности равна канонической десятичной записи неотрицательного целого, она записывается как UNSIGNED-INTEGER Value. Все остальные значения записываются меткой. Благодаря этому строка значения восстанавливается как есть.

### Операнд {#피연산자}

```
Вид операнда 1 WORD    0 путь, 1 ссылка на критерий, 2 вызов функции
Путь, ссылка на критерий   число шагов 1 WORD + метка 1 WORD × число шагов
Вызов функции          метка алиаса 1 WORD + метка имени функции 1 WORD
```

- Путь — путь во входных данных, ссылка на критерий — путь критерия (SPEC), внедрённого через `with`.

| Код | Оператор сравнения |

| `0x0304` | is in |
| `0x0305` | is greater than |
| `0x0306` | is less than |
| `0x0307` | is at most |
| `0x0308` | is at least |

| Код | Логический оператор |
|---|---|

|---|---|

### Вычисление при неизвестном входе {#미상-입력의-평가}

Если вход — маркер места, операторы сравнения вычисляются в трёхзначной логике (истина, ложь, неопределённо U). Для NO-VALUE `is empty` истинно, остальные сравнения ложны. Для UNKNOWN-VALUE `is not empty` истинно, а `equals`, `is in` и сравнения по величине дают U. Для ABSENT и отсутствия описания все операторы дают U. Логические операторы следуют сильной трёхзначной логике Клини, а если предикат даёт U, вердикт узла — Review. Это вычисление — неизменное ядро ([TOULMIN](_index.md#미상-위에서-판정하기)).

## Интерпретация и действительность {#해석과-유효성}

- Число узлов должно равняться числу развёрнутых записей выражения. Позиция после чтения последней записи выражения должна в точности совпадать с концом записи.
- Если индекс метки не меньше числа меток, запись отклоняется.
- Число дочерних у NOT и EXISTS должно быть 1.
- Неизвестный вид (7), неизвестный вид значения или вид операнда отклоняются.
- Число дочерних занимает 13 бит (максимум 8191).

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1010`). Раскладку EXPR нельзя объявить через FIELD, потому что предшествующие простые значения (число узлов, число меток) задают число повторений, поэтому объявление полей остаётся открытой проблемой (повтор [DECLARE](../edge/0x0BBL-declare.md#열린-문제)).
