DO — LINK Codec, записывающий отношение графа TOULMIN. Значение: действие, выполняемое, если узел Active.

| Пункт | Значение |
|---|---|
| Имя | `DO` (BIND `DO` документа спецификации) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Документ спецификации | `0x00000000/codecs/0x00001110/` (объект DECLARE `1110`) |
| Раздел | 8 `1000` (Edge TOULMIN), смещение внутри раздела C = 17 |
| Kind | Edge · семейство: TOULMIN, группа: выполнение, раскладка: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | действие, выполняемое, если узел Active |
| Сторона Hugo | `edge/toulmin/link.md` |

## Раскладка {#레이아웃}

Раскладка — [LINK](_index.md#link) (ID, src, dst, flags, условные поля, SPAN).

| Пункт | Значение |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | правило → FuncRef |

- dst — FuncRef (REF(ALIAS, 0 если нет) + VerbCode 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE не используется (если он включён, запись отклоняется).
- Общие поля (ID, REF, SPAN) и числовые правила следуют [TOULMIN](_index.md#공통-필드).

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1110`). Условные поля раскладки LINK и ширину SPAN, задаваемую SOURCE, нельзя объявить через FIELD, поэтому объявление полей остаётся открытой проблемой ([TOULMIN](_index.md#열린-문제)).
