ATTACKS — LINK Codec, записывающий отношение графа TOULMIN. Значение: отношение атаки. Вердикт атакующего постепенно уменьшает вердикт цели на силу атаки (0~1, по умолчанию 1).

## Раскладка {#레이아웃}

Раскладка — [LINK](_index.md#link) (ID, src, dst, flags, условные поля, SPAN).

| Пункт | Значение |
|---|---|
| TANGEUL | `don't X when Y` |
| src → dst | правило → правило. Постепенно уменьшает вердикт на силу атаки |

- dst — REF узла.
- F_FORCE (сила атаки) использует только этот Codec. См. [сила атаки](#공격-세기) ниже.
- Общие поля (ID, REF, SPAN) и числовые правила следуют [TOULMIN](_index.md#공통-필드).

## Сила атаки {#공격-세기}

Сила атаки (Force) показывает, насколько сильно одно ребро ATTACKS атакует цель. Диапазон 0~1, а если F_FORCE нет, то 1.

- В вердикте вклад `(v+1)/2` значения вердикта атакующего v умножается на силу F. Атака возражения (COUNTER) входит членом знаменателя `F·(v+1)/2`, атака исключения (EXCEPT) — вентилем `Π(1 − F·(v+1)/2)`. Если F равно 0, атака не влияет на вердикт.
- Значение следует числовым правилам [TOULMIN](_index.md#수치). Кодировщик отбрасывает конечные нули коэффициента (0.5 — это `C=5, E=−1`, 1.0 — `C=1, E=0`). Декодер принимает до четырёх знаков после запятой.
- Форма без указания силы (`don't X when Y`, `` `Y` 면 `X` 는 무효다`` (если `Y`, то `X` недействительно)) выключает F_FORCE.
- Форма с указанием силы (`` `Y` 면 `X` 를 0.5의 세기로 공격한다`` (если `Y`, то атаковать `X` с силой 0.5)) включает F_FORCE и записывает в него значение. Даже если 1 записана явно, как в `1.0의 세기로` (с силой 1.0), F_FORCE включается и в нём хранится 1. Поэтому исходная форма восстанавливается как есть.
- Сила атаки — другая ось, чем прочность узла (Strict, Defeasible, Defeater). Прочность относится к узлу, сила атаки — к ребру ATTACKS.

### Пример силы атаки {#공격-세기-예시}

`` `Y` 면 `X` 를 0.5의 세기로 공격한다`` (если `Y`, то атаковать `X` с силой 0.5). Edge Id 5, атакующий Y — Edge Id 3, цель X — Edge Id 2, ширина SPAN 1 WORD.

```
108D                  TAG WORD: Edge, Codec 0x108L (ATTACKS), всего 14 WORD
0051 0005             ID      LOCAL 5
0051 0003             src     LOCAL 3 (Y, атакующий)
0051 0002             dst     LOCAL 2 (X, цель)
0010                  flags   F_FORCE
0683 FFFF FFFF 0005   F_FORCE SIGNED-DECIMAL, E=−1, C=5 (0.5)
0040 001A             SPAN    начальный байт 0x40, число байтов 0x1A
```

У такого же ребра без указания силы flags равны `0000`, поля F_FORCE нет. TAG WORD — `1089` (всего 10 WORD).

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1080`). Условные поля раскладки LINK и ширину SPAN, задаваемую SOURCE, нельзя объявить через FIELD, поэтому объявление полей остаётся открытой проблемой ([TOULMIN](_index.md#열린-문제)).

