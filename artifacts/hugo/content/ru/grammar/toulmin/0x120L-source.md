SOURCE — запись исходного текста и разбиения документа TOULMIN. Значение: авторский исходный текст.

| Пункт | Значение |
|---|---|
| Имя | `SOURCE` (BIND `SOURCE` документа спецификации) |
| TAG ID | `0x120L` |
| Codec ID | `0x00001200` |
| Документ спецификации | `0x00000000/codecs/0x00001200/` (объект DECLARE `1200`) |
| Раздел | 9 `1001` (формат Edge TOULMIN), смещение внутри раздела C = 0 |
| Kind | Edge · семейство: формат TOULMIN, раскладка: ID, ширина SPAN WORD, UTF8 Value |
| TAG WORD | `0001 0010 0000 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | авторский исходный текст |
| Сторона Hugo | `edge/toulmin/source.md` |

## Раскладка {#레이아웃}

Весь авторский исходный текст. Все SPAN — диапазоны байтов внутри этого текста.

```
ID
Ширина SPAN WORD     старшие 2 бита = ширина (00=1, 01=2, 10=4, 11=8 WORD), остальные 14 бит = 0
Исходный текст       запись UTF8-TEXT Value
```

- SOURCE — первая запись BODY. В документе он один.
- SPAN состоит из двух полей: начального байта и числа байтов. Каждое поле — целое без знака шириной (1/2/4/8 WORD), заданной WORD ширины SPAN.
- Это не тот же Codec, что Edge основания [SOURCE](../edge/0x0C0L-source.md) (`0x0C0L`).

- ID — Edge Id, REF — Edge Id записи этого документа ([TOULMIN](_index.md#공통-필드), общие поля). Поля Issuer и номера Codec нет, Payload идёт сразу за TAG.

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1200`). Объявление полей определяется вместе со спецификацией Codec TOULMIN ([TOULMIN](_index.md#열린-문제)).

## Исходный текст документа спецификации {#규격-문서-원문}

Так выглядит документ спецификации `0x00000000/codecs/0x00001200/latest.geul`, прочитанный через `geul show` (шестнадцатеричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000120000000000
BODY
#1 DECLARE 0x1200
#2 BIND #1 "SOURCE"
```
