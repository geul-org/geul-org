UNDO — LINK Codec, записывающий отношение графа TOULMIN. Значение: компенсирующее действие для DO (saga). Если последующий шаг завершился неудачей, выполняется в обратном порядке.

| Пункт | Значение |
|---|---|
| Имя | `UNDO` (BIND `UNDO` документа спецификации) |
| TAG ID | `0x113L` |
| Codec ID | `0x00001130` |
| Документ спецификации | `0x00000000/codecs/0x00001130/` (объект DECLARE `1130`) |
| Раздел | 8 `1000` (Edge TOULMIN), смещение внутри раздела C = 19 |
| Kind | Edge · семейство: TOULMIN, группа: выполнение, раскладка: LINK |
| TAG WORD | `0001 0001 0011 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | компенсирующее действие для DO (saga). Если последующий шаг завершился неудачей, выполняется в обратном порядке |
| Сторона Hugo | `edge/toulmin/link.md` |

## Раскладка {#레이아웃}

Раскладка — [LINK](_index.md#link) (ID, src, dst, flags, условные поля, SPAN).

| Пункт | Значение |
|---|---|
| TANGEUL | `undo fn when n` |
| src → dst | правило → FuncRef |

- dst — FuncRef. `once` у UNDO записывается как F_ONCE в flags.
- F_FORCE не используется (если он включён, запись отклоняется).
- Общие поля (ID, REF, SPAN) и числовые правила следуют [TOULMIN](_index.md#공통-필드).

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1130`). Условные поля раскладки LINK и ширину SPAN, задаваемую SOURCE, нельзя объявить через FIELD, поэтому объявление полей остаётся открытой проблемой ([TOULMIN](_index.md#열린-문제)).

## Исходный текст документа спецификации {#규격-문서-원문}

Так выглядит документ спецификации `0x00000000/codecs/0x00001130/latest.geul`, прочитанный через `geul show` (шестнадцатеричные значения в верхнем регистре).

```

#2 BIND #1 "UNDO"
```
