PROSE — запись исходного текста и разбиения документа TOULMIN. Значение: абзац повествования.

| Пункт | Значение |
|---|---|
| Имя | `PROSE` (BIND `PROSE` документа спецификации) |
| TAG ID | `0x125L` |
| Codec ID | `0x00001250` |
| Документ спецификации | `0x00000000/codecs/0x00001250/` (объект DECLARE `1250`) |
| Раздел | 9 `1001` (формат Edge TOULMIN), смещение внутри раздела C = 5 |
| Kind | Edge · семейство: формат TOULMIN, раскладка: ID, SPAN |
| TAG WORD | `0001 0010 0101 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | абзац повествования |
| Сторона Hugo | `edge/toulmin/source.md` |

## Раскладка {#레이아웃}

Абзац повествования, а не правило. Указывает только на диапазон исходного текста (SPAN).

```
ID
SPAN             ширина, заданная SOURCE × 2 (начальный байт, число байтов)
```

- ID — Edge Id, REF — Edge Id записи этого документа ([TOULMIN](_index.md#공통-필드), общие поля). Поля Issuer и номера Codec нет, Payload идёт сразу за TAG.

## Документ Codec {#코덱-문서}

Документ Codec содержит DECLARE (объект `1250`). Ширину SPAN задаёт SOURCE, поэтому объявить её через FIELD нельзя, и объявление полей остаётся открытой проблемой ([TOULMIN](_index.md#열린-문제)).

Так выглядит документ спецификации `0x00000000/codecs/0x00001250/latest.geul`, прочитанный через `geul show` (шестнадцатеричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000125000000000
BODY

#2 BIND #1 "PROSE"
```
