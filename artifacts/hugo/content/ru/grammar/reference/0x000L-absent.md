ABSENT — [маркер места](../slot-marker.md), означающий «не указано». Это высказывание о документе: данное место не заполнено. О мире оно ничего не утверждает.

| Пункт | Значение |
|---|---|
| Имя | `ABSENT` (BIND `ABSENT` в документе спецификации) |
| TAG ID | `0x000L` |
| Codec ID | `0x00000000` |
| Документ спецификации | `0x00000000/codecs/0x00000000/` (цель DECLARE `0000`) |
| Раздел | 0 `0000` (сущность Reference), смещение внутри раздела C = 0 |
| Kind | Reference · классификация: маркер места |
| TAG WORD | `0000 0000 0000 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | Не указано. Необязательное поле опущено. О мире ничего не утверждается |
| Сторона Hugo | `reference/slot-marker.md` |

## Раскладка {#레이아웃}

```
TAG WORD          0000 0000 0000 0000      WORD 0x0000, 1 WORD
```

- Payload нет. Нет ни ID цели, ни Quantifier ([маркер места](../slot-marker.md#레이아웃)).
- Форма `0x000L` с Payload (L ≥ 1) — Reserved.
- Текстовая запись в `geul show` и `geul add`: `ABSENT`.

## Смысл {#뜻}

| Пункт | Не указано |
|---|---|
| О чём высказывание | **О документе**: это место не заполнено |
| Логика | Ничего не утверждается |
| Допущение о мире | Открытый мир (информации нет) |
| Викиданные | Соответствующего snak нет |

## Допустимость {#수용}

- Принимают только поля с целью CODEC `0000`. Такое поле — **необязательное**. Опуская необязательное поле, на его месте записывают один WORD `0x0000`. Необязательное поле тоже всегда занимает место ([документ спецификации Codec](../codec-spec.md#선택-필드와-자리-표지)). Примеры: Origin в [SOURCE](../edge/0x0C0L-source.md), единица, нижняя и верхняя границы в [QUANTITY](../value/0x066L-quantity.md).
- Нельзя использовать в шаблонах-подстановках (wildcard), в полях без CODEC, на местах записей HEAD и BODY, на месте Edge Id и в полях простых значений (общее правило [маркера места](../slot-marker.md#수용-규칙)).

## Обязанности читающей стороны {#읽는-쪽의-의무}

- **ABSENT ничего не говорит о мире.** Его не читают как UNKNOWN-VALUE или NO-VALUE.
- Записывать как UNKNOWN-VALUE значение, которое конвертер не смог перенести (в источнике оно есть), запрещено, ведь источнику значение известно. Место, о котором источник умолчал (например, Origin в [SOURCE](../edge/0x0C0L-source.md) для происхождения, не описанного в источнике), конвертер тоже записывает как ABSENT.
- В графе вердиктов для ABSENT и для отсутствия высказывания все операторы сравнения дают «не определено» (U). Чтобы читать ABSENT как empty, входная сторона должна объявить замкнутый мир ([TOULMIN](../toulmin/_index.md#미상-위에서-판정하기)).

## Пример {#예시}

`0x0000`, 1 WORD. Например, место единицы в QUANTITY, где единица не указана.

## Документ кодека {#코덱-문서}

В документе кодека есть только один DECLARE (цель `0000`). Payload нет, поэтому нет и FIELD. Декодер имеет смысл маркера и правила допустимости встроенными ([слой 0](../publishing.md#층)). Чтобы прочитать маркер, документ кодека не запрашивают.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000000/latest.geul`, прочитанный командой `geul show` (шестнадцатеричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000000000000000
BODY
#1 DECLARE 0x0000
#2 BIND #1 "ABSENT"
```
