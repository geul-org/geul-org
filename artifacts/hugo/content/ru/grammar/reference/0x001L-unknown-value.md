UNKNOWN-VALUE — [маркер места](../slot-marker.md), означающий «неизвестно». Это утверждение о мире: значение есть, но какое именно, неизвестно.

| Пункт | Значение |
|---|---|
| Имя | `UNKNOWN-VALUE` (BIND `UNKNOWN-VALUE` в документе спецификации) |
| TAG ID | `0x001L` |
| Codec ID | `0x00000010` |
| Документ спецификации | `0x00000000/codecs/0x00000010/` (цель DECLARE `0010`) |
| Раздел | 0 `0000` (сущность Reference), смещение внутри раздела C = 1 |
| Kind | Reference · классификация: маркер места |
| TAG WORD | `0000 0000 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | Неизвестно. Значение есть, но неизвестно какое (`somevalue` в Викиданных) |
| Сторона Hugo | `reference/slot-marker.md` |

## Раскладка {#레이아웃}

```
TAG WORD          0000 0000 0001 0000      WORD 0x0010, 1 WORD
```

- Payload нет. Нет ни ID цели, ни Quantifier ([маркер места](../slot-marker.md#레이아웃)).
- Форма `0x001L` с Payload (L ≥ 1) — Reserved.
- Текстовая запись в `geul show` и `geul add`: `UNKNOWN`.

## Смысл {#뜻}

| Пункт | Неизвестно |
|---|---|
| О чём высказывание | **О мире**: значение есть, какое — неизвестно |
| Логика | `∃x. P(s, x)`, x не идентифицирован |
| Допущение о мире | Существование закрыто, тождество открыто |
| Викиданные | `somevalue` |

## Допустимость {#수용}

- Принимают только поля с целью CODEC `0010`. Такое поле принимает утверждение «неизвестно». Примеры: Object в [TRIPLE](../edge/0x0AAL-triple.md), Value в [QUALIFIER](../edge/0x0ABL-qualifier.md), Origin в [SOURCE](../edge/0x0C0L-source.md).
- Нельзя использовать в шаблонах-подстановках (wildcard), в полях без CODEC, на местах записей HEAD и BODY, на месте Edge Id и в полях простых значений (общее правило [маркера места](../slot-marker.md#수용-규칙)).

## Обязанности читающей стороны {#읽는-쪽의-의무}

- **UNKNOWN-VALUE — не значение, а утверждение о существовании.** Он не равен никакому другому значению и не отличается от него (результат сравнения не определён). Два UNKNOWN-VALUE тоже не считаются одним и тем же значением. Каждое вхождение — независимая квантификация существования (как пустой узел в Викиданных).
- Поэтому два побайтово одинаковых TRIPLE (`P40 Q… UNKNOWN` ×2) не являются дубликатами. Детей может быть двое, а может быть один. TRIPLE с UNKNOWN-VALUE при удалении дубликатов не сливают.
- Когда личность позже выяснится, выпускают новую версию этого TRIPLE с исправлением. На UNKNOWN-VALUE нельзя сослаться. Если нужна общая ссылка, используют LOCAL Variable ([Reference](_index.md#quantifier) Variable).
- **Rank применяется так же.** При выборе представительного значения (truthy) TRIPLE с UNKNOWN-VALUE тоже входит в число кандидатов.
- **Если UNKNOWN-VALUE стоит значением QUALIFIER, он меняет смысл этого уточнения.** `P582 = UNKNOWN` означает, что оно закончилось, а момент неизвестен. Это не читают как утверждение, действующее и сейчас.
- UNKNOWN-VALUE — утверждение «есть», поэтому его пишут, только когда так говорит источник. Значение, которое не удалось перенести, как UNKNOWN-VALUE не записывают.

## Пример {#예시}

`0x0010`, 1 WORD. Например, момент окончания (P582) границы Q30–Q34266 неизвестен: `0AB7 0051 0C58 0191 0246 0051 080C 0010` (QUALIFIER, на месте Value стоит `0010`).

## Документ кодека {#코덱-문서}

В документе кодека есть только один DECLARE (цель `0010`). Payload нет, поэтому нет и FIELD. Декодер имеет смысл маркера и правила допустимости встроенными ([слой 0](../publishing.md#층)). Чтобы прочитать маркер, документ кодека не запрашивают.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000010/latest.geul`, прочитанный командой `geul show` (шестнадцатеричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000001000000000
BODY
#1 DECLARE 0x0010
#2 BIND #1 "UNKNOWN-VALUE"
```
