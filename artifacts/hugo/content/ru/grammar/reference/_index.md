Reference — запись, которая указывает на объект. Объектом может быть сущность, понятие, документ или другой Edge. Указание идёт по ID, а не по имени.

## Раскладка

```
TAG WORD          0000 0LLL LCCC CQQQ
[Length extension TAG]
[IMPORT ID]       для EXTERNAL-POINTER (1/2/4/8 WORD)
[Issuer]          для EXTERNAL-ISSUER (1/2/4/16 WORD)
[ID документа]    для EXTERNAL-ISSUER (4 WORD)
ID объекта        всё остальное
```

- `LLLL` — общее число WORD, включая TAG WORD, минус 1 ([Запись и TAG WORD](/ru/grammar/record/)).
- Codec — 4 бита `CCCC`, Quantifier — 3 бита `QQQ`. Младшие 7 бит TAG WORD — это `CCCC << 3 | QQQ`.
- ID объекта — беззнаковое целое в big-endian, записанное **наименьшей шириной**. Ширина — это остаток Length за вычетом предыдущих полей.
- ID объекта `0` записывается как 1 WORD `0x0000`. В остальных случаях WORD `0x0000` в начало не добавляется.
- Если целочисленные значения равны, ID один и тот же. Ширина не является частью ID.
- Все Codec используют наименьшую ширину. Codec не фиксирует ширину ID объекта.
- [ISSUER-POINTER](/ru/grammar/reference/issuer-pointer/) и [DOC-POINTER](/ru/grammar/reference/doc-pointer/) этой раскладке не следуют. У них нет ID объекта, есть только Issuer (а также ID документа и ID версии).

## Codec (`CCCC`)

| CCCC | Имя | Класс | Объект |
|---|---|---|---|
| `0000` | [Маркер слота](/ru/grammar/reference/slot-marker/) | зарезервирован | Ни на что не указывает. Используются только маркеры в 1 WORD, у которых младшие 3 бита — номер маркера: `0x0000` ABSENT (не записано), `0x0001` UNKNOWN-VALUE (неизвестно), `0x0002` NO-VALUE (нет) |
| `0001` | [LOCAL](/ru/grammar/reference/local/) | декларация | ID, выданный этим документом |
| `0010` | [GEUL](/ru/grammar/reference/geul/) | декларация | Сущность, выдаваемая geul.org |
| `0011` | [GEUL-SIDX](/ru/grammar/reference/geul-sidx/) | декларация | Семантически выровненный идентификатор, несущий смысл в битах |
| `0100` | [WIKIDATA-QID](/ru/grammar/reference/wikidata-qid/) | декларация | Элемент Wikidata. Целое число после `Q` |
| `0101` | [WIKIDATA-PID](/ru/grammar/reference/wikidata-pid/) | декларация | Свойство Wikidata. Целое число после `P` |
| `0110` | [ISSUER-POINTER](/ru/grammar/reference/issuer-pointer/) | указатель-декларация | Сам Issuer |
| `0111` | [DOC-POINTER](/ru/grammar/reference/doc-pointer/) | указатель-декларация | Одна версия документа, опубликованного Issuer |
| `1000`~`1011` | [EXTERNAL-POINTER-1/2/4/8WORD](/ru/grammar/reference/external-pointer/) | указатель | LOCAL ID документа, импортированного через IMPORT |
| `1100`~`1111` | [EXTERNAL-ISSUER-1/2/4/16WORD](/ru/grammar/reference/external-issuer/) | указатель-декларация | LOCAL ID документа, опубликованного Issuer |

- **Декларация** напрямую идентифицирует объект по ID, заданному выдавшей стороной.
- **Указатель** указывает на LOCAL внутри документа, импортированного по IMPORT ID. Младшие 2 бита — это ширина IMPORT ID (`00`=1, `01`=2, `10`=4, `11`=8 WORD).
- **Указатель-декларация** указывает на другой документ и объект в нём одной записью, без IMPORT.
- Если старший бит равен `0`, запись напрямую идентифицирует объект (LOCAL этого документа, выданный ID, сам Issuer или документ), если `1` — указывает на LOCAL другого документа.
- Codec `0000` зарезервирован и не используется как Reference, указывающий на объект. Исключение одно, набор: WORD `0x0000`~`0x0007` (Codec `0000`, 1 WORD) — это [маркеры слота](/ru/grammar/reference/slot-marker/). Сейчас используются три (`0x0000` ABSENT, `0x0001` UNKNOWN-VALUE, `0x0002` NO-VALUE). Маркер действителен только на месте поля записи, где этот WORD точно указан как объект CODEC. Поля-шаблоны (wildcard) и поля без CODEC маркер не принимают, а на месте записи HEAD·BODY и на месте Edge Id он invalid. `0x0003`~`0x0007` и Codec `0000` с Payload зарезервированы.
- Системы идентификации, не относящиеся к CC0 (WordNet и др.), Reference Codec не получают. В Reference нет и кода ISSUER, поэтому и перенести их в формат Issuer некуда.

## LOCAL

LOCAL — это ID, выданный этим документом. Имеет смысл только внутри документа.

- **Уникален.** В одном документе один LOCAL ID указывает только на один объект.
- **0 не назначается.** ID объектов назначаются начиная с 1.
- **Рекомендуется назначать по нарастающей** (auto increment). Величина ID смысла не несёт.
- Указывает на тот же объект во всех версиях. Удалённый ID повторно не используется ([Документ](/ru/grammar/document/), пересмотр).
- Чтобы на объект можно было указывать извне документа, в документе должен быть `DOC-ID`.
- Разные LOCAL ID не означают, что в реальности это разные объекты. Если они одинаковы, их связывают Edge `SAME-NODE`, если различны — Edge `DIFFERENT-NODE`.

### Edge Id

Первым элементом Payload любого Edge ставится LOCAL Reference. Этот LOCAL ID и есть **Edge Id**.

- Edge Id можно прочитать, не зная кодовой книги.
- LOCAL на месте Edge Id — декларация, а LOCAL на других местах Edge — упоминание.
- У LOCAL, объявляющего Edge Id, используется только Quantifier `000`.
- На другие Edge указывают по Edge Id. На Edge этого документа — через LOCAL, на Edge другого документа — через Reference-указатель.

## Указание на другие документы

| Что | Как |
|---|---|
| Сам Issuer | `ISSUER-POINTER` (Issuer) |
| Одна версия документа | `DOC-POINTER` (Issuer, ID документа 4 WORD, ID версии 2 WORD). Версия `0` — последняя |
| Объект в опубликованном документе (последняя версия) | `EXTERNAL-ISSUER-*` (Issuer, ID документа, LOCAL ID) |
| Объект в импортированном документе (версия зафиксирована) | Назначить IMPORT ID через Meta `IMPORT-DOC` и использовать `EXTERNAL-POINTER-*` (IMPORT ID, LOCAL ID) |

- На сам документ, изнутри или снаружи него, указывают только одним DOC-POINTER. Сам на себя документ указывает DOC-POINTER своего `DOC-ID`.
- EXTERNAL-ISSUER следует последней версии. Чтобы зафиксировать версию, используется IMPORT.
- Issuer записывается наименьшей шириной (1/2/4/16 WORD), в которую помещается значение, и выбирается Codec этой ширины.
- ID документа `0` у каждого Issuer зарезервирован под индексный документ терминов (инструментов, ролей и т. п.), определённых этим Issuer. Индексный документ рекомендуется для всех Issuer, но не обязателен ([Issuer и публикация](/ru/grammar/issuer/#документы-определения-терминов)).

Пример: LOCAL 7 в документе `0x0000000000000002` Issuer `0x0001`

```
0360 0001 0000 0000 0000 0002 0007
```

## Quantifier (`QQQ`)

| QQQ | Имя | Смысл | Пример |
|---|---|---|---|
| `000` | Identified | Идентифицированный объект | Илон Маск, Республика Корея |
| `001` | Generic | Общее утверждение о виде в целом. Допускает исключения | Солдат подчиняется приказу |
| `010` | Free-choice | Любой объект, удовлетворяющий условию | Любой солдат |
| `011` | Universal | Все объекты в области | Все солдаты |
| `100` | Variable | Дискурсивная переменная | тот человек, эта женщина |
| `101`~`111` | зарезервированы | | |

- **Исключение: в Codec `0000` (маркер слота) младшие 3 бита — не Quantifier, а номер маркера.** Номер маркера и смысл Quantifier никак не связаны (`0x0001` UNKNOWN-VALUE не есть Generic). Quantifier из этой таблицы относятся только к Codec `0001`~`1111`.
- Generic, в отличие от Universal, не означает применимость ко всем отдельным объектам без исключения. Определяющие выражения вроде «что такое солдат» можно записывать как Generic. Если нужно строгое определение понятия или классификации, оно уточняется отдельным отношением.
- Область действия квантификации и отрицание задаёт не Reference, а использующий его Edge.
- **Variable** — объект в дискурсе, вид которого известен, но который ещё не идентифицирован.
  - Именованная переменная — LOCAL с Variable. Один и тот же LOCAL ID — одна и та же переменная. Вид связывается через Edge.
  - Анонимная переменная — Variable, добавленный к Codec-декларации, указывающей на вид (GEUL, WIKIDATA-*) (например, «президент» в Wikidata + Variable). Кореференция не отслеживается, и снова указать на неё нельзя. Две анонимные переменные не считаются одной.
  - Когда объект позже подтверждается, переменная связывается с ним через `SAME-NODE`. Все выражения, указывающие на эту переменную, вместе разрешаются в этот объект.
  - Разные переменные не обязательно означают разные реальные объекты. Если они одинаковы, связываются `SAME-NODE`, если различны — `DIFFERENT-NODE`.
  - Переменная действует только в своём документе и как постоянный идентификатор не используется.
  - Variable во внешних Codec-указателях (EXTERNAL-POINTER-*, EXTERNAL-ISSUER-*) — это LOCAL-переменная документа, на который указывают.
  - Пример: если в «президент выступил» личность не установлена, используется Variable «президент». Чтобы упомянуть его снова, заводят LOCAL Variable и связывают с видом «президент» через Edge. Когда позже выяснится, что это Обама, переменная связывается с Identified «Обама» через `SAME-NODE`. Все выражения, указывающие на эту переменную, вместе разрешаются в Обаму.
- Пример: Wikidata Q5 (человек) как Generic — `00A1 0005` («человек …»).
