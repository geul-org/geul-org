## Члены {#구성원}

Эта страница охватывает один комплект системы 5Q — пять кодов. Квантификация определяется смещением внутри раздела `C % 5` ([Reference](_index.md#quantifier)). Документ кодека — по одному на код. Поля у пяти документов кодека одинаковы, различаются только цель DECLARE и имя (BIND).

| TAG ID | Имя | Квантификация | Codec ID | Документ спецификации | TAG WORD |
|---|---|---|---|---|---|
| `0x005L` | `LOCAL-IDENTIFIED` | Identified | `0x00000050` | `0x00000000/codecs/0x00000050/` | `0000 0000 0101 LLLL` |
| `0x006L` | `LOCAL-GENERIC` | Generic | `0x00000060` | `0x00000000/codecs/0x00000060/` | `0000 0000 0110 LLLL` |
| `0x007L` | `LOCAL-FREE-CHOICE` | Free-choice | `0x00000070` | `0x00000000/codecs/0x00000070/` | `0000 0000 0111 LLLL` |
| `0x008L` | `LOCAL-UNIVERSAL` | Universal | `0x00000080` | `0x00000000/codecs/0x00000080/` | `0000 0000 1000 LLLL` |
| `0x009L` | `LOCAL-VARIABLE` | Variable | `0x00000090` | `0x00000000/codecs/0x00000090/` | `0000 0000 1001 LLLL` |

## Поля (документ спецификации) {#필드-규격-문서}

Порядок FIELD в документе — это порядок полей Payload ([документ спецификации Codec](../codec-spec.md)).

| Порядок | Поле (BIND) | FIELD | Ширина | Принимаемая форма (CODEC) | ENUM |
|---|---|---|---|---|---|
| 1 | `local-id` | #2 | остаток, простое значение (`0xFFFF`) |  |  |

LOCAL — объявляющий Reference, указывающий на цель по ID, выданному этим документом. Он ссылается на цели внутри документа без внешнего Issuer. Чтобы указывать на цель извне документа, в документ помещают Meta [DOC-ID](../meta/0x1C7L-doc-id.md), и другие документы указывают на него указывающим Reference.

## Раскладка {#레이아웃}

```
TAG WORD          0000 0000 0101 LLLL      Codec 0x005L~0x009L (Identified 0x005L)
[расширяющий TAG Length]
LOCAL ID          unsigned big-endian наименьшей ширины
```

| LOCAL ID | Всего | TAG WORD (Identified) |
|---|---|---|
| `0..65535` | 2 WORD | `0x0051` |
| `65536..2^32-1` | 3 WORD | `0x0052` |
| `2^32..2^48-1` | 4 WORD | `0x0053` |
| `2^48..2^64-1` | 5 WORD | `0x0054` |

- Codec — `0x005L` (Identified), `0x006L` (Generic), `0x007L` (Free-choice), `0x008L` (Universal), `0x009L` (Variable). TAG WORD для Identified — `0000 0000 0101 LLLL`.
- Действует общее правило Reference: ID цели записывают наименьшим числом WORD.

## Edge Id {#edge-id}

- LOCAL, являющийся первым элементом Payload Edge, — это объявление Edge Id данного Edge ([Edge](../edge/_index.md)). Для объявления Edge Id используют только Identified (`0x005L`).
- LOCAL на любом другом месте Payload Edge — упоминание. Цель этого документа при каждом упоминании записывают как LOCAL. Отдельного указывающего кода для целей этого документа нет.

## Выдача идентификаторов {#식별자-할당}

- ID — целое число, назначаемое кодировщиком. Величина числа и порядок выдачи не имеют никакого смысла, кроме тождества.
- **UNIQUE (обязательно).** В одном документе один LOCAL ID указывает только на одну цель. Edge Id объявляется в документе только один раз (HEAD Edge и BODY Edge используют одно пространство номеров). Если один и тот же Edge Id объявляют два или более Edge, это invalid.
- **AUTO INCREMENT (рекомендуется).** Новый ID назначают как максимум из уже выданных в этом документе ID плюс 1, так что ID растут в порядке документа. То же и между версиями (новое создают со значением больше удалённого ID). Это лишь рекомендация, а не условие действительности; документ, где ID не растут, тоже valid. Декодер не полагается ни на величину ID, ни на их непрерывность.
- ID `0` не назначают. Он не указывает ни на какую цель и не используется как Edge Id. ID цели назначают начиная с `1`.
- На документ — и внутри этого документа, и снаружи — указывают только одним [DOC-POINTER](0x041L-doc-pointer.md) (на самого себя — DOC-POINTER на собственный `DOC-ID`). К документу тоже можно присоединять `BIND`, `LABEL` и Edge вердикта.
- На сам Issuer указывают через [ISSUER-POINTER](0x040L-issuer-pointer.md). Документ с ID `0` — индексный документ определений терминов Issuer.
- Codec, придающие смысл `0` на месте компонента («нет» в REF и исполняемом Edge [TOULMIN](../toulmin/_index.md), «документ целиком» в Target HEAD [SOURCE](../edge/0x0C0L-source.md#문서-전체의-출처)), следуют правилам этого Codec. Это договорённость внутри данного Codec, отличная от [маркера места](../slot-marker.md).
- Однажды назначенный ID в том же документе повторно не используют.
- Всегда используют наименьшую ширину, способную выразить значение.

## Тождество и область действия {#동일성과-범위}

- Если в одном документе целые значения LOCAL ID равны, это одна и та же цель. Ширина кодирования не входит в тождество.
- Identified LOCAL обозначает идентифицированную цель. Его не используют как анонимный, неопределённый, null или sentinel. Высказывания «значение есть, но неизвестно» (UNKNOWN-VALUE) и «значения нет» (NO-VALUE) записывают [маркером места](../slot-marker.md) в поле, принимающем такой маркер.
- Разные LOCAL ID — это лишь разные Reference; это не значит, что и цели в реальности различны.
- Тождество LOCAL не распространяют за пределы документа. Такое же число в другом документе ничего не значит.
- Variable (`0x009L`) LOCAL — именованная переменная дискурса ([Reference](_index.md) Variable).

## Слияние {#병합}

При слиянии нескольких документов в один для каждого исходного документа строят таблицу соответствия `old ID → new ID`, заново назначают все LOCAL ID по ID нового документа и заменяют все ссылки.

- ID, равные в одном исходном документе, должны оставаться равными и после слияния.
- Одинаковые числа из разных исходных документов ничего не значат и автоматически не сливаются в один Reference.
- Если остался хотя бы один LOCAL, который не удалось заменить, слияние отвергают.

## Действительность {#유효성}

Следующие кодирования и назначения invalid.

- Non-minimal кодирование с ведущим WORD `0x0000` (исключение — `0x0000`, 1 WORD для значения 0)
- Codec на месте объявления Edge Id не Identified (`0x005L`) или ID равен `0`
- Один ID назначен в одном документе разным целям
- Один и тот же Edge Id объявлен в одном документе два или более раз

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000050/latest.geul`, прочитанный командой `geul show` (шестнадцатеричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000005000000000
BODY
#1 DECLARE 0x0050
#2 FIELD #1 rest
#3 BIND #1 "LOCAL-IDENTIFIED"
#4 BIND #2 "local-id"
```

Выше — документ кодека `LOCAL-IDENTIFIED` (`0x005L`). У остальных членов (`LOCAL-GENERIC`, `LOCAL-FREE-CHOICE`, `LOCAL-UNIVERSAL`, `LOCAL-VARIABLE`) в документе кодека различаются только Codec ID в DOC-ID, цель DECLARE и имя, привязанное в `#1` (BIND).
