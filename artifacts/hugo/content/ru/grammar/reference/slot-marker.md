Маркер слота (slot marker) — запись в 1 WORD, заполняющая место поля записи. Ни на что не указывает. Размещается в зарезервированном Reference Codec `0000`.

На месте значения можно сказать три вещи: значение не записано; значение есть, но неизвестно, какое; значения нет. Это три разные вещи. Маркер слота разводит их на три соседних WORD.

## Раскладка

```
TAG WORD          0000 0000 0000 0MMM
                  Prefix 000, Kind 00 (Reference), LLLL 0000 (1 WORD), CCCC 0000, MMM = номер маркера
```

| WORD | Имя | Смысл | Запись |
|---|---|---|---|
| `0x0000` | ABSENT | не записано | `ABSENT` |
| `0x0001` | UNKNOWN-VALUE | неизвестно: значение есть. Какое — неизвестно | `UNKNOWN` |
| `0x0002` | NO-VALUE | нет: значения нет | `NONE` |
| `0x0003`~`0x0007` | зарезервированы | | |
| CCCC `0000`, LLLL ≥ `0001` | зарезервировано | Маркеры с Payload будут определены позже | |

- Младшие 3 бита `MMM` — **не Quantifier, а номер маркера**. Это место совпадает с `QQQ` других Reference Codec лишь по названию, а смысл с ним не связан ([Reference](/ru/grammar/reference/), исключение для Quantifier).
- Payload нет. ID объекта тоже нет.
- Декодер без кодовой книги по одному TAG WORD понимает, что это Kind Reference в 1 WORD, и пропускает его. Правило «WORD со значением `0`~`7` — маркер слота» проверяется одной битовой операцией (`w & 0xFFF8 == 0`).
- Записи `ABSENT`, `UNKNOWN`, `NONE` — текстовая запись в `geul show` и `geul add`.

## Три различия

| | не записано (ABSENT) | неизвестно (UNKNOWN-VALUE) | нет (NO-VALUE) |
|---|---|---|---|
| О чём это высказывание | **О документе**: это место не заполнено | **О мире**: значение есть. Какое — неизвестно | **О мире**: значения нет |
| Логика | Ничего не утверждает | `∃x. P(s, x)`, x не идентифицирован | `¬∃x. P(s, x)` |
| Допущение о мире | Открытый мир (нет информации) | Существование закрыто, идентичность открыта | Закрытый мир относительно (s, P, ограничивающие условия) |
| Wikidata | соответствующего snak нет | `somevalue` | `novalue` |
| Где применяется | Необязательное поле, где объектом CODEC указан `0000` (Origin у SOURCE и т. п.) | Поле, где объектом CODEC указан `0001` (Object у TRIPLE, Value у QUALIFIER, Origin у SOURCE) | Поле, где объектом CODEC указан `0002` (Object у TRIPLE, Value у QUALIFIER) |
| «Сколько детей (P40)» | неизвестно | 1 или больше | 0 |
| «Есть ли время окончания (P582)» | неизвестно → неизвестно, действует ли ещё | закончилось. Когда — неизвестно | не закончилось (утверждается) |

То же различие действует и на уровне высказывания. **Отсутствие TRIPLE в документе** — это «не записано». Документ GEUL — открытый мир, и отсутствие утверждения не означает отсутствие факта. «Нет» можно сказать только **записав** NO-VALUE.

## Правила приёма

- Маркер слота допустим, **только если тот же WORD точно указан как объект** в списке [CODEC](/ru/grammar/edge/codec/) этого поля. Объект `0000` означает «необязательное поле», `0001` — «принимает неизвестно», `0002` — «принимает нет».
- Поля-шаблоны (wildcard) (`0780`, `0781`, `0F80` и т. д.) маркер не принимают. Wildcard Reference также не пересекается с Codec `0000`.
- Поля записи без CODEC («любая запись») тоже маркер не принимают.
- Маркер на месте записи HEAD·BODY и на месте Edge Id invalid.
- В сыром поле маркер использовать нельзя. У сырого значения нет TAG, и места для маркера в 1 WORD нет.
- Список CODEC, состоящий только из объектов-маркеров (всегда маркер), invalid.
- Смысл маркера (что есть и чего нет) определяет спецификация Edge, принимающего этот маркер. Это тот же принцип, по которому квантификацию и отрицание задаёт не Reference, а Edge.
- У маркера слота нет документа спецификации Codec. Он относится к [слою 0](/ru/grammar/publishing/#уровни) (встроен в декодер). В DECLARE объект Reference оставляет место Quantifier нулевым, поэтому документ спецификации для `0x0001`·`0x0002` создать нельзя, а Payload у всех трёх нет, так что и стоимости встраивания нет.

## Обязанности читающей стороны

1. **UNKNOWN-VALUE — не значение, а утверждение существования.** Он не равен никакому другому значению и не отличается от него (результат сравнения неопределён). Два UNKNOWN-VALUE тоже не считаются одним и тем же значением. Каждое вхождение — независимая квантификация существования (как пустой узел в Wikidata).
   - Поэтому два TRIPLE с одинаковыми байтами (`P40 Q… UNKNOWN` ×2) не дубликаты. Детей может быть двое, а может один. TRIPLE с UNKNOWN-VALUE при дедупликации не сливаются.
   - Когда идентичность позже выясняется, выпускается новая версия исправленного TRIPLE. На UNKNOWN-VALUE указать нельзя. Если нужна кореференция, используется LOCAL Variable ([Reference](/ru/grammar/reference/), Variable).
2. **NO-VALUE замкнут в ограничивающих условиях этого высказывания.** Если добавлен QUALIFIER, он замкнут только в этом диапазоне. Q30 P1304 NO-VALUE (P580 1811, P582 1816) означает, что центрального банка не было только в 1811~1816 годах, и это не противоречит TRIPLE со значением того же свойства (Федеральная резервная система, preferred).
   - Если NO-VALUE и TRIPLE со значением для одних и тех же Subject·Predicate имеют одинаковый rank и ограничивающие условия не различены, это противоречие. Проверяющий выдаёт предупреждение. Не отклоняет. Такое состояние бывает и в Wikidata, а читающая сторона выбирает по rank.
3. **rank применяется так же.** При выборе представительного значения (truthy) TRIPLE с UNKNOWN-VALUE·NO-VALUE тоже попадают в кандидаты. Если есть preferred, остаётся только он.
4. **Если маркер используется как значение QUALIFIER, он меняет смысл этого ограничения.** При `P582 = UNKNOWN` действие закончилось, а время неизвестно. Высказывание не читается как действующее и сейчас. При `P582 = NONE` утверждается, что не закончилось. Если QUALIFIER P582 нет вовсе, неизвестно, закончилось ли.
5. **ABSENT ничего не говорит о мире.** Он не читается как UNKNOWN-VALUE или NO-VALUE. Наоборот, использовать UNKNOWN-VALUE для значения, которое конвертер не смог перенести (значение в источнике есть), запрещено, потому что в источнике значение известно. Место, о котором источник ничего не говорит (например, Origin у [SOURCE](/ru/grammar/edge/source/) для источника, не описывающего первоисточник), конвертер тоже записывает как ABSENT. UNKNOWN-VALUE — утверждение «есть», поэтому используется, только когда так говорит сам источник.

## Отличие от других «нет»

- Правило Codec, использующих [LOCAL](/ru/grammar/reference/local/) `0` как «нет» ([TOULMIN](/ru/grammar/edge/toulmin/) REF и др.), — соглашение внутри этого Codec. Оно отличается от маркера слота.
- Identified LOCAL не используется как null или sentinel. Чтобы записать неизвестное или отсутствующее, в поле, принимающем маркеры, пишут маркер.

## Пример

Граница Q30 (США) – Q34266 (Российская империя), время окончания неизвестно. Edge Id приведены для пояснения.

```
148A 0088 080C 00A8 002F 00A0 001E 00A0 85DA 0000      #2060 TRIPLE P47 Q30 Q34266 normal
138B 0088 0C58 00A8 0246 0088 080C 0001                #3160 QUALIFIER P582 #2060 UNKNOWN
```

Центральный банк Q30, в 1811~1816 годах его не было.

```
140A 0088 0C59 00A8 0518 00A0 001E 0002 0000           #3161 TRIPLE P1304 Q30 NONE normal
148B 0088 0C5A 00A8 0244 0088 0C59 0924 3138 3131      #3162 QUALIFIER P580 #3161 EDTF("1811")
148B 0088 0C5B 00A8 0246 0088 0C59 0924 3138 3136      #3163 QUALIFIER P582 #3161 EDTF("1816")
```

- Место маркера — 1 WORD. TRIPLE становится 9 WORD (`140A`), QUALIFIER — 8 WORD (`138B`).
- В простой форме «детей (P40) нет» — это `140A 0088 <Edge Id> 00A8 0028 <Subject> 0002 0000`.
