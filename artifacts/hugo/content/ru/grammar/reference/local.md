LOCAL — Reference-декларация, указывающая на объект по ID, выданному этим документом. Она ссылается на объекты внутри документа без внешнего Issuer и вне документа смысла не имеет. Чтобы указывать на объект извне документа, в документ помещают Meta [DOC-ID](/ru/grammar/meta/declaration/doc-id/), а другие документы указывают на него через Reference-указатель.

## Раскладка

```
TAG WORD          0000 0LLL L000 1QQQ      CCCC = 0001
[Length extension TAG]
LOCAL ID          unsigned big-endian наименьшей ширины
```

| LOCAL ID | Всего | TAG WORD (Identified) |
|---|---|---|
| `0..65535` | 2 WORD | `0x0088` |
| `65536..2^32-1` | 3 WORD | `0x0108` |
| `2^32..2^48-1` | 4 WORD | `0x0188` |
| `2^48..2^64-1` | 5 WORD | `0x0208` |

- TAG WORD — `0000 0 LLLL 0001 QQQ`. Для Identified (`000`) младшие 7 бит равны `0x08`.
- Применяется общее правило Reference: ID объекта записывается наименьшим числом WORD.

## Edge Id

- LOCAL — первый элемент Payload Edge — это объявление Edge Id этого Edge ([Edge](/ru/grammar/edge/)). У LOCAL, объявляющего Edge Id, используется только Quantifier `000`.
- LOCAL на остальных местах Payload Edge — упоминание. Объект этого документа каждый раз упоминается через LOCAL. Отдельного указывающего кода для объектов этого документа нет.

## Назначение идентификаторов

- ID — целое число, его назначает кодировщик. Величина числа и порядок назначения не имеют смысла, кроме тождества.
- **UNIQUE (обязательно).** В одном документе один LOCAL ID указывает только на один объект. Edge Id объявляется в документе один раз (HEAD Edge и BODY Edge используют одно пространство номеров). Если один и тот же Edge Id объявляют два или более Edge, запись invalid.
- **AUTO INCREMENT (рекомендуется).** Новый ID назначается как максимум из уже назначенных в документе ID + 1, так что ID растут в порядке документа. То же и между версиями (новое создаётся с ID больше удалённых). Это лишь рекомендация, а не условие допустимости, и документ, где ID не растут, тоже valid. Декодер не опирается на величину или непрерывность ID.
- ID `0` не назначается. Он не указывает ни на какой объект и не используется как Edge Id. ID объектов назначаются начиная с `1`.
- На сам документ, изнутри или снаружи него, указывают только одним [DOC-POINTER](/ru/grammar/reference/doc-pointer/) (на себя — DOC-POINTER своего `DOC-ID`). К документу тоже можно прикрепить `BIND`, `LABEL` и Edge вердикта.
- На сам Issuer указывает [ISSUER-POINTER](/ru/grammar/reference/issuer-pointer/). ID документа `0` — индексный документ определений терминов Issuer.
- Codec, придающие смысл `0` на месте компонента ([TOULMIN](/ru/grammar/edge/toulmin/) REF и «нет» у Edge выполнения, «весь документ» у Target [SOURCE](/ru/grammar/edge/source/#источник-всего-документа) в HEAD), следуют правилу этого Codec. Это соглашение внутри этого Codec, отличное от [маркера слота](/ru/grammar/reference/slot-marker/).
- Однажды назначенный ID в том же документе повторно не используется.
- Всегда используется минимальная ширина, в которой можно выразить значение.

## Тождество и область

- Если целочисленные значения LOCAL ID в одном документе равны, это один и тот же объект. Ширина кодирования не входит в тождество.
- Identified LOCAL обозначает идентифицированный объект. Он не используется как анонимный, неуказанный, null или sentinel. Что значение есть, но неизвестно (UNKNOWN-VALUE), или значения нет (NO-VALUE), записывается в поле, принимающем такой маркер, через [маркер слота](/ru/grammar/reference/slot-marker/).
- Разные LOCAL ID — просто разные Reference, а не обязательно разные объекты в реальности.
- Тождество LOCAL не распространяется за пределы документа. Одинаковое число в другом документе никак не связано.
- LOCAL Variable (`100`) — именованная дискурсивная переменная ([Reference](/ru/grammar/reference/), Variable).

## Слияние

При слиянии нескольких документов в один для каждого исходного документа строится таблица соответствия `old ID → new ID`, все LOCAL ID заново назначаются из ID нового документа, и все ссылки заменяются.

- ID, совпадавшие в одном исходном документе, должны совпадать и после слияния.
- Одинаковые числа в разных исходных документах никак не связаны и автоматически в один Reference не сливаются.
- Если хотя бы один LOCAL не удалось заменить, слияние отклоняется.

## Допустимость

Следующие кодирования или назначения invalid.

- non-minimal кодирование с ведущим WORD `0x0000` (исключение — значение 0 в виде 1 WORD `0x0000`)
- На месте объявления Edge Id Quantifier не равен `000` или ID равен `0`
- В одном документе один ID назначен разным объектам с наложением
- В одном документе один и тот же Edge Id объявлен два или более раз

## Пример

| LOCAL ID | WORD sequence |
|---:|---|
| 1 | `0088 0001` |
| 65535 | `0088 ffff` |
| 65536 | `0108 0001 0000` |
| 4294967295 | `0108 ffff ffff` |
| 1, Variable | `008C 0001` |
