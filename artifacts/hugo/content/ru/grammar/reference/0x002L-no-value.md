NO-VALUE — [маркер места](../slot-marker.md), означающий «нет». Это утверждение о мире: значения нет.

| Пункт | Значение |
|---|---|
| Имя | `NO-VALUE` (BIND `NO-VALUE` в документе спецификации) |
| TAG ID | `0x002L` |
| Codec ID | `0x00000020` |
| Документ спецификации | `0x00000000/codecs/0x00000020/` (цель DECLARE `0020`) |
| Раздел | 0 `0000` (сущность Reference), смещение внутри раздела C = 2 |
| Kind | Reference · классификация: маркер места |
| TAG WORD | `0000 0000 0010 LLLL` (`000K KKKC CCCC LLLL`) |
| Описание в индексе | Нет. Значения нет (`novalue` в Викиданных) |
| Сторона Hugo | `reference/slot-marker.md` |

## Раскладка {#레이아웃}

```
TAG WORD          0000 0000 0010 0000      WORD 0x0020, 1 WORD
```

- Payload нет. Нет ни ID цели, ни Quantifier ([маркер места](../slot-marker.md#레이아웃)).
- Форма `0x002L` с Payload (L ≥ 1) — Reserved.
- Текстовая запись в `geul show` и `geul add`: `NONE`.

## Смысл {#뜻}

| Пункт | Нет |
|---|---|
| О чём высказывание | **О мире**: значения нет |
| Логика | `¬∃x. P(s, x)` |
| Допущение о мире | Закрытый мир относительно (s, P, ограничивающие условия) |
| Викиданные | `novalue` |

## Допустимость {#수용}

- Принимают только поля с целью CODEC `0020`. Такое поле принимает утверждение «нет». Примеры: Object в [TRIPLE](../edge/0x0AAL-triple.md), Value в [QUALIFIER](../edge/0x0ABL-qualifier.md).
- Нельзя использовать в шаблонах-подстановках (wildcard), в полях без CODEC, на местах записей HEAD и BODY, на месте Edge Id и в полях простых значений (общее правило [маркера места](../slot-marker.md#수용-규칙)).

## Обязанности читающей стороны {#읽는-쪽의-의무}

- **NO-VALUE замкнут внутри ограничивающих условий своего высказывания.** Если присоединён QUALIFIER, мир закрыт только в этих пределах. Q30 P1304 NO-VALUE(P580 1811, P582 1816) означает, что центрального банка не было только в 1811–1816 годах, и это не противоречит TRIPLE со значением того же свойства (Федеральная резервная система, preferred).
- Если для одних и тех же Subject и Predicate NO-VALUE и TRIPLE со значением стоят вместе с одинаковым rank, а ограничивающие условия не различаются, это противоречие. Проверяющая программа выдаёт предупреждение, но не отвергает: такое состояние бывает и в Викиданных, а читающая сторона выбирает по rank.
- **Rank применяется так же.** При выборе представительного значения (truthy) TRIPLE с NO-VALUE тоже входит в число кандидатов.
- **Если NO-VALUE стоит значением QUALIFIER, он меняет смысл этого уточнения.** `P582 = NONE` утверждает, что оно не закончилось. Если QUALIFIER P582 нет вовсе, неизвестно, закончилось ли оно.
- Сказать «нет» можно, только **записав** NO-VALUE. Если TRIPLE в документе нет, это «не указано» (открытый мир).

## Пример {#예시}

`0x0020`, 1 WORD. Например, «детей (P40) нет» записывается как `0AA8 0051 <Edge Id> 0191 0028 <Subject> 0020 0000` (TRIPLE, на месте Object стоит `0020`).

## Документ кодека {#코덱-문서}

В документе кодека есть только один DECLARE (цель `0020`). Payload нет, поэтому нет и FIELD. Декодер имеет смысл маркера и правила допустимости встроенными ([слой 0](../publishing.md#층)). Чтобы прочитать маркер, документ кодека не запрашивают.

## Исходный текст документа спецификации {#규격-문서-원문}

Документ спецификации `0x00000000/codecs/0x00000020/latest.geul`, прочитанный командой `geul show` (шестнадцатеричные значения в верхнем регистре).

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000002000000000
BODY
#1 DECLARE 0x0020
#2 BIND #1 "NO-VALUE"
```
