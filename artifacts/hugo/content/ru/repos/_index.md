Публичные репозитории GEUL находятся в организации [geul-org](https://github.com/geul-org) на GitHub. Нормативная грамматика — [грамматика GEUL](/ru/grammar/) на этом сайте.

Документ GEUL — это последовательность 16-битных WORD. Единица данных — запись, которая начинается с одного TAG WORD; записи содержатся в документе. Документы публикует Issuer, и каждая версия закреплена хешем содержимого. Репозитории ниже — инструменты для записи, чтения, преобразования и поиска таких документов.

## Библиотека

### gogeul

Библиотека GEUL для Go и инструмент командной строки `geul`.

Пишет, читает, проверяет и публикует документы GEUL (`.geul`). Пакеты предоставляют проверку формата, декодирование записей по документам спецификаций Codec, разницу между версиями, разрешение зависимостей IMPORT и Codec TOULMIN. CLI `geul` охватывает редактирование (`new`, `add`), публикацию (`publish`), просмотр (`ls`, `log`, `show`), просмотрщик в браузере (`serve`, `build`) и архивы pack (`pack build`, `pack unpack`). Архивы pack могут хранить записи, сжатые zstd.

## Wikidata

### wikigeul

Преобразование Wikidata → GEUL (прежнее название gogeulwiki).

Читает дамп Wikidata, загруженный wikipg в PostgreSQL, и публикует по одному документу GEUL на каждый элемент или свойство: метки, описания, псевдонимы, утверждения с квалификаторами и источниками, ссылки на сайты на всех языках. Все документы публикуются под Issuer `wikidata.geul.org` (`0x00010000`).

|---|---|

| Язык | Go |

### wikipg

Загрузка JSON-дампов Wikidata в PostgreSQL без потерь.

Хранит сущности, метки, описания, псевдонимы, утверждения, квалификаторы, источники, ссылки на сайты и Lexeme в порядке дампа и сохраняет каждую строку дампа дословно. Сам дамп (файл, URL, размер, контрольные суммы, коммит загрузчика) тоже записывается. wikipg не зависит от GEUL.

## Поиск

### silk

[SILK](/ru/projects/silk/) — движок индексации и поиска, созданный для GEUL.

Строит секционированные отсортированные индексы записей архива pack GEUL и отвечает на запросы вроде «какие документы утверждают, что профессия (P106) человека — физик (Q169470)?», не декодируя все документы. Разделяет записи и их поля только по TAG WORD, без кодовой книги. Находится на ранней стадии разработки, проверяет алгоритмы поиска; форматы могут измениться до первого выпуска.

## Кодовые книги (до v1)

Два репозитория ниже спроектированы до текущей грамматики v1. Отдельные части с ней не совпадают.

### sidx

Исследование назначения SIDX (Semantic-aligned Index).

Исследовательские материалы по назначению SIDX — семантического адреса, который даёт близкие номера сущностям с близким смыслом, — на основе статистики использования Wikidata. Содержит прежнюю 48-битную схему атрибутов Entity, скрипты кодировщика и кодовые книги; назначений SIDX пока нет. Нормативное определение SIDX — [GEUL-SIDX](/ru/grammar/reference/geul-sidx/) в грамматике.

| | |
|---|---|
| GitHub | [geul-org/sidx](https://github.com/geul-org/sidx) |
| Язык | Python |
| Лицензия | CC0 |

### wordnet-verb

Временная 16-битная кодовая книга глаголов на основе WordNet 3.0.

Даёт каждому из 13 767 глагольных synset WordNet 3.0 один 16-битный код, причём близким по смыслу глаголам — близкие коды. Это временная редакция, которую заменит кодовая книга без WordNet; как переносить коды в записях GEUL, ещё не решено.

Содержит материалы, производные от WordNet, поэтому **не является продуктом CC0.** Производные от WordNet части подчиняются WordNet 3.0 License; под CC0 только собственные части проекта GEUL, например коды и классификация.

## Связанные репозитории

Репозитории вне организации geul-org.

### toulmin

Движок правил на основе модели аргументации Тулмина (TypeScript, Python, Go, C).

Правила — это функции, а исключения — отношения атаки в графе. Edge [TOULMIN](/ru/grammar/edge/toulmin/) грамматики GEUL (прямые коды `0x60`–`0x7B`) записывает эти графы суждений и исполнения как документы GEUL.
