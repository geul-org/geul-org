GEUL（General Encoding Unified Language）语法是基于 SIDX（Semantic-aligned Index）64位全局语义标识符的二进制流格式。

## 设计原则

1. **长期可扩展性：** 不将保留位挪作临时用途。为未来世代保留可用空间。
2. **语义永久性：** 一旦定义的位模式含义不再更改。如需新含义则分配新模式。
3. **向下兼容：** 任何版本的 GEUL 都必须能完整解析所有旧版本。
4. **线性复杂度：** GEUL 符号处理对长度保持 O(n)。

## SIDX 概述

SIDX 是64位全局语义标识符。从最高位开始逐位分支以确定区域。

| Prefix | 区域 | 比例 | 用途 |
|--------|------|------|------|
| `1` | Far Future | 50% | 远未来保留 |
| `01` | Future | 25% | 近未来保留 |
| `001` | Standard | 12.5% | 官方标准区域 |
| `000` | Free | 12.5% | 完全自由 |

`0001` 是自由区域（000）中本提案所使用的惯例空间。

## Prefix 体系

```
bit1
├─ 1: Far Future
│
└─ 0
    └─ bit2
        ├─ 1 (01): Future
        │
        └─ 0
            └─ bit3
                ├─ 1 (001): Standard
                │     └─ bit4~
                │         ├─ 1           (001 1)        → Tiny Verb Edge
                │         ├─ 01          (001 01)       → Verb Edge
                │         ├─ 001         (001 001)      → Entity Node
                │         └─ 000         (001 000)      → 9位统一区域
                │
                └─ 0 (000): Free
                      └─ 0001: Proposal (Standard 镜像)
```

## 数据包类型

GEUL 流由9种数据包类型组成。按 Prefix 位分配顺序（=重要度）排列。

| 类型 | Prefix | 字 | 说明 |
|------|--------|------|------|
| Tiny Verb Edge | `0001 1` | 2 | 高频简单谓述 |
| [动词边](../verb-edge/) | `0001 01` | 3~5 | 559 根动词 → 13,767 WordNet 动词 |
| [实体节点](../entity-node/) | `0001 001` | 4 | 64 EntityType，48位属性 |
| [三元组边](../triple-edge/) | `0001 000 110` | 4~5 | 属性/关系，Top63 + 扩展 |
| [子句边](../clause-edge/) | `0001 000 101` | 4 | 基于RST的篇章/逻辑16种关系 |
| [事件6边](../event6-edge/) | `0001 000 100` | 3~8 | 六何原则事件 |
| [上下文边](../context-edge/) | `0001 000 011` | 3 | 世界观/语境64类型 |
| [数量节点](../quantity-node/) | `0001 000 010` | 4~7 | 64单位代码，SI/货币/时间戳 |
| [AST 边](../ast-edge/) | `0001 000 001` | 3+ | 64种编程语言，256种AST节点类型 |
| [分组边](../group-edge/) | `0001 000 000 111` | 4+ | 集合/分组7类型 |

## 编码规则

| 项目 | 规则 |
|------|------|
| 字节序 | Big Endian |
| 位序 | MSB First (bit1 = MSB) |
| 字大小 | 16位（2字节） |

所有字段对齐到16位字边界，数据包大小始终为字单位（2字节倍数）。需要填充时以 0x00 填充。
