DO 是用于写入 TOULMIN 图关系的 LINK Codec。含义：节点为 Active 时执行的动作。

| 项目 | 值 |
|---|---|
| 名称 | `DO`（规格文档 BIND `DO`） |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| 规格文档 | `0x00000000/codecs/0x00001110/`（DECLARE 对象 `1110`） |
| 章节 | 8 `1000`（Edge TOULMIN），章节内偏移 C = 17 |
| Kind | Edge · 系列：TOULMIN，分组：执行，布局：LINK |
| TAG WORD | `0001 0001 0001 LLLL`（`000K KKKC CCCC LLLL`） |
| 索引说明 | 节点为 Active 时执行的动作 |
| Hugo 侧 | `edge/toulmin/link.md` |

## 布局 {#레이아웃}

布局为 [LINK](_index.md#link)（ID、src、dst、flags、条件字段、SPAN）。

| 项目 | 值 |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | 规则 → FuncRef |

- dst 是 FuncRef（REF(ALIAS，没有则为 0) + VerbCode 1 WORD）（[NODE](_index.md#필드)）。
- 不使用 F_FORCE（若已开启则拒绝）。
- 公共字段（ID、REF、SPAN）与数值规则遵循 [TOULMIN](_index.md#공통-필드)。

## Codec 文档 {#코덱-문서}

Codec 文档设有 DECLARE（对象 `1110`）。LINK 布局的条件字段以及由 SOURCE 决定的 SPAN 宽度无法用 FIELD 声明，因此字段声明是未决问题（[TOULMIN](_index.md#열린-문제)）。

## 规格文档原文 {#규격-문서-원문}

用 `geul show` 读取规格文档 `0x00000000/codecs/0x00001110/latest.geul` 的样子（十六进制为大写）。

```
SPEC-VERSION 0x0001
DOC-ID 0x0426000000000000111000000000
BODY
#1 DECLARE 0x1110
#2 BIND #1 "DO"
```
