DO es el Codec LINK que escribe una relación del grafo TOULMIN. Significado: acción que se realiza si el nodo está Active.

| Elemento | Valor |
|---|---|
| Nombre | `DO` (BIND `DO` del documento de especificación) |
| TAG ID | `0x111L` |
| Codec ID | `0x00001110` |
| Documento de especificación | `0x00000000/codecs/0x00001110/` (destino de DECLARE `1110`) |
| Sección | 8 `1000` (Edge TOULMIN), desplazamiento dentro de la sección C = 17 |
| Kind | Edge · familia: TOULMIN, grupo: ejecución, layout: LINK |
| TAG WORD | `0001 0001 0001 LLLL` (`000K KKKC CCCC LLLL`) |
| Descripción del índice | acción que se realiza si el nodo está Active |
| Lado Hugo | `edge/toulmin/link.md` |

## Layout {#레이아웃}

El layout es [LINK](_index.md#link) (ID, src, dst, flags, campos condicionales, SPAN).

| Elemento | Valor |
|---|---|
| TANGEUL | `do fn when n` |
| src → dst | regla → FuncRef |

- dst es un FuncRef (REF (ALIAS, o 0 si no hay) + VerbCode de 1 WORD) ([NODE](_index.md#필드)).
- F_FORCE no se usa (si está activado, se rechaza).
- Los campos comunes (ID, REF, SPAN) y las reglas numéricas siguen a [TOULMIN](_index.md#공통-필드).

## Documento del Codec {#코덱-문서}

El documento del Codec contiene DECLARE (destino `1110`). Los campos condicionales del layout LINK y el ancho de SPAN que fija SOURCE no se pueden declarar con FIELD, por lo que la declaración de campos es un problema abierto ([TOULMIN](_index.md#열린-문제)).
